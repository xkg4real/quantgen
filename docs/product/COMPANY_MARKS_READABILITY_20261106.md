# 기업 식별·연구홈 표·설명문 가독성

2026-11-06, main f180f69 이후 사용자가 요청한 추가 UI 변경입니다.

Home 표는 원형 회사 문자 마크, 코드 pill, 이름을 한 줄로 묶습니다. 행 높이는
44px이며 전체 이름은 모델·접근성 이름·툴팁에 남습니다. 가격·등락·거래량·시총·PER·EPS는
오른쪽 정렬하고 Q-SCORE와 `?`는 마지막 열에 둡니다. 좁은 창에서는 표 내부 가로
스크롤과 키보드 상세 열기를 유지합니다. 동일 마크를 시장 카드·검색·종목 제목에서
재사용하며 종목·언어가 바뀌면 이름도 함께 갱신합니다.

마크는 네트워크 없이 그리는 자체 문자 식별자입니다. 외부 공식 기업 로고를 받았다고
주장하지 않습니다. 알려진 국내 기업 그룹 외에는 이름/코드에서 중립 마크를 만듭니다.
두 테마에서 같은 마크 색을 유지하며 회사명·코드를 대신하지 않습니다.

거래량과 시가총액은 공통 `compact_large_number`로 K/M/B/T를 사용합니다. 한국어도
동일하며 소수·그룹 구분은 지역 형식을 따릅니다. 반올림으로 1000K가 되면 1M로
올립니다. 누락·비유한 값은 `—`이고 전체 값은 상세 또는 툴팁에 남습니다. 가격은
축약하지 않습니다. 새로운 가격·기업 분석·Q-SCORE 산식·공급자 요청을 만들지 않습니다.

작은 한글 획에 관한 사용자 보고는 글자 누락이 아닌 흐림/울퉁불퉁함입니다. 동봉
Pretendard 기반 OTF와 고정 원본 OTF, 공식 대체 TTF를 비교했으며 원본에도 glyph
hint 명령이 없었습니다. 파일 변환 중 힌트를 잃었다고 단정하지 않습니다. Qt Windows
기본 힌팅을 새 수리처럼 표현하거나 동일한 무힌트 TTF로 교체하지 않았습니다.
공통 본문 라벨은 15px, 설명 캡션은 실제 Medium 14px/500으로 올리고 Home 설명문은
14px/500과 본문색을 사용합니다. 표·차트의 밀집 글자는 별도 크기를 유지합니다.
글꼴 바이너리·OFL은 그대로이며 외부 다운로드나 텍스트 비트맵 확대를 추가하지 않습니다.

검증은 공급자 요청을 차단한 fixture 기반 Qt offscreen입니다. 표의 상세 클릭·Enter,
언어/테마 전환, 값과 단위, 이름 말줄임/접근성, 큰 가격의 실제 치수와 Q-SCORE 버튼
배치를 검사합니다. 시장 카드/검색/제목의 마크 전환과 전체 거래량 툴팁을 검사합니다.
1360/1000px와 100/125/150% 논리 배율 캡처는 Linux 렌더링 근거이며 실제 Windows의
