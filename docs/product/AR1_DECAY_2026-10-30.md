## Correction

For `x[t] = c + phi*x[t-1] + error`, an impulse after k observations is
`phi**k`. Its amplitude is `abs(phi)**k`; a stable negative coefficient
alternates sign while shrinking. The old `phi <= 0 -> inf` rule incorrectly
reported no finite decay for those stationary oscillating examples.

`ar1_decay` now exposes the fitted coefficient, definition, observation
unit and one of these diagnostic statuses:

| Status | Meaning | Half-life |
| --- | --- | --- |
| MONOTONE | 0 < phi < 1 | -log(2)/log(phi), same as before |
| OSCILLATING | -1 < phi < 0 | -log(2)/log(abs(phi)), amplitude only |
| NO_MEMORY | phi = 0 | 0 as the zero-persistence limit; no memory after one observation |
| NON_DECAYING | abs(phi) >= 1 | no finite estimate |
| NOT_ESTIMATED | too short, non-finite or unidentified/rank-deficient variation | no estimate |

The numeric `half_life` entry point retains infinity for unavailable or
non-decaying cases for compatibility. The structured diagnostic uses null
and an explicit status. Existing `half_life_days` payload keys are retained;
their accompanying definition states **observations**, not elapsed time
over missing dates. Negative stable estimates are labeled amplitude decay,
not monotone OU decay or proof of stationarity.

ETF and Crypto Flet/Qt views, shared commentary, AI context and native
JSON/HTML reports carry the meaning. An old result lacking diagnostic
metadata shows "not estimated" rather than inventing a reason. ETF no
longer uses infinity to claim slow reversion/entry timing or uses a short
half-life alone to conclude a discount is tradable after fixed costs.
The GARCH variance half-life is a different model and is unchanged.
