## PR #57 통합 재대조 — 2026-11-02

현재 통합은 `853de90`의 상세 전송·보관·선택/중지 사실과 PR #57 `cac727e2`의 정당한 정책·버전·검토 이력을 모두 보존합니다. [FACTS](../compliance/FACTS.md#kis-market-integration-2026-11-02)에 중복 설명을 통합했습니다.

- 지정 개발 인터프리터 `/workspace/work/quantgen-dev-venv/bin/python`가 확인한 설치본은 **websockets 16.0 / BSD-3-Clause**이며 라이선스 원문과 추가 Requires-Dist 부재를 확인했습니다. PR #57 당시 기록의 **16.1.1**과 서로 다른 환경/시점의 증거입니다. 현재 별도 `/workspace/.venvs/quantgen`에서 발견한 **17.3**은 선언 `>=15,<17` 밖이므로 이 통합의 의존성 충족 증거로 사용하지 않습니다. 공유 환경·의존성 선언은 변경하지 않았습니다. 최종 배포 버전·고지·전이 의존성 확인은 남아 있습니다.
- 승인 발급 주소는 설정된 `client.base_url`을 사용하며 기본값이 HTTPS일 뿐 코드가 모든 설정 주소의 HTTPS를 보장하는 것은 아닙니다. 실제 구독의 `ws://`·23시간 재사용/삭제 구분과 서버 사용자 분리·로그·권리 미검증 조건을 유지합니다.
- Flet의 실시간 중지는 WebSocket만 중지하고 REST 반복은 별도 스위치를 OFF로 바꿉니다. 두 모드는 상호 배타적이며 화면 이탈·세션 종료는 둘 다 중지합니다. 이미 시작된 요청의 취소·전역 캐시 삭제·원격 철회로 확대하지 않습니다.
- 최종 통합 팔레트는 PR #57의 LIGHT SMA `#896000`/BB `#157367`을 유지했습니다. DARK도 유지합니다. `tests.market_core_acceptance` **17개 PASS**는 양 테마·420/1000 폭의 모든 렌더링 텍스트 **4.5:1 이상**, 지표 그래픽 **3:1 이상**, 색상 외 구조·좌표·지표 불변을 확인합니다. [14번](../compliance/14-contrast.md)의 과거 대비 실패·중간 수정·최종 색상/범위를 구분하며 실제 Windows·브라우저·전체 상태·보조기술 수용은 미실행입니다.

20개 문서의 `review-required`·공개 준비 `BLOCKED`와 운영/권리 미확정 조건은 바꾸지 않았습니다. 소스 fingerprint는 전체 통합 검토 후 별도로 갱신합니다.
