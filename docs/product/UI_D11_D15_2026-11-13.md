## 요청한 화면 변화

- **시장 차트 대기:** KIS 이력을 받은 페이지부터 표시한다. 전체 이력·현재가를 기다리는 동안에도 먼저 받은 차트를 볼 수 있다. 기존 요청 횟수·최종 결과·한도는 유지하며 조회 중 상태를 표시한다. 최종 결과 전에는 실시간 구독과 점수 결과 전달을 시작하지 않고, 이전 종목 응답은 버린다. 실제 계정 응답속도 개선율은 측정하지 않았다.
- **기술지표 가이드:** 입력 검색을 없애고 SMA·EMA·RSI·MACD·볼린저 밴드를 설명형 복수 선택 카드로 배치했다. 같은 과거 사례와 기간에서 비교하며 선택 색상·해설·차트를 연결한다. 짧은 해설, 상세 펼치기, 반례를 제공한다. 추가 용어도 입력 대신 목록에서 선택한다.
- **분석 화면 안내:** 분석 도구 10종, 설계/검증 2종, 분석 3종에 목적·범위·3단계 사용 안내를 추가했다. 채권과 Monte Carlo의 실행 전 빈 결과 영역을 접었다. 첫 방문에는 제목부터 보여주고 재방문에는 읽던 위치를 유지한다.
- **글꼴:** 스타일이 적용된 자식 위젯에도 QG Interface를 명시해 기호 글꼴로 대체되며 본문이 사라지던 경로를 수정했다. 기존 폰트 파일과 N3 설정은 바꾸지 않았다.

## CMD 업데이트·실행

실행 중인 앱을 닫고 **CMD**에서 아래 블록 전체를 실행한다. PowerShell용 명령이 아니다.

```bat
cd /d "C:\Users\skymi\OneDrive\문서\GitHub\quantgen"
set "QG_GIT=git"
for /d %G in ("%LOCALAPPDATA%\GitHubDesktop\app-*") do @if exist "%G\resources\app\git\cmd\git.exe" set "QG_GIT=%G\resources\app\git\cmd\git.exe"
"%QG_GIT%" switch main && "%QG_GIT%" --no-pager pull --ff-only origin main && "%QG_GIT%" --no-pager log -1 --oneline && .venv\Scripts\python.exe -X utf8 -m quantgen_desktop
```

GitHub의 변경은 PC에 자동 반영되지 않는다. 위 명령으로 main을 받아 앱을 다시 연다.
`.env`와 `.venv`는 삭제하지 않는다. Git이 충돌을 보고하면 reset/clean하지 않는다.
