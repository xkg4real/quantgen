## 추가 사용자 요청: 차트 대기·가이드·작업 안내

기존 PR112에 함께 반영한다. KIS 차트는 첫 이력 페이지를 먼저 표시하고 나머지 이력과 현재가를 받는다.
API 요청 횟수·최종 결과는 그대로이며 실제 계정의 속도 개선율을 주장하지 않는다.
기술지표 가이드는 5개 지표의 설명형 복수 선택 카드와 같은 기간 비교, 짧은 해설+상세 펼치기,
선택형 추가 용어 목록으로 구성한다. 직접 입력 검색창은 없다.
분석 도구 10종/설계·검증 2종/분석 3종에는 목적·범위와 3단계 안내가 있다. 채권/Monte Carlo는
실행 전 빈 결과를 접는다. 공통 스타일에서 QG Interface를 명시해 기호 글꼴 대체로 글자가 빠지는 문제를 고친다.

검증: 차트/라우터/가이드 90개, 작업 안내/레이아웃 60개 통과. 한국어 밝게1440px·영어 어둡게1000px
가이드/도구/설계/분석 캡처에서 가로 넘침 없음. 첫 방문 스크롤·글꼴 글리프·라이브 점수/저장 후속 검사는
최종 CI에 포함한다. 중간 f74c63c CI의 옛 SymbolCard.qscore 검사 참조는 새 점수 카드/배지 검증으로 수정했다.
Windows/Linux 최종 CI 통과 전 main 적용 완료로 보고하지 않는다.

추가 CI 검증에서 첫 방문 스크롤의 자유 singleShot 클로저가 창 파괴 뒤 실행되는 오류를 발견했다. 창 소유 단발 QTimer로 교체하여 파괴 시 취소하고 즉시 파괴 회귀 검사를 추가했다. Windows 세 버전의 점수·보고서 저장 선행 검사는 b658cde에서 모두 통과했다.
