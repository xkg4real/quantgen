# 10. 요금·추가 비용 고지 정책 및 가격표 양식

문서 ID: QG-C10 · 버전: 1.2 · 검토일: 2026-10-31 · 상태: review-required

## 적용 범위와 현재 상태

QUANTGEN 소프트웨어의 판매, 구독, 체험, 추가 기능, 결제 직전 화면 및 외부 서비스 비용 설명에 적용한다. 2026-10-31 사용자 제공 정보에 따라 아래 세 상품의 원화 월 요금·부가세 포함·월 자동 갱신 조건과 Team Pilot 최대 5인 조건을 확정하여 반영했다. 현재 코드에서 실제 결제·환불 시스템과 자동 갱신 실행 기능은 확인하지 못했다. 확정한 가격 조건을 실제 결제 구현 완료로 해석하지 않는다.

Strategy Lab의 `Cost bp/side` 등은 백테스트에 반영하는 **가정 거래비용**이다. 소프트웨어 이용료, 실제 증권사 수수료 청구, QUANTGEN 결제와 구별해 표시해야 한다. 이용자 API 키로 사용하는 데이터·AI 서비스에 별도 비용이 생기는지는 해당 공급자 요금제와 계약으로 확인한다.

### 2026-10-31 앱 UI 변경 검토

교육 가이드·지역별 숫자 표시에 서비스 청구 또는 외부 유료 번역 호출을 추가하지 않았습니다. 지원 언어를 선택해도 계약 통화·가격을 환전하거나 변경하지 않습니다. 기존 상품 가격·외부 데이터와 AI 계약 비용의 확인 의무는 그대로입니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

## 정책 또는 구현 기준

### 확정 요금표

| 상품명 | 결제 통화 | 월 총액 | 부가세 | 결제 주기·자동 갱신 | 사용 인원 |
|---|---|---|---|---|---|
| Research | KRW | 29,000원 | 포함 | 매월 결제·매월 자동 갱신 | 인원·기기 조건 미확정 |
| Pro | KRW | 59,000원 | 포함 | 매월 결제·매월 자동 갱신 | 인원·기기 조건 미확정 |
| Team Pilot | KRW | 290,000원 | 포함 | 매월 결제·매월 자동 갱신 | 최대 5인; 초과 이용 조건 미확정 |

월 총액은 상품 단위 금액이다. Team Pilot의 월 290,000원을 1인당 요금으로 표시하지 않는다. 상품별 기능·지원·AI·데이터 포함 범위, Research·Pro의 인원·기기 조건, 이용 개시일, 결제수단, 청구 기준일·다음 결제일, 해지 방법·효력은 미확정이다. 무료 체험·할인·연간 요금·일할 환불을 제공한다고 표시하지 않는다. 추가 자율 환불정책은 협의 중이며 법정 청약철회·하자 구제·환급 의무는 그 협의와 별도로 적용한다.

### 가격 표시 및 판매 전 구현 기준

1. 상품명, 제공 기능, 이용 범위, 결제 통화, 세금 포함 최종 결제액, 이용 기간, 결제 주기, 자동 갱신 여부를 한 화면에서 확인할 수 있게 한다.
2. 필수 수수료를 뒤 단계에서 추가하지 않는다. 외화 결제·해외 카드 비용처럼 사업자가 최종 금액을 정할 수 없는 비용은 부담 주체와 산정 근거를 신청 전에 설명한다.
3. 할인·정상가·연간 환산가는 비교 기준과 기간을 명시한다. 실제 결제액을 월 환산가보다 눈에 띄지 않게 숨기지 않는다.
4. 무료 체험의 기간, 유료 전환일, 전환 가격, 결제수단 등록 필요 여부, 해지 방법을 밝힌다. 자동 갱신의 신청·변경·해지와 관련된 적용 법령은 [출처 대장](SOURCES.md) 및 이용약관과 함께 검토한다.
5. API·AI·데이터 비용이 상품 가격에 포함되는지 명시한다. 별도 계약이 필요한 공급자의 비용·권리를 QUANTGEN 이용권이 모두 포함한다고 광고하지 않는다.
6. 청약철회·환불 안내는 [03번 환불정책](03-refund-policy.md)과 일치시킨다. 법정 권리를 가격표의 짧은 문구로 배제하지 않는다.
7. 가격이 바뀌면 가격표·구매 버튼·결제 화면·약관·영수증과 기존 이용자 적용 조건을 함께 갱신한다. 미확정 가격은 판매 화면에 게시하지 않는다.

미확정 운영 조건을 채우고 판매 흐름을 검증한 후 게시할 가격 안내 양식:

> 판매자: (주)넥스트제너레이션  
> 월 총액: Research KRW 29,000원 / Pro KRW 59,000원 / Team Pilot KRW 290,000원 중 선택 상품의 금액, 모두 부가세 포함  
> 결제 주기·자동 갱신: 세 상품 모두 매월 결제·매월 자동 갱신  
> 사용 인원: Team Pilot 최대 5인; 다른 상품의 인원·기기 조건은 판매 전 확정  
> 상품별 제공 기능·이용 개시: {{pricing.service_period_and_scope}}  
> 실제 다음 결제일·해지 효력: {{pricing.next_billing_and_cancellation_effect}}  
> 별도 비용: {{pricing.external_costs}}  
> 해지·환불: {{pricing.cancellation_path}} / {{pricing.refund_policy_url}}  
> 문의: {{operator.support_email}}

실제 상품 화면에서는 선택한 상품의 월 총액을 단독으로 명확히 표시하고, 미선택 상품의 가격과 혼동되지 않게 한다. 추가 환불 혜택은 협의 중이며, 법정 권리는 [03번 정책](03-refund-policy.md)에 따른다.

분석 화면에 사용할 문구:

> 거래비용 가정은 분석 결과를 계산하기 위한 입력입니다. QUANTGEN 이용료나 실제 거래 수수료 청구액이 아닙니다. 외부 데이터·AI 이용 비용은 해당 서비스 계약을 확인하세요.

## 양식

아래 표를 Research, Pro, Team Pilot 각각에 대해 작성한다. 이미 확정한 월 요금·부가세·월 자동 갱신·Team Pilot 최대 5인 조건은 그대로 사용한다. 나머지 필수 판매·운영 조건은 `미확정`으로 기록하고, 이를 확정하고 구현하기 전에 실제 결제를 개시하지 않는다.

| 필드 | 확정할 내용 |
|---|---|
| 상품 ID / 버전 / 적용일 | 동일 상품을 식별하는 코드와 가격 적용 시작일 |
| 상품명 / 대상 이용자 | Research / Pro / Team Pilot 중 선택; 개인·사업자 등 판매 대상은 별도 확정 |
| 포함 기능 / 제외 기능 | 데스크톱·브라우저·AI·데이터·지원 포함 범위 |
| 이용 범위 | Team Pilot 최대 5인; 계정·기기·동시 이용 등 나머지 제한은 별도 확정 |
| 결제 통화 / 세금 포함 월 총액 | KRW / Research 29,000원, Pro 59,000원, Team Pilot 290,000원 중 선택; 모두 부가세 포함. 공급가·세액 분리와 반올림은 결제 설계에서 검증 |
| 정기결제 여부 / 주기 / 다음 결제일 | 세 상품 모두 매월 자동 갱신; 실제 청구 기준일·다음 결제일은 미확정 |
| 체험 / 할인 / 연간 요금 | 미확정. 도입 결정 시 기간·전환액·비교 가격의 실제 근거를 별도 기록 |
| 별도 필수 비용 / 선택 비용 | 외부 API, AI, 데이터, 카드 비용의 부담 주체 |
| 해지 경로 / 효력 / 환불 기준 | 경로·효력은 미확정; 법정 권리는 03번 문서 적용, 추가 자율 환불정책은 협의 중 |
| 기존 계약 적용 / 통지 방법 | 변경 대상과 필요한 동의·고지 검토 결과 |
| 가격표·주문·결제·영수증 증거 | 동일 상품의 네 화면 캡처와 금액 대조 |
| 담당 / 검토자 / 상태 | 검토일, 오류 수정 이력, 통과·실패·미실행 |

## 검증과 변경 시 재검토

- **통과:** 가격표부터 최종 결제·영수증까지 동일 조건·금액이고, 모든 필수 비용·자동 갱신·환불 경로가 신청 전에 확인된다. 별도 외부 비용과 분석용 가정 비용이 구분된다.
- **실패:** 최종 단계의 미고지 필수 비용, 숨긴 자동 갱신, 근거 없는 할인, 서비스 가격으로 오인되는 거래비용 표시가 있다.
- 확정 요금 검증: Research KRW 29,000원·Pro KRW 59,000원·Team Pilot KRW 290,000원의 월 총액, 모두 부가세 포함·월 자동 갱신, Team Pilot 최대 5인 조건이 가격표·약관·주문·결제·영수증에서 일치해야 한다. 협의 중인 추가 환불정책을 이유로 법정 권리까지 미확정으로 처리하지 않는다.
- **미실행:** 상품별 기능·남은 운영 조건이나 실제 결제 환경이 미확정이다. 가격·월 자동 갱신 조건의 확정과 결제·해지·환불 구현 완료를 구분한다.
- 가격·세금·상품 기능·청구 제공자·외부 서비스 요금 포함 범위가 바뀌면 재점검한다. 실제 금전 결제 없이 테스트 환경의 주문·금액·해지 흐름으로 먼저 검증하고 운영 증거는 별도 보관한다.
