# 11. 이용후기 진실성 정책 및 게시 승인 양식

문서 ID: QG-C11 · 버전: 1.1 · 검토일: 2026-10-31 · 상태: review-required

## 적용 범위와 현재 상태

QUANTGEN의 제품 화면, 판매 페이지, 앱 소개, SNS, 광고, 보도자료에서 사용하는 이용후기·평점·추천사·고객 사례에 적용한다. 조사한 `main.py`, `ui/`, `quantgen_desktop/`에서 이용후기 모듈을 확인하지 못했다. 외부 마케팅 사이트·광고·실제 배포본의 후기를 점검했다는 뜻은 아니다.

실제 후기 원문, 게시 동의, 대가 제공 여부가 확보되지 않은 사례는 게시하지 않는다. 예시를 만들기 위해 가상의 이용자·실적·프로필 사진을 실제 고객처럼 작성하지 않는다.

### 2026-10-31 앱 UI 변경 검토

추가된 과거 지표 사례와 실패 신호는 공개 관측 자료의 교육 설명이며 고객 후기·실사용자 수익 사례가 아닙니다. 고객 추천사·평점 모듈이나 게시 동의를 추가하지 않았으며 외부 소개사이트 후기는 조사하지 않았습니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

## 정책 또는 구현 기준

1. 실제 이용 경험을 확인할 수 있는 후기만 게시한다. 구매하지 않은 이용자가 제공한 사용 후기라면 구매 후기라고 표시하지 않는다.
2. 원문을 줄이거나 번역할 때 의미·유보·부정적 평가를 바꾸지 않는다. 승인된 편집본과 원문을 연결해 보관한다.
3. 임직원·협력자·유료 홍보·제품 제공·할인·추천 수수료 등 이해관계와 경제적 대가는 후기를 보는 위치에서 명확히 밝힌다. 확인되지 않은 관계를 `자발적 후기`라고 표시하지 않는다.
4. 시뮬레이션·백테스트 결과를 고객의 실제 수익 경험으로 표현하지 않는다. 실제 투자 수익 주장도 기간·비용·표본·권한·근거가 검증되지 않으면 게시하지 않는다.
5. 고객 성명·사진·계정명·거래정보는 필요한 범위만 사용한다. 게시 범위·기간·철회 연락처를 정하고 원자료는 접근을 제한한다. 게시 동의와 서비스 이용 동의를 묶지 않는다.
6. 리뷰 수·평점 평균·표시 순서는 실제 집계 기준과 일치해야 한다. 좋은 후기만 선별한 경우 전체 이용자의 대표 평가처럼 표시하지 않는다.
7. 허위·도용·중대한 오해가 확인되면 게시를 중단하고 재사용 위치를 추적한다. 철회·삭제 요청은 [20번](20-deletion.md)의 접수 절차와 연결한다.

이해관계가 실제로 있는 경우의 게시 문구 예시:

> 이 후기는 {{testimonial.incentive_description}}을 제공받은 이용자가 작성했습니다. 개인의 사용 경험이며 투자 성과를 보장하지 않습니다. 원문 중 {{testimonial.edit_scope}}를 편집했습니다.

대가가 없었다는 표현도 확인 증거가 있을 때만 사용한다. 예시 문구 자체는 후기 자료가 아니며 게시 승인 전 사용하지 않는다.

## 양식

후기별로 다음 승인 대장을 작성한다. 이메일·구매 증빙 등 원본 개인정보는 공개 Git 저장소에 넣지 않고 제한된 증거 위치만 기록한다.

| 필드 | 작성 방법 |
|---|---|
| 후기 ID / 게시 채널 / URL | 모든 재게시 위치를 연결할 고유 ID |
| 작성자 내부 식별자 / 공개 표시명 | 최소 정보 사용, 신원 증거는 비공개 보관 |
| 실제 이용 기능 / 이용 시점 / 확인 근거 | 이용 이력을 확인한 방법과 검토자 |
| 원문 위치 / 원문 해시 / 작성일 | 무단 변경 여부를 확인할 비공개 증거 |
| 편집·번역본 / 변경 사유 | 의미가 유지되는지 작성자 확인 결과 |
| 이해관계 / 제공 대가 | 없음·임직원·제품 제공·금전 등 실제 사실 |
| 공개할 이해관계 고지 | 실제 화면에 표시할 정확한 문구 |
| 게시 동의 범위 / 버전 / 시점 | 채널·사진·이름·기간·철회 방법 포함 |
| 수익·성능 주장 / 연결 근거 | 12번 주장 ID 또는 해당 주장 없음 |
| 이미지 권리 / 연결 권리 ID | 19번 권리 대장의 사진·프로필 항목 |
| 게시 만료·철회일 / 담당 | {{operator.support_email}} 등 실제 접수 경로 확정 |
| 판정 / 승인자 / 검토일 | 통과·실패·미실행·미적용과 사유 |

## 검증과 변경 시 재검토

- **통과:** 원문·실제 이용·게시 권한·대가 관계와 공개 고지가 연결되고, 편집이 의미를 왜곡하지 않으며, 게시된 평점·후기 수가 집계 근거와 일치한다.
- **실패:** 생성한 가짜 고객·도용 사진, 보상 관계 은폐, 원문 없는 추천사, 시뮬레이션을 실수익으로 표시, 철회 후 무단 재사용이 있다.
- **미실행:** 실제 게시물·원문·동의 증거를 확인하지 못했다. 후기 기능이 없으면 `미적용: 해당 릴리스에는 이용후기를 게시하지 않음`으로 한정한다.
- 새 후기, 문구 편집, 평점 집계 방식, 채널 추가, 대가 변경, 게시 동의 철회 시 재검토한다. 자동 검사는 대장 누락·증거 만료를 탐지하며 후기의 진실성을 독자적으로 인증하지 않는다.
