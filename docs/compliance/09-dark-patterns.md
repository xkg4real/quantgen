# 09. 사용자 선택권 보호 정책 및 다크패턴 점검 양식

문서 ID: QG-C09 · 버전: 1.1 · 검토일: 2026-10-31 · 상태: review-required

## 적용 범위와 현재 상태

QUANTGEN의 Flet 브라우저 화면, PyQt6 데스크톱 화면, 향후 판매·가입·해지 화면에 적용한다. 이용자가 분석 설정, 외부 전송, 구매, 해지를 이해하고 직접 선택하도록 하는 기준이다.

- 규칙 작성 화면은 금융 의사결정 입력을 비워 두고 저장·확인·활성화를 구분한다. 네이티브 규칙 화면에도 별도 확인 단계가 있다.
- 네이티브 AI 해설에는 전송 내용 미리보기와 기본 미동의 체크박스가 있다. 모든 Flet·Qt 화면의 동의 동등성은 별도 검증 대상이다.
- 연구 화면에는 종목·분석 모델 등의 기본값이 있다. 이를 사용자의 투자 선택이나 자동 주문 동의로 간주하지 않는다.
- 코드에서 서비스 구매·정기결제·해지 화면을 확인하지 못했다. 향후 화면은 이 문서의 수용 기준을 충족해야 한다. 배포 사이트와 외부 결제 페이지는 아직 점검하지 않았다.

### 2026-10-31 앱 UI 변경 검토

교육 지표는 개별 토글·전체 해제가 가능하고 선택 상태를 색상과 문자·체크 표시로 함께 나타냅니다. 자동 과거 사례와 사용자가 고른 사례를 구분하며, 사례는 투자 선택이나 주문 동의가 아닙니다. 보고서 저장은 명시적 버튼 동작입니다. 실제 구매·해지 여정의 미검증 상태는 유지합니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

## 정책 또는 구현 기준

1. 선택적 개인정보 수집, 마케팅, 비필수 추적, 외부 AI 전송은 사전 선택하지 않는다. 서비스 이용에 필요한 계약 확인과 선택 동의를 한 항목으로 묶지 않는다.
2. 동의·거절의 의미와 결과를 같은 화면에서 읽을 수 있게 한다. 선택 거절이 핵심 연구 기능을 막는 경우에는 실제 기능상 필요성을 설명하고 선택 항목의 분류를 다시 검토한다.
3. 버튼에는 실제 동작을 쓴다. `저장`, `외부 AI로 전송`, `결제하기`, `구독 해지`를 단순한 `계속`으로 감추지 않는다. 닫기·이전·취소를 숨기거나 반복적으로 동의를 재요청하지 않는다.
4. 무료 체험의 유료 전환, 자동 갱신, 결제 주기, 해지 효력 발생일을 최종 신청 전에 표시한다. 해지는 가입과 비교해 부당하게 복잡하게 만들지 않는다.
5. 실제 근거 없는 잔여 수량·마감 타이머·실시간 구매 알림·추천 배지를 쓰지 않는다. 선택하지 않은 상품을 장바구니에 넣지 않는다.
6. 기본 분석값은 `예시 입력` 또는 `분석 가정`으로 설명한다. 기본값의 존재를 투자 권유나 검증된 전략 추천으로 표현하지 않는다.
7. 저장·실행·삭제·외부 전송·결제를 구분한다. 모의 실행을 실제 체결로 오인하게 하는 문구를 사용하지 않는다. 취소가 불가능한 작업은 실행 전에 그 사실을 알린다.

사용 가능한 안내 문구:

> 선택 항목을 거절해도 기본 연구 기능을 이용할 수 있습니다. 외부 AI 해설은 전송 내용을 확인하고 동의한 경우에만 요청합니다. 분석의 기본값은 예시이며 투자 결정을 대신하지 않습니다.

이 문구는 해당 동작이 구현·검증된 화면에만 게시한다. 아직 구현되지 않은 해지·동의 기능이 존재한다고 안내하지 않는다.

## 양식

다음 표를 화면·사용자 여정별로 한 행씩 작성한다. 제어가 없는 항목은 `미적용`과 이유를 남기며 빈칸을 통과로 취급하지 않는다.

| 초기 선택 상태 | 체크 여부·선택값·최초 진입 화면 증거 |

## 검증과 변경 시 재검토

- **통과:** 핵심 행위의 의미·비용·선택권을 실행 전에 알 수 있고, 거절·취소가 동작하며, 선택 동의가 기본 해제되어 있다. 실제 동작과 고지 문구가 일치한다.
- **실패:** 사전 체크된 선택 동의, 허위 희소성, 거절 방해, 동작을 감춘 버튼, 미고지 유료 전환, 존재하지 않는 취소 경로가 하나라도 있다.
- **미실행:** 실제 배포 환경이나 테스트 증거가 없다. 정적 소스 확인만으로 실제 결제·해지 여정을 통과시키지 않는다.
- 가입·구매·AI·쿠키·해지 화면, 기본값, 수집 목적 또는 외부 서비스가 바뀌면 관련 행을 다시 작성한다. 검증 전 변경은 배포 점검표에서 미완료로 유지한다.
- 요금은 [10번](10-pricing.md), 동의는 [06번](06-form-consent.md), 외부 서비스는 [08번](08-third-parties.md)의 기록과 대조한다.
