## 적용 범위와 현재 상태

QUANTGEN 앱 코드에서 방문자용 쿠키 동의 배너·선호 설정 저장 흐름을 확인하지 못했습니다. 선택적 분석·광고 쿠키가 실제로 존재하는지와 사전 선택이 필요한지는 [쿠키 조사 대장](04-cookie-policy.md) 및 적용 법역에 따라 확정합니다. 이 문서는 배너의 문안·상태 전이·기록 양식입니다. 배너가 이미 구현되었다거나 모든 배포에 반드시 필요하다고 선언하지 않습니다.

실제 필수 저장장치만 사용하고 선택 항목이 없는 배포에는 무의미한 “모두 동의”를 요구하지 않습니다. 실제 항목·근거를 설명하는 정책과 필요한 설정 안내를 제공합니다. 선택 항목을 도입하는 경우에는 사용자 선택 전 로드되지 않도록 동작까지 구현해야 합니다.

## 정책 또는 구현 기준

### 첫 화면 문안

> **쿠키 사용 선택**
>
> (주)넥스트제너레이션은 QUANTGEN의 {{cookies.required_purposes}}에 필요한 저장장치를 사용합니다. 선택적 {{cookies.optional_purposes}}는 허용하신 경우에만 사용합니다. 선택 항목을 거부해도 기본 연구 기능은 이용할 수 있습니다. 사용 항목·제공자·기간은 쿠키 정책에서 확인하고, 선택은 언제든 쿠키 설정에서 바꿀 수 있습니다.

첫 화면에 동일한 발견 가능성·가독성·접근성을 갖춘 **“선택 쿠키 거부”**, **“선택 설정”**, **“선택 쿠키 모두 허용”** 버튼과 **“쿠키 정책”** 링크를 제공합니다. 모두 허용만 강한 색으로 표시하거나 거부를 저대비 링크·추가 화면 뒤에 숨기지 않습니다. 버튼의 시각적 배치와 키보드 순서는 일관되게 정하고 수락이 기본 포커스·자동 실행이 되지 않도록 합니다.

### 세부 설정 문안

| 범주 | 설명과 제어 |
| --- | --- |
| 필수 | {{cookies.required_item_names}} / {{cookies.required_purposes}} / 실제 기간·제공자. 필수성 근거와 브라우저 제어 방법 안내 |
| 분석 | {{cookies.analytics_items_and_providers}} / {{cookies.analytics_purpose}} / 기본 OFF. 사용하지 않으면 범주 제거 |
| 광고·맞춤화 | {{cookies.advertising_items_and_providers}} / {{cookies.advertising_purpose}} / 기본 OFF. 사용하지 않으면 범주 제거 |

버튼은 **“설정 저장”**, **“선택 쿠키 모두 거부”**, **“닫기”**로 명시합니다. 닫기·스크롤·다른 화면 클릭·앱 계속 사용·시간 경과를 허용으로 해석하지 않습니다. 아무 선택도 하지 않거나 닫으면 선택 저장장치는 계속 OFF입니다. 정책 링크를 읽기 위해 배너의 수락이 필요해서는 안 됩니다.

### 상태 전이와 기술 계약

| 상태/행동 | 선택 태그·저장장치 동작 | 기록·화면 동작 |
| --- | --- | --- |
| 첫 접속, 결정 없음 | 필수성 확인된 기능만 실행 | 선택 항목 OFF, 문안·버전 제시 |
| 거부 또는 배너 닫기 | 분석·광고 요청을 보내지 않음 | 거부 선택은 필요한 최소 기록만; 닫기는 동의 기록 생성 금지 |
| 일부 허용 | 허용 범주의 제공자만 실행 | 범주별 선택과 제시 버전 기록 |
| 모두 허용 | 공개한 선택 범주만 실행 | 미래의 새 제공자·새 목적까지 허용으로 간주하지 않음 |
| 철회 | 이후 선택 전송 중단, 제거 가능한 해당 저장정보 삭제 | 결과 안내; 철회 전 적법 처리의 효력·법정 보존과 구분 |
| 유효한 선택 없는 오래된 기록·목적 변경 | 필요한 재선택 전 새 선택 처리를 보류 | 변경 항목·이유 표시. 단순 UI 배포마다 무의미하게 재동의 요구하지 않음 |
| 저장 실패·파싱 실패 | 선택 항목 OFF로 유지 | 오류 안내, 필수 기능은 가능한 범위에서 제공 |

프런트엔드에서 배너만 숨기거나 화면 선택값만 저장하는 것으로 끝내지 않습니다. 모든 선택적 태그·서버 호출·SDK 초기화 경로가 선택 상태를 확인해야 합니다. 철회 상태를 다른 탭·새 세션과 일관되게 처리하고, 다른 도메인 간 설정을 공유하면 범위·식별정보·이전 근거를 설명합니다.

환경별 테스트는 새 프로필, 이전 선택 프로필, 다중 탭, 키보드·스크린리더, 모바일 확대 화면을 포함합니다. 필수 여부는 법적·기술적 검토로 결정하며 “동의 기록 저장”만을 이유로 광고 식별자를 발급하지 않습니다.

## 양식

### 배너 문안 및 범주 승인서

| 필드 | 작성값 |
| --- | --- |
| 버전·적용 환경 | {{consent.ui_version}} / 운영 URL·앱 버전·대상 국가 |
| 배너를 제공하는 이유 | 선택 항목·적용 법역·필요한 사전 선택 근거 |
| 범주별 항목·제공자·기간 | 쿠키 대장 ID를 연결. 존재하지 않는 항목 제거 |
| 첫 화면 문안·버튼·링크 | 실제 문안, 순서, 스크린리더 이름, 정책 URL |
| 기본값·닫기·실패 처리 | 모든 선택 OFF / 닫기 동의 아님 / 오류 시 선택 전송 없음 |
| 철회 경로 | 모든 주요 화면에서 찾을 수 있는 실제 설정 위치 |
| 구현 소유자·검증자 | 담당자·검증일·안전한 증거 위치 |

### 선택 이력 기록 구조

```json
{
  "record_id": "SYNTHETIC-ONLY",
  "notice_version": "{{consent.notice_version}}",
  "purpose_version": "{{consent.purpose_version}}",
  "recorded_at": "{{consent.timestamp_with_timezone}}",
  "action": "reject_optional",
  "choices": {"analytics": false, "advertising": false},
  "surface": "{{consent.surface}}",
  "expires_at": "{{consent.record_expiry}}"
}
```

위 JSON은 필드 양식이며 실제 동의 기록이 아닙니다. 수집하지 않는 범주는 제거하고, 필요한 최소 식별자만 선택합니다. 원본 IP·브라우저 지문·원본 쿠키 값의 추가 수집을 기본값으로 하지 않습니다. 실제 기록은 개인정보 처리방침에 정한 보유기간·권한·삭제 절차에 따라 관리하며 Git에 저장하지 않습니다.

### 합성 검증 결과표

`환경 / 시작 상태 / 행동 / 허용 범주 / 실제 요청 도메인 / 생성·삭제된 키 이름 / 예상 대비 결과 / 접근성 관찰 / 검증자 / 후속 조치`를 기록합니다. 원본 네트워크 로그는 인증·식별정보 제거 후 필요한 증거만 보관합니다.

## 검증과 변경 시 재검토

- **통과:** 첫 접속·거부·닫기·저장 실패·철회에서 선택 요청이 없고, 일부 수락 시 허용 범주만 동작합니다. 버튼이 키보드·스크린리더로 구별되며 거부·허용이 동등하게 찾을 수 있습니다.
- **차단:** 태그가 배너보다 먼저 실행, 미리 선택된 선택 범주, 닫기를 동의로 해석, 거부 숨김, 철회 후 계속 전송, 실제 대장과 다른 수령자·기간입니다.
- 배너 문구·범주·제공자·도메인·태그 관리자·SDK 초기화·설정 저장 방식·철회 경로·적용 법역 변경 시 재검토합니다.
- 실제 선택 저장장치가 없으면 이 설계를 불필요하게 활성화하지 않고, 쿠키 조사 결과와 적용 제외 근거를 남깁니다. 적용 제외도 다음 배포의 신규 태그 도입까지 자동 면제하지 않습니다.
