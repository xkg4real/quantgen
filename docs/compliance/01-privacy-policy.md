## 적용 범위와 현재 상태

이 문서는 QUANTGEN의 브라우저용 Flet 화면, 선택 설치하는 PyQt6 데스크톱 화면, 고객지원 및 향후 유료 판매에서 처리하는 개인정보의 공개 방침 양식입니다. `{{...}}`는 운영자가 사실과 계약을 확인해 채울 필수값입니다. 미확정값이나 사용하지 않는 선택안이 남은 상태로 게시하지 않습니다. 문서 작성만으로 아래 기능의 동의·삭제·보안 조치가 구현되지는 않습니다.

현재 소스에서 확인한 처리와 배포 운영에서 추가 확인할 처리를 구분합니다.

| 처리 흐름 | 확인된 동작 | 공개 전 확인할 사항 |
| --- | --- | --- |
| 연결 키 | `.env` 또는 환경변수에서 읽음. KIS 앱 키·시크릿은 토큰 발급 요청에 사용 | 사용자 PC 실행인지 공동 서버 실행인지, 접근권한·키 보관 방식 |
| KIS 접속 토큰 | `~/.nextgen/kis_token.json`에 토큰·만료시각을 JSON으로 저장 | 평문 저장 보완, 타 프로그램과 경로 공유 여부, 만료 후 실제 파기 절차 |
| Upbit 자산조회 | 통화·기준통화·잔액·잠금 금액·평균 매수가를 조회하고 총수량·원화평가액을 계산. 보유 통화의 공개 시세도 요청 | Flet의 기본 조회를 이용자의 선택과 일치시키기. 네이티브 기본 미선택과 차이 존재 |
| 규칙·모의기록 | 규칙 이름·메모·개정 이력, 모의주문·판정·상태를 로컬 파일에 저장 | 실제 저장 위치, 이용자별 분리, 보유기간·삭제 방법 |
| AI 해설 | 계산 결과 및 사용자가 입력한 질문을 Anthropic API로 전송 | 계약 주체, 수탁/독립 처리 관계, 처리 국가·보유기간·재위탁·국외이전 근거 |
| AI 필터 | 알려진 private 필드명을 제외함. 자유 입력 질문의 개인정보 탐지 장치가 아님 | 전송 미리보기·민감 입력 방지, Flet와 네이티브 동의 흐름 일치 |
| 시계열 캐시 | 시장 데이터 파일을 로컬에 저장하며 기본 TTL은 6시간 | TTL은 신선도 기준이며 파일 삭제 기간이 아님. 사용자 식별정보 혼입 여부 |
| 웹 접속·고객지원·거래 | 검토한 실행 코드에서 회원가입·결제·일반 삭제 흐름을 찾지 못함 | 실서비스의 IP·접속로그·결제·지원 도구·수탁자·백업을 별도 조사 |

로컬 실행에서는 QUANTGEN 운영자가 사용자 PC의 파일을 자동 수집한다고 단정할 근거가 없습니다. 반대로 서버에서 실행하거나 지원 자료를 수령하면 처리 주체와 범위가 달라집니다. 운영자는 실제 배포 구조에 맞춰 아래 방침을 확정합니다.

### 2026-10-31 앱 UI 변경 검토

네이티브 언어·지역 설정은 QSettings의 QUANTGEN/QUANTGEN 내 ui/language·ui/locale에 저장됩니다. 교육 가이드는 동봉한 공개 과거 시계열을 로컬에서 읽고, 사용자가 저장을 선택할 때 HTML·교육 메타데이터·체크섬 ZIP을 만듭니다. 언어 선택을 외부 번역 서비스로 보내는 경로는 추가하지 않았습니다. 기존 AI·계좌조회·토큰 처리의 한계와 배포별 조사 항목은 유지합니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

C형 차트 후속 변경에서 네이티브 화면 테마(light/dark)를 같은 QSettings의 ui/theme에 저장합니다. 브라우저 앱 테마는 page 세션 상태이며, 테마 전환은 기존 분석 결과를 다시 그립니다. 새 외부 전송이나 분석 실행을 추가하지 않습니다.

**2. 보유기간 및 파기**

목적 달성, 확정한 보유기간 만료 또는 유효한 삭제 요청 시 불필요한 정보를 지체 없이 파기합니다. 법령에 따라 보존해야 하는 자료는 적용 법령·대상 항목·기간을 명시하여 별도 분리하고 원래 보존 목적 외에 이용하지 않습니다. 실제 유료 거래가 있는 경우 적용될 수 있는 전자상거래 기록 등은 법령과 사업 형태를 확인하여 {{privacy.legal_retention_schedule}}에 구체화합니다.

전자파일은 복구 위험에 맞는 삭제 절차로, 종이는 분쇄 등 적절한 방법으로 파기합니다. 캐시 만료, 화면에서 숨기기, 모의투자 초기화는 전체 개인정보 파기를 뜻하지 않습니다. 백업은 {{privacy.backup_expiry_and_restore_controls}}에 따라 만료·재삭제하며 위탁사 처리와 완료 안내는 [삭제 절차](20-deletion.md)에 따릅니다.

이용자는 관계 법령에 따라 열람, 정정·삭제, 처리정지, 동의 철회 등을 {{operator.support_email}} 또는 {{privacy.rights_request_url}}로 요청할 수 있습니다. 본인 및 적법한 대리인 확인은 필요한 최소한의 방법으로 하고 API 시크릿·비밀번호·주민등록증 전체 사본을 기본 제출물로 요구하지 않습니다. 처리기한·연장·제한 사유는 해당 권리의 법정 기준을 따르며 결과와 불복 방법을 안내합니다. 실행 기기에만 있는 자료와 운영자 보유 자료의 처리 주체를 구분하여 안내합니다.

## 검증과 변경 시 재검토

- **통과:** 실제 제공 기능별 항목·목적·근거·위치·보유기간이 완결되고, 수탁자/제3자/이전 국가가 계약과 일치하며, 권리행사·삭제·연락 창구를 합성 자료로 검증했습니다.
- **차단:** `{{...}}` 잔존, 처리 국가·사업자·보유기간 미확정, KIS 평문 토큰을 암호화 저장이라고 설명, Flet 잔고 조회를 기본 미선택이라고 설명, 캐시 TTL을 자동 파기 기간이라고 설명하는 경우입니다.
- `config.py`, API 클라이언트, AI payload·질문, 저장 경로, 로깅·지원 도구, 배포 방식, 신규 결제·회원·동의·삭제 기능, 제공자 계약이 바뀌면 재검토합니다.
- 정적 문서 검사 통과는 공개 승인·법률 검토·실제 파기 완료를 뜻하지 않습니다. 수동·운영 증거가 필요한 항목은 별도 확인 전까지 미완료입니다.
