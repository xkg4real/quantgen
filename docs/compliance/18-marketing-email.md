# 18. 광고성 이메일 동의·수신거부 정책 및 메일 양식

- 문서 ID: QG-C18

- 기준일: 2026-10-31
- 상태: review-required
- 관리 주체: (주)넥스트제너레이션
- 문의: {{operator.support_email}}

## 적용 범위와 현재 상태

사진의 18번 ‘이메일에 수신거부 링크를 추가하기’에 대응한다. QUANTGEN 운영자가 향후 직접 또는 발송업체를 통해 보내는 광고성 이메일의 동의, 표시, 철회, 발송 제외를 정의한다.

현재 코드의 알림 sink는 `email: unavailable`이며 검토 범위에서 이메일 주소 수집·광고 발송·수신거부 엔드포인트·구독자 DB를 확인하지 못했다. 아래 메일과 동의 양식은 향후 기능을 위한 서식이다. 실제 메일을 발송하지 않았고 링크나 수신거부 기능을 배포하지 않았다.

지원 답변·영수증·보안 알림·계약상 안내와 상품 홍보를 구분한다. 제목을 ‘공지’로 바꾸었다고 광고성이 사라지지 않으며, 필수 안내에 홍보를 섞는 경우 실제 내용에 따라 광고 규정을 검토한다. 광고 수신 동의 거부를 분석 기능·고객지원·계약 이행의 일괄 거절 사유로 삼지 않는 것을 설계 기준으로 정한다.

## 정책 또는 구현 기준

### 도입 전 확정할 운영 조건

1. 수신 주소의 수집 출처·처리 근거와 광고 수신 동의의 목적·항목·보유기간·거부 결과를 별도로 고지한다. 기본 체크는 해제하고 약관·개인정보 필수 동의와 묶지 않는다. 구매자·GitHub 기여자·문의자 이메일을 자동 광고 목록으로 편입하지 않는다.
2. 대한민국 대상 광고는 사전 동의와 법정 예외의 실제 요건을 검토한다. 거래관계 등의 예외는 자동 적용하지 않고 증거와 범위를 남긴다. 선택 동의 기록에는 주소 자체의 공개 대신 제한된 시스템의 식별자·동의 시각·채널·문구 버전·철회 상태를 보관한다.
3. 발송 직전에 유효 동의, 수신거부, 오류·반송·신고·삭제 요청 상태를 확인한다. 예약·분할·재시도 발송에도 최신 수신거부를 다시 적용한다. 광고 철회 후 재구독은 새 동의로 받고 과거 동의를 복구하지 않는다.
4. 적용 규정에 따른 광고 표시를 제목 앞에 두고 발신자의 법적 명칭·연락처, 쉽고 무료인 수신거부 방법을 본문에서 찾기 쉽게 제공한다. 수신거부에 로그인·결제·탈퇴·추가 개인정보 제출·설문 응답을 요구하지 않는다.
5. 서명된 무작위 토큰 등으로 수신거부 대상을 확인하며 URL에 이메일 주소나 계정정보 원문을 노출하지 않는다. 링크 미리보기·보안 스캐너의 GET 방문만으로 의도치 않은 변경이 일어나지 않게 설계하되, 광고 화면에서는 간단한 확인만으로 처리한다. 발송업체가 지원하는 표준 `List-Unsubscribe` 및 원클릭 기능은 별도로 실제 동작을 검증한다.
6. 수신거부 요청은 실제 광고 발송 제외 목록에 즉시 반영하는 것을 내부 목표로 한다. 연결된 발송업체·예약 큐·수동 CSV 목록에도 전파하고 성공·실패를 기록한다. 처리 결과 통지와 정기 동의 확인은 적용 법령·매체에 맞춰 수행한다. 대한민국의 광고 수신동의 여부 정기 확인 요구를 검토하며 동의 재확인 주기를 단순 마케팅 재동의로 오인하지 않는다.
7. 이메일 외 SMS·앱 푸시 등으로 확장하면 해당 매체의 야간 전송·표시·수신거부 규정을 별도로 검토한다. 이메일에 대한 규정과 예외를 모든 매체에 동일하게 적용하지 않는다. 기본 발송시간·대상 시간대는 `{{marketing.send_window_timezone}}`로 확정한다.
8. 발송업체·CRM·클릭 추적을 도입하면 8번 대장, 1번 방침, 필요한 국외 이전 고지와 계약을 갱신한다. 열람 추적 픽셀과 개인화 링크는 기본적으로 추가하지 않는 것을 설계 기준으로 한다. 실제 도입 시 목적·항목·동의 필요성·거부 수단을 별도 검토한다.

수신거부 기록은 재발송 방지를 위해 필요한 최소 정보와 근거를 정해 제한적으로 관리한다. 삭제 요청을 받은 사람의 주소를 마케팅 DB에서 지우고도 오래된 CSV를 다시 올려 광고를 보내는 일이 없도록, 20번 삭제 절차와 최소 차단기록의 보존 근거·기간을 함께 결정한다. 영구 보존을 기본값으로 삼지 않는다.

## 양식

### F18-01 광고성 이메일 수신 동의

> [ ] **선택: QUANTGEN 광고성 이메일 수신에 동의합니다.**  
> 발신·처리 주체: (주)넥스트제너레이션  
> 목적: {{marketing.email_purpose}}  
> 수집·이용 항목: {{marketing.email_fields}}  
> 보유·이용기간: {{marketing.consent_retention}}  
> 동의를 거부할 수 있으며, 거부해도 광고 외 기본 서비스 이용에는 영향을 주지 않습니다.  
> 철회: 메일의 ‘광고 이메일 수신거부’ 또는 {{marketing.preferences_url}} / 문의 {{operator.support_email}}  
> 고지 버전·적용일: {{marketing.notice_version_date}}

처리 근거가 광고 수신 동의와 별도로 필요한 개인정보 수집·이용 동의라면 그 요건을 갖춘 별도 항목으로 구성한다. 이 한 문장으로 제3자 제공·국외 이전·다른 매체 광고까지 동의한 것으로 처리하지 않는다.

### F18-02 발송용 이메일 본문

```text
제목: (광고) QUANTGEN {{marketing.campaign_title}}
발신자: (주)넥스트제너레이션 <{{marketing.sender_email}}>

{{marketing.campaign_body}}

발신자: (주)넥스트제너레이션
사업장 주소: 서울특별시 성북구 안암로 145
연락처: {{operator.support_email}} / {{operator.support_phone}}

수신 이유: {{marketing.consent_reason_and_date}}
광고 이메일 수신거부: {{marketing.unsubscribe_url}}
수신거부에는 로그인이나 비용이 필요하지 않습니다.
개인정보처리방침: {{public.privacy_url}}
```

수신거부 URL과 발신자 정보가 확정되지 않은 템플릿은 발송하지 않는다. 캠페인 문구의 성과·이용후기·제한 조건은 11·12번 검토도 통과해야 한다.

### F18-03 수신거부 처리 결과 화면·회신

> QUANTGEN 광고 이메일 수신거부 요청을 처리했습니다.  
> 적용 시각: {{marketing.unsubscribed_at_timezone}}  
> 대상: {{marketing.masked_address}}  
> 처리 ID: {{marketing.unsubscribe_request_id}}  
> 문의: {{operator.support_email}}  
> 계약 이행이나 보안에 필요한 비광고 안내가 있는 경우 그 목적 범위에서 발송될 수 있습니다.

실제 공급자 또는 예약 큐 전파가 실패했다면 ‘처리 완료’를 표시하지 않는다. 요청 접수 상태와 완료를 구분하고 대체 접수 방법·후속 처리 상태를 안내한다. 결과 회신에 새 광고를 포함하지 않는다.

## 검증과 변경 시 재검토

| 검사 ID | 검증 방법 | 수용 기준 |
|---|---|---|
| C18-01 | 미동의·철회·거부·만료한 합성 구독자로 발송 시험 | 광고 발송 0건. 선택 동의 기본값은 미선택이고 핵심 기능 이용이 차단되지 않음 |
| C18-02 | 로그인하지 않은 브라우저·키보드·모바일·텍스트 메일에서 거부 | 비용·계정 생성·탈퇴 없이 요청 가능하고 URL에 주소 원문 없음 |
| C18-03 | 수신거부 직후 예약·분할·재시도·CSV 재업로드 시험 | 모든 발송 경로가 최신 차단 상태를 적용하고 추가 광고 0건 |
| C18-04 | GET 프리뷰·변조 토큰·중복 요청·만료 링크·업체 장애 시험 | 다른 사람의 설정을 바꾸거나 정보를 노출하지 않음. 중복은 안전하게 처리하고 실패를 완료로 오표시하지 않음 |
| C18-05 | 실제 메일 원문·헤더·링크·렌더링 확인 | 광고 제목 표시·법적 발신자·연락처·무료 거부 링크가 확인되고 헤더 기능은 실제 설정과 일치 |
| C18-06 | 정기 확인·철회 결과 통지·삭제 절차 검토 | 적용 법령의 기한과 운영 책임이 정해져 있으며 통지에 광고가 섞이지 않음 |

현재 발송·수신거부 기능은 미구현이므로 위 검사는 아직 운영 통과 증거가 아니다. 이메일·SMS·푸시·CRM·광고 수신 동의·추적·발송업체·국외 이전·대상 국가가 추가되거나 변경되면 재검토한다.

## 근거

- 현재 이메일 상태: [`core/skills/alerts.py`](../../core/skills/alerts.py) 9–10·24행(`email: unavailable`).
- 런타임 범위: [`pyproject.toml`](../../pyproject.toml), [`ui/settings_page.py`](../../ui/settings_page.py). 검토 범위에서 광고메일 발송 및 수신거부 기능은 확인하지 못함.
- 공식 법령: [정보통신망 이용촉진 및 정보보호 등에 관한 법률](https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률) 제50조 등, [동법 시행령](https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률시행령), [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법).
- 실무 확인 창구: [KISA 불법스팸대응센터](https://spam.kisa.or.kr/). 최신 가이드·규정의 시행일과 실제 적용 검토는 [출처 대장](SOURCES.md)에 기록한다.
