## 적용 범위와 현재 상태

사진의 16번 ‘사업자 정보 추가하기’에 대응한다. QUANTGEN 앱·웹사이트·다운로드 안내·주문 화면·고객지원에서 실제 계약 상대방과 연락 방법을 이용자가 식별하도록 한다.

최신 README에는 2026-10-30 상업 출시 결정이 적혀 있다. 검토한 실행 코드에서는 통합 회원가입·결제·환불 화면이나 사업자 정보의 실제 공개값을 확인하지 못했다. 브랜드명 QUANTGEN, GitHub 소유자명, 개발자 계정은 법적 사업자 명칭을 대신하지 않는다. 아래 양식은 공개값을 확정하기 위한 초안이며, 번호·성명·주소·신고 여부를 임의로 채우지 않는다.

대한민국 전자상거래·통신판매 관련 표시 의무의 적용 범위는 실제 판매 주체, 거래방식, 면제 요건과 소비자 대상 여부로 확정한다. 저장소의 상업 출시 문구만으로 사업자등록·신고·금융업 등록이 완료되었다고 표시하지 않는다.

## 정책 또는 구현 기준

### 공개할 정보와 운영 기준

| 항목 | 표시·검증 기준 |
|---|---|
| 상호·법적 사업자명 | 실제 계약·영수증·개인정보처리방침과 동일하게 표시 |
| 대표자 | 실제 등록 자료와 대조. 개발자 별명으로 대체하지 않음 |
| 사업장 주소 | 소비자 연락·문서 송달에 사용할 실제 공개 주소. 임의 주소 사용 금지 |
| 사업자등록번호 | 실제 증빙과 대조하고 공개 전 오타 검증 |
| 통신판매업 신고 | 적용 여부, 면제 판단의 근거, 해당 시 신고번호·관할기관 기록. 미신고 상태를 신고 완료로 표시하지 않음 |
| 고객지원 | 실제 수신·응답하는 이메일·전화번호, 추가 접수 채널과 운영시간·시간대 명시. 전자상거래법 제13조가 적용되는 판매에서 전화번호를 이메일·문의 양식으로 대체하지 않음 |
| 개인정보 문의 | 1번 방침과 연결되는 실제 담당자 또는 부서·연락처 |
| 판매·결제 주체 | 운영자와 판매자·결제대행사·앱스토어가 다르면 역할과 계약 상대방 구분 |
| 상품·가격·계약 조건 | 실제 요금·부가세·갱신·해지·환불 조건으로 연결. 다른 문서의 가격과 불일치 금지 |
| 서비스 범위 | 현재 연구·분석·모의투자 기능의 범위와 실제 제공 상태를 기재. 미확정 인허가·규제 면제·수익 보장 주장 금지 |

법령상 요구되는 사업자 신원·거래조건은 이용자가 계약 전에 확인할 수 있는 위치에 제공한다. 하단에 접근 가능한 ‘사업자 정보’ 링크를 두고 주문·결제 전 화면에서도 계약 상대방과 고객지원·환불 조건을 확인하도록 한다. 앱이 작은 화면에서 연락처를 잘라내거나 복사·키보드 접근을 막지 않도록 한다. 현재 구현 완료를 선언하는 지침이 아니라 앞으로 적용할 표시 기준이다.

사업자 정보는 영업일 변경·주소 이전·명의 변경 시 실제 등록자료와 함께 갱신한다. 변경일·적용일·대상 판매 채널을 기록하고 기존 계약 상대방에 영향을 주는 변경은 필요한 통지를 수행한다. 고객의 문의 원문·주문·결제정보는 공개 사업자 정보나 Git에 포함하지 않는다.
