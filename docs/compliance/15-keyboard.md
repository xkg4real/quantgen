# 15. 키보드·포커스 접근성 기준 및 사용자 여정 검증 양식

문서 ID: QG-C15 · 버전: 1.7 · 검토일: 2026-11-02 · 상태: review-required

## 적용 범위와 현재 상태

Flet 브라우저의 워크스페이스·모바일 메뉴·대화상자와 Qt 데스크톱의 탐색·입력·탭·표·파일 저장·AI·모의 실행 화면에 적용한다. 마우스 없이 주요 기능에 도달하고 실행·취소할 수 있어야 한다.

- 두 UI는 기본 버튼·입력·콤보박스 등을 사용한다. Qt 일부 입력에는 접근성 이름과 포커스 테두리가 있다.
- `tests/desktop_acceptance.py`의 탐색 검사는 `navigate()` 호출을 사용한다. 실제 Tab 순서·키 입력·화면 읽기 검증의 대체 증거가 아니다.
- 네이티브 이행 문서는 실제 Windows 키보드·포커스·DPI 검증을 남은 과제로 명시한다. 현재 전 화면 키보드 접근성을 통과로 표시할 근거가 없다.
- 계산 중 종료 시 기다리는 동작과 작업 취소 미구현은 이행 문서에 기록되어 있다. 존재하지 않는 취소 키를 안내하지 않는다.

### 2026-10-31 앱 UI 변경 검토

새 네이티브 기술지표 차트는 방향키·Home·End와 날짜 슬라이더를 제공합니다. offscreen 키 이벤트·커서 좌표·선택 유지 검사를 했습니다. 실제 Windows의 Tab 순서·DPI·스크린리더 및 배포된 Flet 브라우저의 수동 여정은 여전히 미실행입니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

C형 후속은 넓은 화면에서 차트/해설을 나란히 두고 좁으면 아래로 이어 표시합니다. 테마·폭 변경 후 선택·커서·입력 유지와 네이티브 재시작 테마 복원을 검사했습니다. 로컬 Chromium은 마우스/휠·화면 검사이며 전체 키보드·스크린리더 여정 통과가 아닙니다.

### 2026-11-02 KIS 차트 입력·중지 여정

KIS 화면에 자산·종목·거래소/시장·주기·봉 수, 조회·5초 반복 조회·실시간 연결·중지, 지표 선택·확대·커서 제어를 추가했습니다. Qt 차트는 좌우 방향키·Home·End·봉 선택 슬라이더·접근성 이름을 제공하고 Flet은 이름/tooltip이 있는 봉 선택·표시 범위 제어와 선택 봉 값을 표시합니다. 새 검수 여정은 “조건 선택 → 조회 → REST 반복/실시간 연결 → 중지 → 과거 봉/범위/지표 선택 → 화면 이탈·복귀 → 오류/오래된 값 확인”입니다. 복귀가 자동 조회·재연결을 일으키지 않는지도 포함합니다.

합성 이벤트·직접 콜백 호출·Linux offscreen 검사와 실제 키보드 여정을 구분합니다. Windows Tab·Shift+Tab·포커스·DPI·스크린리더 및 배포 브라우저 수동 수용은 미실행입니다. Flet 실시간 중지는 WebSocket만 중지하며 REST 반복은 별도 OFF로 전환합니다. 화면 이탈의 수신 중지를 전체 백그라운드 REST 호출 취소·데이터 삭제·제공자 키 철회로 보장하지 않습니다. [Qt](../../quantgen_desktop/market_chart.py), [Flet](../../ui/market_chart_page.py), [검증 범위](../product/KIS_MARKET_CHARTS_2026-11-02.md)가 근거입니다.

이 절은 양쪽 소스·문서 검토를 통합한 사실 기록이며 `review-required`와 운영 증빙의 미확정 상태를 유지합니다. 법률 검토·공개 승인·실제 배포 검증이 아닙니다.

### 2026-11-02 Home 시세·Q-SCORE 후속 검토

기술지표 가이드를 독립 왼쪽 메뉴로 이동하고 Home 표의 행에서 상세 창·차트로 이어지는 경로를 추가합니다. 표는 행 선택과 Enter/Return 상세 열기를 제공하며 Q-SCORE 방법은 명시적인 도움말 버튼으로 열 수 있습니다. Home → 행 선택 → 상세 → 닫기·차트 이동, Q-SCORE 도움말 → 닫기, 실시간 목록 연결 → 중지 → Home 이탈·복귀를 각각 검사해야 합니다.

ToolPane의 불필요한 빈 높이 제거와 차트 위치 이동은 화면 배치 변경입니다. 직접 `navigate()` 호출이나 Qt offscreen 시험만으로 실제 Windows Tab 순서·선택 복원·DPI·스크린리더 여정을 통과로 기록하지 않습니다. 숨김 시 수신을 멈추는 것과 이미 진행 중인 모든 REST 작업 취소·개인정보 삭제를 구분합니다.

소스·문서 정합성 검토이며 기존 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. 법률 의견·공개 승인·실제 계정 연결·Windows 수동 검증이 아닙니다.

### 2026-11-02 Home compact 후속 검토

Q-SCORE 도움말을 표 헤더 안의 실제 포커스 가능 버튼으로 옮깁니다. 헤더 이동·크기 변경·가로 스크롤을 따라 위치를 갱신하고, 키보드 포커스가 오면 해당 열을 드러내도록 스크롤합니다. 클릭·Enter·Space로 소개를 열고 닫을 수 있는 경로를 유지합니다. Home의 별도 차트 바로가기를 제거하므로 종목 행 선택·상세→차트의 실제 경로를 회귀 검사합니다.

새 44px 행·22px 도움말 제어의 소스/주입 키 검사와 실제 Windows Tab·DPI·스크린리더·모바일/웹 검증은 구분합니다. 기능 소개로 바뀐 도움말을 계산식 전체가 표시되는 화면으로 안내하지 않습니다.

소스·문서 정합성 검토이며 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. [변경 근거와 20종 대조](../product/HOME_COMPACT_REVIEW_20261102.md)를 참조합니다.

### 2026-11-02 종목 정보·글꼴 확장 후속

새10열 표에서도 Q-SCORE 소개는 마지막 열의 실제 버튼입니다. 가로 스크롤 후 키보드 포커스로 해당 열을 드러내며, 가격 hover의 출처·시각·상태·재무 기준 안내는 상세 버튼이나 행 Enter로도 읽을 수 있어야 합니다. 열 인덱스 변경 후 상세→차트·소개 열기/닫기·포커스 복귀와 새 글꼴의 긴 이름/점수 표시를 재검사합니다.

글꼴등록·화면위계 변경 자체가 Windows의 모든 Tab 순서·DPI·대화상자·보조기술 검증이나 브라우저·소개사이트 배포 증거는 아닙니다.

소스·문서 정합성 검토이며 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. [최종 범위와 검증 기록](../product/HOME_COMPACT_REVIEW_20261102.md)을 참조합니다.

### 2026-11-02 네이티브 수신 체결봉·선택 지표 후속

이동평균·지수이평·볼린저·RSI·MACD는 Tab으로 이동하여 Space/Enter 또는 전체 버튼 클릭으로 켜고 끕니다. 조회 전·조회 중·체결 수신 중에도 지표 선택을 바꿀 수 있고 새로고침 뒤 선택을 유지합니다. 종목 입력 Enter는 명시적 조회 실행이며, 표시 지표 변경은 새 네트워크 구독을 만들지 않습니다.

차트 방향키·Home/End·슬라이더의 선택 봉과 OHLCV/지표 텍스트를 맞춥니다. 읽기 안내/고급 설정/중지 제어를 키보드로 제공하고, 복수 패널 뒤 슬라이더/읽기 영역이 그래프 아래에 배치되어 스크롤 끝에서 접근되는 오프스크린 회귀를 확인했습니다. 활성 입력 변경과 예약된 자동 재동기화도 중지·화면 이탈로 해제합니다. 전체 여정의 Windows 보조기술 검수·배포 인증은 별도입니다.

[실제 지원·20종 영향 검토](../product/CHART_RECEIVED_BARS_REVIEW_20261102.md)를 따릅니다. 기존 `review-required`·공개 준비 `BLOCKED`와 미확정 계약/운영 사실을 유지하며 공개 승인·실계정 검증을 뜻하지 않습니다.

### 2026-11-03 네이티브 가이드 검색 전환

기술지표 가이드의 첫 조작이 버튼 선택에서 검색으로 바뀝니다. 새 키보드 여정은 “Tab으로 검색창 → 입력하면 추천 목록 표시 → 아래쪽 방향키로 목록 이동(위쪽 방향키로 검색창 복귀) → Enter로 선택 → Esc로 목록 닫기 → Tab으로 자주 찾는 항목·차트 표시 칩(이름은 설명 다시 보기, `✕`는 차트에서 빼기)·모두 해제·설명의 차트 표시 버튼”입니다. 검색창에서 Enter는 강조된 추천(목록을 닫았으면 가장 잘 맞는 항목)을 고르고, 선택한 이름이 검색창에 남으며 다시 포커스를 받으면 전체 선택되어 새 입력으로 바뀝니다. 마우스 클릭도 같은 선택을 합니다.

Qt offscreen 합성 키 입력 시험(`QTest`)으로 위 순서를 확인했으며 실제 Windows IME 조합 입력·Tab 순서·DPI·스크린리더 여정은 미실행입니다. 한글 초성 검색은 조합이 끝난 글자에 대한 결과이며 IME 조합 중 표시를 보장하지 않습니다. [Qt 가이드](../../quantgen_desktop/indicator_guide.py), [검색 사전](../../core/education/glossary.py), [설계 기록](../product/INDICATOR_GUIDE_DESIGN.md)이 근거입니다.

## 정책 또는 구현 기준

1. 주요 기능을 Tab·Shift+Tab, 방향키, Enter·Space, Escape 등 해당 컨트롤의 표준 키로 사용할 수 있게 한다. 단축키가 없더라도 기능에 도달할 수 있어야 한다.
2. 시각적·논리적 순서에 맞게 포커스를 이동한다. 숨긴 화면·비활성 기능으로 이동하거나 포커스가 사라지지 않아야 한다. 현재 위치가 명확하고 스크롤·고정 영역에 가려지지 않아야 한다.
3. 대화상자는 열릴 때 적절한 위치에 포커스를 주고, 실행·취소 후 호출한 맥락으로 돌려준다. 모달 안에 필요한 동안 포커스를 제한하되 사용자가 정상적으로 닫고 빠져나올 수 있어야 한다.
4. 입력의 이름·단위·오류·필수 여부를 키보드와 보조기술로 알 수 있게 한다. 오류를 수정할 위치에 도달하고 기존의 유효한 입력을 보존한다.
5. 표의 행·열·선택·스크롤과 차트의 대체 표·설명에 도달할 수 있어야 한다. 직접 그린 차트의 픽셀만으로 결과를 전달하지 않는다.
6. 삭제·전송·결제 등 결과가 큰 행위는 우연한 포커스 이동으로 실행하지 않는다. 모의 엔진 Arm·활성화·긴급 정지의 의미와 실제 상태를 구분한다.
7. 사용자가 설정한 확대·DPI·고대비 환경에서 포커스와 핵심 버튼이 가려지지 않는지 확인한다. 네이티브 최소 창 크기와 지원 범위도 실제 환경에서 검증한다.
8. 단축키를 추가하면 충돌과 단일 문자 키의 오작동을 검토하고 접근 가능한 도움말에 실제 키만 기록한다.

사용자 안내 양식:

검증되지 않은 `Escape로 항상 취소`, `모든 기능을 키보드로 사용 가능` 등의 표현은 게시하지 않는다.

## 양식

여정별로 아래 표를 복제하고 실제 키 입력 순서를 기록한다. 테스트 스크립트가 함수를 직접 호출했다면 그 사실을 구분한다.

| 필드 | 작성 내용 |
|---|---|
| 여정 ID / 빌드·커밋 | QG-KEY-번호와 테스트 대상 버전 |
| OS / 브라우저·Qt / 보조기술 버전 | Windows·브라우저·NVDA 등 실제 환경 |
| 창 크기 / DPI·확대 / 테마 | 재현 가능한 수치와 모드 |
| 시작 위치 / 사전 조건 | 첫 실행·특정 화면·모의 엔진 정지 등 |
| 사용 키 / 단계별 예상 포커스 | 실제 Tab·방향키·Enter·Escape 순서 |
| 실제 포커스 / 읽힌 이름·상태 | 이름·역할·값·오류가 전달되는지 |
| 완료·취소 후 위치 | 결과·오류·대화상자 종료 후 복귀 위치 |
| 시간 제한·진행 상태·작업 취소 | 실제 지원·제약·사용자 고지 |
| 판정 / 증거 / 테스트 ID | 통과·실패·미실행, 영상·기록·자동 테스트 |
| 결함 / 담당 / 수정·재검토일 | 문제 컨트롤·경로·재현 단계 |

필수 여정은 다음과 같다.

| 여정 | 완료 기준 |
|---|---|
| 시작 → 모든 워크스페이스 → 작은 화면 메뉴 | 모든 탐색·닫기·복귀에 접근 |
| 분석 입력 → 오류 수정 → 실행 → 결과 확인 | 이름·단위·오류·진행·결과를 이해 |
| 결과 표 → JSON·보고서 저장 → 파일창 취소 | 결과와 취소 후 포커스 복귀 |
| 규칙 초안 → 확인 → 활성화 → 모의 엔진 정지 | 단계·상태를 구분하고 키보드로 제어 |
| AI 미리보기 → 동의·거절 → 전송 | 비동의 시 전송되지 않고 결과·오류 확인 |
| 테마 전환·확대·DPI 변경 | 포커스와 주요 동작이 계속 보임 |

## 검증과 변경 시 재검토

- **통과:** 명시한 환경에서 필수 여정 전체를 마우스 없이 완료·취소하고, 키보드 함정·누락 기능·가려진 포커스가 없다. 화면 읽기 검증은 별도 실제 결과를 남긴다.
- **실패:** 필요한 제어에 도달할 수 없거나, 함정·사라진 포커스·잘못된 자동 실행·사용 불가능한 오류 수정·취소 복귀 문제가 있다.
- **미실행:** 실제 키 입력을 사용하지 않았거나 지원 환경의 증거가 없다. Qt offscreen 렌더링·소스 속성 검사만으로 Windows 수동 수용을 통과시키지 않는다.
- 화면 구조·모달·테이블·폼·작업 큐·UI 프레임워크·단축키 변경 시 해당 여정과 앞뒤 포커스 이동을 재검증한다. 자동 테스트는 가능한 여정을 실제 키 이벤트로 수행하고, 수동 수용 기록과 구분한다.
