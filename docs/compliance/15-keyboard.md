# 15. 키보드·포커스 접근성 기준 및 사용자 여정 검증 양식

문서 ID: QG-C15 · 버전: 1.13 · 검토일: 2026-11-06 · 상태: review-required

## 적용 범위와 현재 상태

Flet 브라우저의 워크스페이스·모바일 메뉴·대화상자와 Qt 데스크톱의 탐색·입력·탭·표·파일 저장·AI·모의 실행 화면에 적용한다. 마우스 없이 주요 기능에 도달하고 실행·취소할 수 있어야 한다.

- 두 UI는 기본 버튼·입력·콤보박스 등을 사용한다. Qt 일부 입력에는 접근성 이름과 포커스 테두리가 있다.
- `tests/desktop_acceptance.py`의 탐색 검사는 `navigate()` 호출을 사용한다. 실제 Tab 순서·키 입력·화면 읽기 검증의 대체 증거가 아니다.
- 네이티브 이행 문서는 실제 Windows 키보드·포커스·DPI 검증을 남은 과제로 명시한다. 현재 전 화면 키보드 접근성을 통과로 표시할 근거가 없다.
- 계산 중 종료 시 기다리는 동작과 작업 취소 미구현은 이행 문서에 기록되어 있다. 존재하지 않는 취소 키를 안내하지 않는다.

새 네이티브 기술지표 차트는 방향키·Home·End와 날짜 슬라이더를 제공합니다. offscreen 키 이벤트·커서 좌표·선택 유지 검사를 했습니다. 실제 Windows의 Tab 순서·DPI·스크린리더 및 배포된 Flet 브라우저의 수동 여정은 여전히 미실행입니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

C형 후속은 넓은 화면에서 차트/해설을 나란히 두고 좁으면 아래로 이어 표시합니다. 테마·폭 변경 후 선택·커서·입력 유지와 네이티브 재시작 테마 복원을 검사했습니다. 로컬 Chromium은 마우스/휠·화면 검사이며 전체 키보드·스크린리더 여정 통과가 아닙니다.

### 2026-11-02 KIS 차트 입력·중지 여정

KIS 화면에 자산·종목·거래소/시장·주기·봉 수, 조회·5초 반복 조회·실시간 연결·중지, 지표 선택·확대·커서 제어를 추가했습니다. Qt 차트는 좌우 방향키·Home·End·봉 선택 슬라이더·접근성 이름을 제공하고 Flet은 이름/tooltip이 있는 봉 선택·표시 범위 제어와 선택 봉 값을 표시합니다. 새 검수 여정은 “조건 선택 → 조회 → REST 반복/실시간 연결 → 중지 → 과거 봉/범위/지표 선택 → 화면 이탈·복귀 → 오류/오래된 값 확인”입니다. 복귀가 자동 조회·재연결을 일으키지 않는지도 포함합니다.

합성 이벤트·직접 콜백 호출·Linux offscreen 검사와 실제 키보드 여정을 구분합니다. Windows Tab·Shift+Tab·포커스·DPI·스크린리더 및 배포 브라우저 수동 수용은 미실행입니다. Flet 실시간 중지는 WebSocket만 중지하며 REST 반복은 별도 OFF로 전환합니다. 화면 이탈의 수신 중지를 전체 백그라운드 REST 호출 취소·데이터 삭제·제공자 키 철회로 보장하지 않습니다. [Qt](../../quantgen_desktop/market_chart.py), [Flet](../../ui/market_chart_page.py), [검증 범위](../product/KIS_MARKET_CHARTS_2026-11-02.md)가 근거입니다.

이 절은 양쪽 소스·문서 검토를 통합한 사실 기록이며 `review-required`와 운영 증빙의 미확정 상태를 유지합니다. 법률 검토·공개 승인·실제 배포 검증이 아닙니다.

### 2026-11-03 네이티브 가이드 검색 전환

기술지표 가이드의 첫 조작이 버튼 선택에서 검색으로 바뀝니다. 새 키보드 여정은 “Tab으로 검색창 → 입력하면 추천 목록 표시 → 아래쪽 방향키로 목록 이동(위쪽 방향키로 검색창 복귀) → Enter로 선택 → Esc로 목록 닫기 → Tab으로 자주 찾는 항목·차트 표시 칩(이름은 설명 다시 보기, `×`는 차트에서 빼기)·모두 해제·설명의 차트 표시 버튼”입니다. 검색창에서 Enter는 강조된 추천(목록을 닫았으면 가장 잘 맞는 항목)을 고르고, 선택한 이름이 검색창에 남으며 다시 포커스를 받으면 전체 선택되어 새 입력으로 바뀝니다. 마우스 클릭도 같은 선택을 합니다.

Qt offscreen 합성 키 입력 시험(`QTest`)으로 위 순서를 확인했으며 실제 Windows IME 조합 입력·Tab 순서·DPI·스크린리더 여정은 미실행입니다. 한글 초성 검색은 조합이 끝난 글자에 대한 결과이며 IME 조합 중 표시를 보장하지 않습니다. [Qt 가이드](../../quantgen_desktop/indicator_guide.py), [검색 사전](../../core/education/glossary.py), [설계 기록](../product/INDICATOR_GUIDE_DESIGN.md)이 근거입니다.

### 2026-11-03 해외 종목명 검색·휠 확대

> 2026-11-04 대체: 종목 검색은 시장 검색창의 코드·이름 목록으로 바뀌었습니다(아래 절). 차트 휠·`+`/`-` 확대는 그대로입니다.

> 2026-11-11 대체: 휠은 더 이상 차트를 확대·축소하거나 옮기지 않습니다. 종목 상세 화면의 차트 위에서는 휠이 아무 동작도 하지 않고(페이지도 움직이지 않음), 그 밖의 곳에서는 페이지로 넘어갑니다. 확대·축소는 차트 포커스의 `+`·`-` 키와 기간 막대의 버튼입니다. 아래 “2026-11-11 왼쪽 메뉴·연구 Home·순위 목록·종목 상세 화면” 절을 참조합니다.

해외증권 탭의 종목 입력은 검색창이 됩니다. 입력하면 아래에 최대 8개 결과(이름 · 코드 · 거래소)가 나오고, 아래쪽 방향키로 목록 이동·위쪽 방향키로 복귀·Enter로 선택·Esc로 닫습니다. 고르면 조회와 지원되는 체결 연결이 버튼 없이 시작됩니다. 거래소·조회 봉 수·표시 봉 수 입력은 화면에서 없어졌고 국내파생상품 탭에서만 “시장 구분” 선택을 보입니다. 차트 위 마우스 휠로 확대·축소하며, 차트에 포커스가 있으면 `+`·`-` 키로도 같은 동작을 합니다. 더 확대·축소할 수 없으면 휠은 페이지 스크롤로 넘어갑니다. Qt offscreen 합성 입력으로 확인했으며 실제 Windows 휠 감도·고해상도 터치패드·스크린리더는 미실행입니다.

### 2026-11-03 마우스 휠과 선택 상자

포커스가 없는 선택 상자·숫자 상자와 탭은 마우스 휠로 값이 바뀌지 않고, 휠은 그 방향으로 움직일 수 있는 가장 가까운 스크롤 영역으로 전달됩니다(소유자 UI-3). 움직일 영역이 없으면 휠 입력은 무시됩니다. 선택 상자·숫자 상자는 휠로 포커스를 받지 않도록 클릭·Tab 포커스(StrongFocus)로 설정했고, 클릭이나 Tab으로 포커스를 준 상자는 기존처럼 휠로 바뀝니다. 탭은 휠로 바뀌지 않습니다. 키보드 조작은 바뀌지 않습니다. [휠 처리](../../quantgen_desktop/wheel_guard.py)와 [시험](../../tests/desktop_operation_fixes_acceptance.py)이 근거입니다. Qt offscreen 합성 휠 이벤트와 포커스 정책 검사로 확인했으며, 실제 Windows 휠·터치패드는 미실행입니다.

### 2026-11-04 시장 관심종목·한 종목 화면·분석 도구

> 2026-11-11 대체: 관심종목 카드는 연구 Home으로 옮겼고 키 조작(Enter·Space로 열기, Tab으로 `×`)은 그대로입니다. 시장 화면의 검색창 아래에는 순위 목록이 있습니다. 한 종목 화면은 종목 상세 화면으로 바뀌어 뒤로 버튼은 “← 실시간 차트”이고, 키 조작은 아래 “2026-11-11 왼쪽 메뉴·연구 Home·순위 목록·종목 상세 화면” 절을 따릅니다.

관심종목 카드는 포커스를 받고 Enter·Space로 엽니다. 카드에서 Tab을 누르면 그 카드의 `×` 버튼으로 가고 Space로 관심종목에서 뺍니다. 한 종목 화면은 “← 관심종목” 버튼으로 돌아가고 ☆·★ 버튼으로 넣고 뺍니다. 분석 도구 화면의 10개 도구 버튼은 Space로 고르며 방향키로 이웃 버튼에 포커스가 옮겨 갑니다. Qt offscreen 합성 키 입력으로 카드 Enter·Space 열기, 카드에서 Tab으로 `×` 버튼 도달, 검색 목록의 아래쪽 방향키+Enter 열기와 Esc 닫기, 도구 버튼 Space 선택·오른쪽 방향키 이동을 일회성으로 확인했습니다. 이 확인은 시험 파일에 들어 있지 않습니다. 화면 전체의 Tab 순서, 실제 Windows Tab 순서·IME 조합 입력·스크린리더는 미실행입니다. [변경 사실](FACTS.md#markets-watchlist-2026-11-04)을 따릅니다.

### 2026-11-06 A1 표시 용어 검수 범위

한영 전환 뒤 메뉴·항목·표 머리글과 실행/연결/공식 판정의 이름이 실제 값과 맞는지 점검합니다. 지정 Flet 셀의 번역 제외 메타데이터와 Qt의 표시 역할은 번역 범위를 정하는 장치이며, 보조기술의 머리글 연결·이름·현재값 발화를 입증하지 않습니다. 공식 판정의 원래 코드 병기와 상태 tooltip 보존도 모든 tooltip에 키보드로 접근할 수 있다는 증거가 아닙니다.

새 문구 길이에서 잘림·가로 스크롤·초점 가림이 없는지, 언어 전환 후에도 실제 Tab·방향키·Enter 여정이 유지되는지 Windows DPI·스크린리더와 배포 Flet 브라우저에서 확인해야 합니다. 이번 용어 변경은 새 키보드 도움말·단축키를 구현하지 않으며 A3 읽기 도움말은 별도입니다. [A1 소스 범위](FACTS.md#a1-terminology-2026-11-06)와 실제 환경 수동 검증 `NOT_RUN`을 구분합니다.

### 2026-11-06 A3 알아보기·결과 배치 여정

네이티브 F1 또는 표/선택한 라벨의 문맥 메뉴에서 “알아보기”를 엽니다. 검색 후보에서 용어를 명시적으로 선택해 정의를 읽고 Esc·닫기로 나옵니다. 원래 위젯이 남아 있고 표시·활성 상태이면 포커스를 돌려주며 표의 원래 셀도 복원합니다. 페이지·도구 전환, 결과 초기화·교체, 원본 삭제 시 인용을 비워 오래된 결과를 유지하지 않습니다. 문맥 메뉴의 복사·모두 선택도 구분해 확인합니다.

MC 작은 결과표와 Bonds 두 결과 패널의 모든 행·가로 스크롤·외부 페이지 스크롤, 820px 내용 폭 재배치, F1→검색→선택→Esc/닫기→원래 셀, 상세 정보 펼침/접기와 언어·테마·DPI 변경을 검수합니다. [기록된 합성 키·레이아웃 검사](../product/A3_READING_LAYOUT_2026-11-06.md)는 실제 Windows Tab 순서·IME·스크린리더·배포 Flet 브라우저 수용을 대신하지 않습니다. 전체 수동 수용은 `NOT_RUN`을 유지합니다.

## 정책 또는 구현 기준

1. 주요 기능을 Tab·Shift+Tab, 방향키, Enter·Space, Escape 등 해당 컨트롤의 표준 키로 사용할 수 있게 한다. 단축키가 없더라도 기능에 도달할 수 있어야 한다.
2. 시각적·논리적 순서에 맞게 포커스를 이동한다. 숨긴 화면·비활성 기능으로 이동하거나 포커스가 사라지지 않아야 한다. 현재 위치가 명확하고 스크롤·고정 영역에 가려지지 않아야 한다.
3. 대화상자는 열릴 때 적절한 위치에 포커스를 주고, 실행·취소 후 호출한 맥락으로 돌려준다. 모달 안에 필요한 동안 포커스를 제한하되 사용자가 정상적으로 닫고 빠져나올 수 있어야 한다.
4. 입력의 이름·단위·오류·필수 여부를 키보드와 보조기술로 알 수 있게 한다. 오류를 수정할 위치에 도달하고 기존의 유효한 입력을 보존한다.
5. 표의 행·열·선택·스크롤과 차트의 대체 표·설명에 도달할 수 있어야 한다. 직접 그린 차트의 픽셀만으로 결과를 전달하지 않는다.
6. 삭제·전송·결제 등 결과가 큰 행위는 우연한 포커스 이동으로 실행하지 않는다. 모의 엔진 Arm·활성화·긴급 정지의 의미와 실제 상태를 구분한다.
7. 사용자가 설정한 확대·DPI·고대비 환경에서 포커스와 핵심 버튼이 가려지지 않는지 확인한다. 네이티브 최소 창 크기와 지원 범위도 실제 환경에서 검증한다.
8. 단축키를 추가하면 충돌과 단일 문자 키의 오작동을 검토하고 접근 가능한 도움말에 실제 키만 기록한다.

## 검증과 변경 시 재검토

- **통과:** 명시한 환경에서 필수 여정 전체를 마우스 없이 완료·취소하고, 키보드 함정·누락 기능·가려진 포커스가 없다. 화면 읽기 검증은 별도 실제 결과를 남긴다.
- **실패:** 필요한 제어에 도달할 수 없거나, 함정·사라진 포커스·잘못된 자동 실행·사용 불가능한 오류 수정·취소 복귀 문제가 있다.
- **미실행:** 실제 키 입력을 사용하지 않았거나 지원 환경의 증거가 없다. Qt offscreen 렌더링·소스 속성 검사만으로 Windows 수동 수용을 통과시키지 않는다.
- 화면 구조·모달·테이블·폼·작업 큐·UI 프레임워크·단축키 변경 시 해당 여정과 앞뒤 포커스 이동을 재검증한다. 자동 테스트는 가능한 여정을 실제 키 이벤트로 수행하고, 수동 수용 기록과 구분한다.

### 2026-11-11 왼쪽 메뉴·연구 Home·순위 목록·종목 상세 화면(UI-D7·UI-D8)

> 2026-11-11 UI-D10 대체: "왼쪽 메뉴" 항목의 하위 항목(거래대금·거래량·급상승·급하락·시가총액·종목 검색)과 "종목 검색"의 포커스 이동, 1000×700에서 메뉴가 스크롤된다는 문장, "시장 순위 목록" 항목의 시장 버튼 줄(국내 전체·코스피·코스닥·미국)과 두 남은 문제(분류 칩 줄의 보이지 않는 포커스, 바탕뿐인 행 포커스)는 아래 “2026-11-11 시장 페이지” 절이 대체합니다(구현 커밋이 이 절에 더했던 시장 페이지 항목은 그 절로 옮김). 메뉴 키, Home, 종목 상세 화면의 키 조작은 그대로입니다.

- **왼쪽 메뉴:** Ctrl+B(창 어디서나)와 패널 아이콘 버튼으로 메뉴를 48px 띠로 접고 펼칩니다. 접힘 여부는 저장되어 다음 실행에 복원됩니다. 메뉴에 키보드 포커스가 있을 때 접거나 펼치면 포커스는 펼치기·접기 버튼으로 옮겨 가고, 현재 페이지와 스크롤 위치는 그대로입니다. 접힌 띠에는 펼치기 버튼(모의 엔진 실행 중이면 중지 버튼도)만 있으므로 메뉴 항목으로 가려면 먼저 펼쳐야 합니다. 메뉴 버튼 사이는 ↑/↓, 처음·끝은 Home/End, 실행은 Return/Enter(Space는 Qt 버튼 기본 동작)이며 Tab으로도 모두 닿습니다. "시장"을 고르면 바로 아래에 하위 항목(거래대금·거래량·급상승·급하락·시가총액·종목 검색)이 나타나 같은 키로 이동하고, 고르면 시장 화면의 그 목록으로 가며 "종목 검색"은 검색 칸에 포커스를 줍니다. 포커스 테두리는 키보드로 옮겼을 때만 보이고 마우스 클릭 뒤에는 남지 않습니다. 1000×700 창에서는 메뉴가 그 안에서 스크롤되고 포커스 항목을 보이게 따라갑니다([앱](../../quantgen_desktop/app.py) `set_sidebar_collapsed`, [메뉴 키](../../quantgen_desktop/shell_rail.py) `RailKeys`).
- **연구 Home:** 시장 카드는 포커스를 받고 Enter·Space로 고릅니다. 카드에서 ←/→는 이웃 카드를, Home/End는 처음·끝 카드를 고르며 포커스와 줄이 함께 넘어가고, 고른 시장의 차트 이력을 읽기 시작합니다(자동 갱신이 켜진 창). 이전·다음·기간(영어 창 1M·3M·6M·1Y, 한국어 창 1개월·3개월·6개월·1년)·새로고침·종목 추가 버튼의 포커스 표시는 1px `accent` 테두리입니다. "전체 시세 표" 접기 버튼(QToolButton)은 Tab으로 포커스를 받고 Space로 펼치며, 포커스 동안 Home의 다른 버튼과 같은 1px `accent` 선이 보입니다(2026-11-11 해결: 이전에는 자체 스타일이 테두리를 없애고 포커스 규칙이 없어 포커스 표시가 없었음; [Home](../../quantgen_desktop/home_view.py) `fold_stylesheet`·`QuotesFold`, [시험](../../tests/desktop_home_markets_home_acceptance.py) `test_quotes_fold_toggle_shows_a_focus_line_without_changing_its_look`). 접혀 있는 동안 그 안의 시세 표와 Q-SCORE `?` 도움말에는 Tab이 닿지 않습니다. 큰 차트는 포커스를 받지 않아 날짜별 값은 마우스로만 읽습니다([Home](../../quantgen_desktop/home_view.py)). 관심종목 카드의 키 조작은 그대로입니다.
- **시장 순위 목록:** 새로고침·업종 선택은 Tab으로 가는 일반 버튼과 선택 상자이고 포커스 표시는 2px `accent` 테두리입니다. 분류 칩 줄(거래대금·거래량·급상승·급하락·시가총액)과 시장 버튼 줄(국내 전체·코스피·코스닥·미국)은 각각 하나만 고르는 단추 묶음(배타 `QButtonGroup`)이라, Tab은 각 줄의 선택된 단추에만 멈추고(새로고침 → 선택된 칩 → 선택된 시장 버튼 → 업종 선택) 화살표 키가 포커스를 옮기면서 그 단추를 고릅니다. 선택되지 않은 칩·시장 버튼은 Tab으로 가지 않습니다([시험](../../tests/desktop_home_markets_markets_acceptance.py) `test_chips_and_market_buttons_are_radio_groups_for_the_keyboard`; 2026-11-11 검토 정정: 이전 문장은 넷 모두 Tab으로 가는 일반 버튼이고 선택되지 않은 칩의 포커스 표시가 2px 테두리라고 적었으나, 그 표시는 키보드로는 나타나지 않음). 시장 버튼은 2026-11-11 해결: 목록 스타일이 창의 포커스 규칙을 덮어 포커스 표시가 없던 것을 목록 스타일의 자체 `:focus` 규칙으로 고쳤습니다(포커스가 없을 때의 모양은 그대로; [목록 스타일](../../quantgen_desktop/market_rankings.py) `board_stylesheet`, [시험](../../tests/desktop_home_markets_markets_acceptance.py) `test_market_buttons_show_the_windows_focus_ring_without_changing_their_look`); 키보드로 닿는 선택된 시장 버튼은 포커스 때 밑줄이 네 변의 테두리로 넓어집니다. 분류 칩 줄은 키보드 포커스가 전혀 보이지 않습니다: 키보드가 닿는 칩은 선택된 칩뿐이고 그 2px `accent` 테두리는 같은 `accent` 바탕 위라 보이지 않습니다(남은 문제; [14번](14-contrast.md)). 순위 행은 Tab으로 포커스를 받고 Enter·Space로 종목 상세 화면을 엽니다. 행의 포커스 표시는 hover와 같은 옅은 바탕뿐입니다([14번](14-contrast.md)). 국내·미국 시가총액의 출처·상장주식수와 국내 값의 대조 근거·쓰지 않은 이유는 그 칸의 tooltip에만 있어 키보드로 읽는 경로가 없고, 계산 방식과 대조 규칙의 요지는 열 머리와 목록 아래 글자로 보입니다([목록](../../quantgen_desktop/market_rankings.py) `RankRow`·`_footnote`).
> 2026-11-12 후속(소유자 R-D12-1·2): 차트 확대·축소는 차트 위 **Ctrl+마우스 휠**(휠 위로 확대, 마우스 아래 봉 기준)과 터치패드 핀치이고, `+`·`-`·`=`·`_` 키와 기간 막대의 −·+ 버튼은 없앴습니다. 차트를 **왼쪽 버튼으로 끌면** 좌우로 옮겨지고(잡은 봉이 포인터를 따라감, 처음·최신 봉에서 멈춤, 끌지 않은 클릭은 그대로 봉 선택), ←/→·Shift+←/→·Home/End·`0`·기간 버튼은 그대로입니다. 휠만으로는 여전히 아무 동작도 하지 않습니다. 안내 문구는 "← → · 끌기 이동 · Ctrl+휠 확대·축소"입니다. 키보드만으로는 기간 버튼·Home/End·`0`으로 보이는 범위를 바꿀 수 있고, 연속 확대·축소는 마우스(Ctrl+휠)나 터치패드가 필요합니다([차트](../../quantgen_desktop/market_chart.py) `MarketChartPane.zoom_at`·`drag_to`·`MarketChartSvg.wheelEvent`, [시험](../../tests/desktop_stock_detail_acceptance.py)).

- **종목 상세 화면:** 종목을 열거나 기간·이동·기본 보기 버튼을 누르면 포커스가 차트로 갑니다. 차트에 포커스가 있을 때 ←/→는 선택 봉을 옮기고(창 끝에서는 화면이 밀림), Shift+←/→는 10봉씩, Home은 첫 봉, End는 최신 봉, `+`/`-`는 확대·축소, `0`은 기간 기본 보기입니다. Shift+F는 크게 보기(왼쪽 메뉴 접기와 오른쪽 열 숨기기, 메뉴 접힘은 저장하지 않고 끝내면 되돌림)를 켜고 끄며, Esc는 크게 보기를 끝내거나 좁은 창에서 겹쳐 연 오른쪽 열을 닫습니다. 같은 동작은 도구 막대의 ⤢ 버튼과 기간 막대의 ◀·▶·−·+·기본 보기 버튼으로도 할 수 있고, 차트 아래에 "← → 이동 · + − 확대" 안내가 있습니다. 차트 위 마우스 휠은 아무 동작도 하지 않고, 종목을 연 동안 시장 페이지는 휠·키로 스크롤되지 않으며 오른쪽 열만 스크롤됩니다([상세 화면](../../quantgen_desktop/stock_detail.py) `chart_key`·`PageLock`, [차트](../../quantgen_desktop/market_chart.py) `chart_key`·`wheelEvent`). 차트 자체에는 포커스 테두리가 없어 포커스는 선택 봉 표시와 OHLC 줄의 변화로만 알 수 있습니다. 오른쪽 열의 접는 머리는 Space·Enter로 접고 펴고, "지금 이 차트" 줄은 Enter·Space로 그 지표를 켜며(지표가 이미 켜진 줄은 포커스를 받아도 아무 동작을 하지 않음), 관심종목·최근 본 종목 행은 Enter·Space로 엽니다. 지표 선택은 검색 칸, 분류 머리(Space·Enter로 접기), 행(Space·Enter로 켜고 끔), 행 안의 ⓘ·스위치(Tab)로 조작합니다([지표 선택](../../quantgen_desktop/indicator_picker.py), [오른쪽 열](../../quantgen_desktop/stock_detail_side.py)). 접는 머리·지표 행의 포커스 표시도 옅은 바탕뿐입니다. 아래 패널 머리·지표 행의 ⓘ·×, '최신 봉으로' 버튼, "지금 이 차트" 줄, 관심종목·최근 본 종목 행은 Tab으로 포커스를 받지만 보이는 포커스 표시가 없습니다(남은 문제, [14번](14-contrast.md)).

### 2026-11-11 시장 페이지: 국내 주식·미국 주식·코인(UI-D10)

- **왼쪽 메뉴:** "시장"의 하위 항목은 국내 주식·미국 주식·코인이며 키 조작(↑/↓, Home/End, Return·Enter, Tab)은 위 절과 같습니다. 고르면 그 시장 페이지가 보이고 강조가 따라오며, 종목 화면을 연 동안에는 그 아래 목록의 시장(주식이면 그 종목의 시장)을 가리킵니다. "종목 검색" 항목은 없어졌고, Home의 "종목 추가"는 마지막에 본 주식 시장(국내 또는 미국) 페이지의 검색 칸에 포커스를 줍니다(코인 페이지에 있었으면 그 주식 시장으로 바꿈; [검토 시험](../../tests/desktop_home_markets_markets_acceptance.py) `test_home_add_and_enter_reach_stocks_from_the_coin_page`). 항목이 줄어 1000×700 창에서 메뉴는 필요할 때만 스크롤합니다([메뉴 시험](../../tests/desktop_home_markets_shell_acceptance.py) `test_short_window_scrolls_the_rail_to_the_focused_item`).
- **Tab 순서와 단추 묶음:** 각 시장 페이지에는 페이지 제목·설명 문단·별도 검색 칸이 없습니다. Tab은 머리 줄 검색 칸(그 시장 안에서 찾기) → 새로고침 → 선택된 분류 칩 → 선택된 하위 시장 단추(전체·코스피·코스닥, 미국은 전체·나스닥·NYSE) → 업종 선택 → "조건" 순입니다. 분류 칩 줄과 하위 시장 줄은 하나만 고르는 단추 묶음이라 Tab은 선택된 단추에만 멈추고 ←/→가 포커스를 옮기며 고릅니다. 코인 페이지에는 하위 시장·업종이 없고 칩은 거래대금·급상승·급하락뿐입니다(거래량·시가총액은 비활성 칩이 아니라 빠져 있음; [시험](../../tests/desktop_home_markets_markets_acceptance.py) `test_chips_and_market_buttons_are_radio_groups_for_the_keyboard`·`test_coin_page_has_no_dead_controls_and_says_coin`).
