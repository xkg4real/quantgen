## 적용 범위와 현재 상태

QUANTGEN의 제품 화면, README, 소개·판매 자료, 연구 보고서, AI 출력에 쓰이는 기능·정확도·수익·검증·기관 관련 주장에 적용한다.

- 현행 README는 연구·분석·모의투자와 실주문 경로 부재를 설명한다. 상업 출시 결정은 팀의 판단이며 정부·금융투자협회의 승인·인증·보증이 아니라고 구분한다.
- README의 기록된 QA 집계는 새 테스트 실행이나 전체 출시 적합성 판정이 아니다. `NOT_RUN`을 `PASS`와 합치지 않는다.
- UI의 P5–P95는 시뮬레이션 분포의 중앙 90% 구간이다. 95% 신뢰구간·손실 방지·수익 보장으로 표현하지 않는다.
- 옵션 호가 검사는 실제 수행 분모와 `NOT_RUN`·`PARTIAL`을 함께 표시한다. 미검사 자료의 null이나 부분 검사에서의 0을 전체 무위반·실거래 차익 검증·공식 연구 통과로 해석하지 않는다.
- 스왑션 주모델 가격·Greeks의 정상 계산과 보조 모델 변동성 환산의 `UNAVAILABLE`은 별도 상태다. 보조 결과를 0으로 만들거나 주가격 전체가 실패했다고 표시하지 않는다.
- 네이티브 이행 문서에는 이전 개인 사용 정책을 가리키는 문장이 남아 있다. 상업 출시 결정과의 불일치로 기록하고 현재 정책을 확정한 뒤 문서 간 표현을 정리해야 한다.

### 2026-11-02 KIS 차트 주장 범위

[구현 범위](../product/KIS_MARKET_CHARTS_2026-11-02.md)는 REST 단일·5초 반복 조회와 WebSocket 체결 수신을 구분합니다. `SUBSCRIBED`는 구독 승인, `LIVE`는 유효 체결 수신이며 연결·heartbeat만으로 새 시세를 주장하지 않습니다. 미국 무료 Nasdaq 피드는 통합시세와 제공 범위가 다를 수 있고 아시아 무료 피드는 15분 지연으로 안내합니다. 채권은 일봉, 해외선물은 검증된 master 배율의 일·주·월봉을 지원하며 해외옵션·야간 WebSocket 등 미지원 조합을 구분합니다. 모든 자산·주기의 무지연·완전한 실시간 지원을 주장하지 않습니다.

형성 중 봉·지표, 워밍업 부족, 부분 이력·미확정 거래량, 수신 공백 후 OHLC 불완전, 일부 국내 체결의 KST 수신일 추정을 유지합니다. 지표는 조회 이력의 계산 결과이며 수익·예측 능력 검증이 아닙니다. PR #56·PR #57 및 통합 작업 트리의 합성 소켓·시세/Linux offscreen 검사는 실제 KIS 계정·권리·Windows 수동 수용·AWS 배포·공식 연구 판정·규제 승인 증거가 아닙니다. [변경 사실](FACTS.md#kis-market-integration-2026-11-02)과 연결합니다.

이 절은 양쪽 소스·문서 검토를 통합한 사실 기록이며 `review-required`와 운영 증빙의 미확정 상태를 유지합니다. 법률 검토·공개 승인·실제 배포 검증이 아닙니다.

### 2026-11-02 M3-N08 금리 재평가의 일관성 주장

`7e8d7442`는 `horizon_pv_distribution`에 전달한 계산 파라미터를 조용히 무시하던 동작을 바꿉니다. `model`·`kappa`·`theta`·`sigma`·`r0`가 `sim.params`와 정확히 같지 않으면 곡선/경로 재평가 전에 `ValueError`로 다른 필드명을 알립니다. 설명용 `note`는 비교에서 제외하며 작은 수치 변경도 새 시뮬레이션이 필요합니다. 기존 경로를 다른 파라미터로 재평가하는 기능을 추가한 것은 아닙니다. Flet와 네이티브 서비스는 Hull–White의 기존 `r0` 정규화까지 반영한 최종 파라미터를 전달합니다.

정상 일치 입력의 모형·경로 선택·가격·손실 기준·분위수/CVaR·0 하한과 금리/현금흐름 규약은 유지합니다. 파라미터 일치만으로 입력 곡선·공급사 자료·모형 가정의 적합성이나 성과를 검증했다고 설명하지 않습니다. [기록된 검증](../product/RATES_REVALUATION_PARAMS_2026-11-02.md)은 합성 10개 검사와 이전 `0169c98` 대비 terminal 배열 12개·PV 배열 24개·요약 값/설명 144개 정확 일치에 한정합니다. 기존 공식 판정·연구 기준·실행 승인·실제 Windows 검증 조건, 공개 준비 `BLOCKED`와 `review-required`는 유지합니다.

### 2026-11-02 Home 시세·Q-SCORE 후속 검토

Q-SCORE v0.1은 기존 기술신호 합성값을 0–100으로 환산한 값 70%, 과거 최대 낙폭 점수 15%, 과거 95% CVaR 점수 15%를 더하는 새 표시용 합성 점수입니다. 낙폭 0–40%와 일간 CVaR 0–8%를 각각 100–0으로 환산·제한하며 20·40·60·80점을 별 개수의 경계로 사용합니다. 비중·경계는 초기 설계값으로 예측력이나 최적성이 검증된 것이 아닙니다. 기업가치·투자 등급·수익 확률·고객 후기·모든 엔진의 평가로 표현하지 않습니다.

입력 검사를 통과한 KIS 국내주식 수정 일별 이력 최소 200개·최대 최근 252개를 사용하고 유효한 새 체결은 당일 잠정 종가에 반영합니다. 부족·오래됨·부적절한 수정 기준·중복/역순·미확인 시각을 정상 실시간 점수로 바꾸지 않습니다. 별점 표시 성공과 실제 계정 수신, Windows 화면, 공급자 권리, 독립 연구 게이트 통과·실거래 성과를 구분합니다. 데이터·계산·수신 상태와 방법 설명은 [Home 검토 기록](../product/HOME_LIVE_QSCORE_REVIEW_20261102.md)에 연결합니다.

소스·문서 정합성 검토이며 기존 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. 법률 의견·공개 승인·실제 계정 연결·Windows 수동 검증이 아닙니다.

### 2026-11-02 종목 정보·글꼴 확장 후속

표시 시가총액은 같은 KIS 현재가 응답의 원화 가격×유효한 양의 정수 상장주수로 산출하며 기준을 명시합니다. `hts_avls` 원시값의 단위는 여전히 미검증이므로 환산하거나 공급자 공식 시가총액과 동일하다고 주장하지 않습니다. 유효한 같은 KST 날짜의 체결로 가격을 바꿔 산출값을 갱신하더라도 상장주수가 실시간 재검증되었다는 뜻은 아닙니다. 자료가 없거나 날짜가 맞지 않을 때 새로운 확정값으로 표시하지 않습니다.

PER/EPS는 KIS 제공값으로 한정합니다. 공식 확인이 없는 TTM·희석·연결/별도 재무제표 기준, EPS 화폐/주당 단위, 재무 기준일을 붙이지 않습니다. 0·음수의 유효한 공급자 값과 미제공을 구분하고, 재무항목의 기존 REST 수신 시각을 가격 tick 시각으로 덮어쓰지 않습니다. 업종은 공급자의 분류명이며 GICS 등 다른 분류로 간주하지 않고, 알려진 한영 대응 외 원문은 미번역임을 표시합니다.

글꼴 교체·실제 굵기·정보 위계 변경은 표시 변경이며 분석 성능·시세 복구·실거래 수익·전 화면 접근성 검증을 새로 입증하지 않습니다. 기존 Q-SCORE 내부 산식·초기 설계·예측력 미검증 조건은 유지합니다.

소스·문서 정합성 검토이며 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. [최종 범위와 검증 기록](../product/HOME_COMPACT_REVIEW_20261102.md)을 참조합니다.

### 2026-11-02 네이티브 수신 체결봉·선택 지표 후속

새 틱·초봉은 **연결 이후 수신한 체결**의 묶음입니다. 전체 거래소 체결·과거 틱 이력·초봉 완전성·모든 증권사 기능 지원을 주장하지 않습니다. 1/10/100틱의 개수는 수용한 레코드 수이고 1/5/10/30초는 거래소 현지 시각 구간입니다. 첫 봉·현재 봉·누락 영향 봉은 불완전할 수 있으며 누락 가격/거래량을 복원하지 않습니다. 해외 무료 피드의 시장센터 범위·지연과 모의/자산별 미지원 범위를 유지합니다.

이동평균20, 지수이평12/26, 볼린저20/2σ, Wilder RSI14, MACD12/26/Signal9는 선택한 봉 단위로 계산합니다. 분·틱 차트의 기간을 일수로 광고하지 않고 충분한 봉 전에는 값을 표시하지 않습니다. 지표 설명은 추세·변동성·모멘텀의 해석과 한계이며 검증된 예측력·매매 지시·수익 보장이 아닙니다. 축 숫자의 자리수를 줄여도 선택 봉 읽기 수치는 보존합니다.

[실제 지원·20종 영향 검토](../product/CHART_RECEIVED_BARS_REVIEW_20261102.md)를 따릅니다. 기존 `review-required`·공개 준비 `BLOCKED`와 미확정 계약/운영 사실을 유지하며 공개 승인·실계정 검증을 뜻하지 않습니다.

### 2026-11-06 AI 해설의 참고용 숫자 대조

‘AI 해설 · 검증 안 됨’은 정상 종료된 생성문에도 적용합니다. 숫자 대조는 계산 JSON의 값 및 질문과 일부 숫자 표현을 비교하는 참고 정보이며, 부호·지표와 숫자의 대응·추론·판정·진위를 확인하지 않습니다. 우연히 같은 숫자나 계산으로 유도된 값이 있을 수 있어 일치가 정확성 증거도, 미일치가 거짓의 확정도 아닙니다. 키 이름·고정 지시문·분석 종류·값 표기 설명은 대조 대상이 아니므로 ‘전송한 모든 내용에서 검증’이라고 쓰지 않습니다.

네이티브에서 URL·비밀정보를 가려 표시된 응답이 원문과 다르면 원문 기반 숫자 대조를 화면·내보내기에서 보류합니다. 다시 검사한 것으로 표시하지 않으며 `verification=NOT_VERIFIED`, 보고서 `verdict=NOT_RUN`을 유지합니다. 정상 `end_turn` 판정·strict JSON·배열 보존·크기 제한은 사실성·재현성·투자 성과 검증이 아닙니다. 같은 요청의 출력 변동과 [구현·운영 검증의 한계](FACTS.md#ai-commentary-guards-2026-11-06)를 유지합니다.

### 2026-11-06 A1 번역의 주장 범위

“설계/검증”, “분석”, “모의투자”, “샤프 지수”, “무이표 금리” 등은 기존 기능·항목의 표시 이름입니다. 메뉴 이름이나 실행 “완료”가 공식 연구 통과·실주문·모델 성능을 새로 입증하지 않습니다. 공식 판정은 원래 코드와 함께 표시하고 `CONFIGURED`의 “설정 있음”은 `REACHABLE`의 “응답 확인”과 구분합니다. `OBSERVED`의 “정상 관측”은 일별 관측 범위이며 실시간 수신·공급사 대조 완료를 뜻하지 않습니다.

지정 Flet 표의 머리글과 공급자·사용자·결과 셀을 구분한 사실을 전체 Flet 번역 완료로 확대하지 않습니다. 네이티브 ETF의 한국어 표시 어댑터는 원래 보고서 설명·AI payload·계산값을 보존합니다. 새 A3 제목 번역이 있다고 A3 배치·읽기 도움말까지 구현되었다고 안내하지 않습니다. [A1 사실 기록](FACTS.md#a1-terminology-2026-11-06)은 소스 검토이며 실제 Windows·API·법률·라이선스·파일럿·동결 연구 검증이나 공개 승인이 아닙니다.

## 정책 또는 구현 기준

1. 배포하는 주장은 주장 ID, 정확한 표현, 노출 위치, 근거 버전·시점·커밋, 검토자를 가져야 한다. 근거가 없거나 더 이상 해당 버전에 적용되지 않으면 표현을 제거하거나 사실에 맞게 좁힌다.
2. `계산 완료`, `코드 테스트 통과`, `공식 연구 게이트 통과`, `실거래 성과`, `규제 승인`을 서로 대체하지 않는다. `미실행`, `부분`, `합성`, `미검증` 상태를 숨기지 않는다.
3. 수익·예측 성능에는 대상 자산·기간·표본·분할·벤치마크·거래비용·데이터 출처·한계를 함께 제시한다. 인샘플 최적화와 검증 구간을 구분하고 유리한 결과만 전체 결과처럼 제시하지 않는다.
4. 백테스트·시뮬레이션·모의투자는 실제 고객 계좌 성과가 아니다. 연환산·누적·로그수익률·단리·복리·세전·세후·비용 전후를 명확히 구분한다.
5. `원금 보장`, `확정 수익`, `무위험`, `정확도 100%`, `정부 인증`, `누구나 수익`처럼 근거와 실제 범위를 넘어선 표현을 쓰지 않는다. 단순 면책문을 추가하는 것으로 본문상의 허위·과장을 정당화하지 않는다.
6. AI 해설은 생성 결과임을 표시하고 원래 계산·공식 판정을 바꾸지 않도록 한다. 외부 AI가 낸 주장을 검증된 제품 성능으로 재사용하지 않는다.
7. 새로운 실주문·개인화 추천·매매 권한 기능이 생기면 기존의 기능·법적 분류 설명을 재검토한다. 이 문서의 표현만으로 실제 서비스의 법적 성격을 확정하지 않는다.

권장 제품 안내:

> QUANTGEN은 정량 분석과 모의투자를 지원합니다. 표시된 결과는 데이터·모델·가정에 따라 달라지며 미래 성과를 보장하지 않습니다. 계산 완료는 별도 연구 게이트 통과를 의미하지 않습니다. 데이터 출처·관측일·합성 여부와 검증 상태를 함께 확인하세요.

## 검증과 변경 시 재검토

- **통과:** 게시 문구와 같은 버전·대상·조건의 재현 가능한 근거가 있고, 실패·미실행·한계가 오인 없이 제시된다.
- **실패:** 근거 없는 수익·정확도·승인 주장, 합성·인샘플 결과의 성격 은폐, 오래된 집계를 최신 검증처럼 표시, 실제 기능과 다른 법적·기술적 안내가 있다.
- **미실행:** 수동 검토·연구 자료·실제 게시 위치가 확인되지 않았다. 금지어 검색만으로 모든 주장이 검증되었다고 표시하지 않는다.
- 모델·게이트·데이터·테스트 집계·연구 범위·판매 정책이 바뀌면 영향을 받는 주장과 표시 위치를 재검토한다. 변경된 코드와 문서의 관련성은 자체 점검 보고서에서 추적한다.
