# 12. 성능·금융·인증 주장 근거 정책 및 주장 대장

문서 ID: QG-C12 · 버전: 1.5 · 검토일: 2026-11-02 · 상태: review-required

## 적용 범위와 현재 상태

QUANTGEN의 제품 화면, README, 소개·판매 자료, 연구 보고서, AI 출력에 쓰이는 기능·정확도·수익·검증·기관 관련 주장에 적용한다.

- 현행 README는 연구·분석·모의투자와 실주문 경로 부재를 설명한다. 상업 출시 결정은 팀의 판단이며 정부·금융투자협회의 승인·인증·보증이 아니라고 구분한다.
- README의 기록된 QA 집계는 새 테스트 실행이나 전체 출시 적합성 판정이 아니다. `NOT_RUN`을 `PASS`와 합치지 않는다.
- UI의 P5–P95는 시뮬레이션 분포의 중앙 90% 구간이다. 95% 신뢰구간·손실 방지·수익 보장으로 표현하지 않는다.
- 옵션 호가 검사는 실제 수행 분모와 `NOT_RUN`·`PARTIAL`을 함께 표시한다. 미검사 자료의 null이나 부분 검사에서의 0을 전체 무위반·실거래 차익 검증·공식 연구 통과로 해석하지 않는다.
- 스왑션 주모델 가격·Greeks의 정상 계산과 보조 모델 변동성 환산의 `UNAVAILABLE`은 별도 상태다. 보조 결과를 0으로 만들거나 주가격 전체가 실패했다고 표시하지 않는다.
- 네이티브 이행 문서에는 이전 개인 사용 정책을 가리키는 문장이 남아 있다. 상업 출시 결정과의 불일치로 기록하고 현재 정책을 확정한 뒤 문서 간 표현을 정리해야 한다.

### 2026-10-31 앱 UI 변경 검토

기술지표 사례는 교육 전용이며 실패 사례는 이후 5개 관측을 이용한 사후 설명으로 명시합니다. 교육 메타데이터의 verdict는 NOT_RUN이며 연구 통과·실현 수익을 만들지 않습니다. 한국어·영어 번역과 714개 지역 형식을 구분합니다. 통합된 메인 변경의 SABR 수렴·잔차·경계·외삽 정보는 독립 검증/차익 검증 NOT_RUN과 함께 유지하고, FX·캐리·금리 번역은 정규 증거와 판정을 바꾸지 않습니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

C형 공통 배치와 다크모드는 기존 차트 종류·데이터·축 범위·연구 판정을 유지합니다. Linux 로컬 Chromium/Flet와 Qt offscreen 화면을 확인했으나 소개사이트 반영·운영 배포·물리 Windows 설치 확인으로 확대하지 않습니다.

### 2026-11-02 KIS 차트 주장 범위

[구현 범위](../product/KIS_MARKET_CHARTS_2026-11-02.md)는 REST 단일·5초 반복 조회와 WebSocket 체결 수신을 구분합니다. `SUBSCRIBED`는 구독 승인, `LIVE`는 유효 체결 수신이며 연결·heartbeat만으로 새 시세를 주장하지 않습니다. 미국 무료 Nasdaq 피드는 통합시세와 제공 범위가 다를 수 있고 아시아 무료 피드는 15분 지연으로 안내합니다. 채권은 일봉, 해외선물은 검증된 master 배율의 일·주·월봉을 지원하며 해외옵션·야간 WebSocket 등 미지원 조합을 구분합니다. 모든 자산·주기의 무지연·완전한 실시간 지원을 주장하지 않습니다.

형성 중 봉·지표, 워밍업 부족, 부분 이력·미확정 거래량, 수신 공백 후 OHLC 불완전, 일부 국내 체결의 KST 수신일 추정을 유지합니다. 지표는 조회 이력의 계산 결과이며 수익·예측 능력 검증이 아닙니다. PR #56·PR #57 및 통합 작업 트리의 합성 소켓·시세/Linux offscreen 검사는 실제 KIS 계정·권리·Windows 수동 수용·AWS 배포·공식 연구 판정·규제 승인 증거가 아닙니다. [변경 사실](FACTS.md#kis-market-integration-2026-11-02)과 연결합니다.

이 절은 양쪽 소스·문서 검토를 통합한 사실 기록이며 `review-required`와 운영 증빙의 미확정 상태를 유지합니다. 법률 검토·공개 승인·실제 배포 검증이 아닙니다.

### 2026-11-02 Home 시세·Q-SCORE 후속 검토

Q-SCORE v0.1은 기존 기술신호 합성값을 0–100으로 환산한 값 70%, 과거 최대 낙폭 점수 15%, 과거 95% CVaR 점수 15%를 더하는 새 표시용 합성 점수입니다. 낙폭 0–40%와 일간 CVaR 0–8%를 각각 100–0으로 환산·제한하며 20·40·60·80점을 별 개수의 경계로 사용합니다. 비중·경계는 초기 설계값으로 예측력이나 최적성이 검증된 것이 아닙니다. 기업가치·투자 등급·수익 확률·고객 후기·모든 엔진의 평가로 표현하지 않습니다.

입력 검사를 통과한 KIS 국내주식 수정 일별 이력 최소 200개·최대 최근 252개를 사용하고 유효한 새 체결은 당일 잠정 종가에 반영합니다. 부족·오래됨·부적절한 수정 기준·중복/역순·미확인 시각을 정상 실시간 점수로 바꾸지 않습니다. 별점 표시 성공과 실제 계정 수신, Windows 화면, 공급자 권리, 독립 연구 게이트 통과·실거래 성과를 구분합니다. 데이터·계산·수신 상태와 방법 설명은 [Home 검토 기록](../product/HOME_LIVE_QSCORE_REVIEW_20261102.md)에 연결합니다.

소스·문서 정합성 검토이며 기존 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. 법률 의견·공개 승인·실제 계정 연결·Windows 수동 검증이 아닙니다.

## 정책 또는 구현 기준

1. 배포하는 주장은 주장 ID, 정확한 표현, 노출 위치, 근거 버전·시점·커밋, 검토자를 가져야 한다. 근거가 없거나 더 이상 해당 버전에 적용되지 않으면 표현을 제거하거나 사실에 맞게 좁힌다.
2. `계산 완료`, `코드 테스트 통과`, `공식 연구 게이트 통과`, `실거래 성과`, `규제 승인`을 서로 대체하지 않는다. `미실행`, `부분`, `합성`, `미검증` 상태를 숨기지 않는다.
3. 수익·예측 성능에는 대상 자산·기간·표본·분할·벤치마크·거래비용·데이터 출처·한계를 함께 제시한다. 인샘플 최적화와 검증 구간을 구분하고 유리한 결과만 전체 결과처럼 제시하지 않는다.
4. 백테스트·시뮬레이션·모의투자는 실제 고객 계좌 성과가 아니다. 연환산·누적·로그수익률·단리·복리·세전·세후·비용 전후를 명확히 구분한다.
5. `원금 보장`, `확정 수익`, `무위험`, `정확도 100%`, `정부 인증`, `누구나 수익`처럼 근거와 실제 범위를 넘어선 표현을 쓰지 않는다. 단순 면책문을 추가하는 것으로 본문상의 허위·과장을 정당화하지 않는다.
6. AI 해설은 생성 결과임을 표시하고 원래 계산·공식 판정을 바꾸지 않도록 한다. 외부 AI가 낸 주장을 검증된 제품 성능으로 재사용하지 않는다.
7. 새로운 실주문·개인화 추천·매매 권한 기능이 생기면 기존의 기능·법적 분류 설명을 재검토한다. 이 문서의 표현만으로 실제 서비스의 법적 성격을 확정하지 않는다.

권장 제품 안내:

> QUANTGEN은 정량 분석과 모의투자를 지원합니다. 표시된 결과는 데이터·모델·가정에 따라 달라지며 미래 성과를 보장하지 않습니다. 계산 완료는 별도 연구 게이트 통과를 의미하지 않습니다. 데이터 출처·관측일·합성 여부와 검증 상태를 함께 확인하세요.

## 검증과 변경 시 재검토

- **통과:** 게시 문구와 같은 버전·대상·조건의 재현 가능한 근거가 있고, 실패·미실행·한계가 오인 없이 제시된다.
- **실패:** 근거 없는 수익·정확도·승인 주장, 합성·인샘플 결과의 성격 은폐, 오래된 집계를 최신 검증처럼 표시, 실제 기능과 다른 법적·기술적 안내가 있다.
- **미실행:** 수동 검토·연구 자료·실제 게시 위치가 확인되지 않았다. 금지어 검색만으로 모든 주장이 검증되었다고 표시하지 않는다.
- 모델·게이트·데이터·테스트 집계·연구 범위·판매 정책이 바뀌면 영향을 받는 주장과 표시 위치를 재검토한다. 변경된 코드와 문서의 관련성은 자체 점검 보고서에서 추적한다.
