## 적용 범위와 현재 상태

현재 QUANTGEN에는 연구 입력·규칙 이름·메모·외부 AI 질문과 선택적 Upbit 연결이 있습니다. 검토한 소스에서는 회원가입·구매·광고 수신 신청을 위한 공통 폼과 동의 대장을 확인하지 못했습니다. 새 양식 도입 시 목적·필수성·법적 근거를 먼저 판정하고 필요한 고지와 동의를 설계해야 합니다.

네이티브 AI 화면은 전송 미리보기와 기본 미선택 체크박스를 제공합니다. Flet의 AI 패널은 전송 설명·질문·전송 버튼을 제공하지만 동일한 체크박스 흐름은 없습니다. 구조화된 private 필드를 제외하는 필터는 자유 입력 질문에 개인정보가 있는지 탐지하지 않습니다. Flet Crypto 분석은 키가 설정되면 자산 조회가 기본 포함될 수 있고 네이티브에서는 기본 OFF이므로, “모든 개인정보 처리는 별도 선택 후 실행”이라는 현재 상태 설명은 부정확합니다.

## 정책 또는 구현 기준

### 양식 설계 규칙

1. 입력 필드마다 목적·항목·필수/선택·법적 근거·보유기간·수령자·외부 전송을 식별합니다. 개인정보 처리방침은 상세 설명이며, 동의가 필요한 처리를 포괄 동의 한 개로 대체하는 수단이 아닙니다.
2. 계약 이행에 필요한 처리, 법정 의무, 동의 기반 처리를 구분합니다. 서비스 약관 동의, 개인정보 수집·이용 동의, 제3자 제공, 국외 이전, 선택적 광고 수신을 서로 자동 결합하지 않습니다. 해당 근거에 별도 동의가 필요한지 실제로 검토합니다.
3. 동의를 받는 경우 목적, 항목, 보유·이용기간, 거부권 및 거부 시 구체적 영향을 쉽게 읽을 수 있게 제시합니다. 제3자 제공·국외 이전 등에는 그 처리에 필요한 추가 고지 항목도 제공합니다.
4. 선택 항목·광고 수신은 기본 미선택입니다. “전체 동의”를 제공해도 세부 항목을 개별 선택·해제할 수 있게 하며 선택 항목을 거부해도 관계없는 기본 기능을 제한하지 않습니다.
5. 폼을 닫거나 스크롤하거나 값을 입력한 사실만으로 동의했다고 기록하지 않습니다. 마지막 실행 시 제시된 문안·데이터 범위·선택 상태가 변경되지 않았는지 확인합니다.
6. 동의의 증명은 실제 제시 문안 버전, 목적별 선택, 일시, 이용자가 수행한 명시적 행동, 철회 이력을 최소한으로 보관합니다. 서명 그림·IP·기기 지문을 무조건 추가 수집하지 않습니다.
7. 주민등록번호, 계좌 비밀번호, 원본 인증 키를 고객지원 폼에 요구하지 않습니다. 개인정보가 들어갈 수 있는 질문·메모에는 입력 전 주의 문구와 삭제 경로를 제공합니다.
8. 연령·법정대리인·민감정보·고유식별정보 처리가 실제 필요하면 별도 요건을 검토합니다. “필수 동의”라는 글자만으로 필요성이나 적법성을 입증하지 않습니다.

### 선택적 외부 AI 고지 및 실행 양식

> **외부 AI 해설 요청**
>
> 이 기능은 선택 사항입니다. 전송 미리보기에 표시한 계산 결과와 아래 질문을 {{privacy.ai_recipient_legal_name}}에 전송하여 해설을 생성합니다. 전송 목적·보유기간·처리 국가·이전 근거·거부 방법은 {{privacy.ai_notice_link}}에서 확인할 수 있습니다. 요청하지 않아도 로컬 계산 결과와 기본 해설은 이용할 수 있습니다. API 키, 비밀번호, 계좌정보나 다른 사람의 개인정보를 질문에 입력하지 마세요. 외부 API 비용은 {{pricing.ai_cost_payer}}에게 {{pricing.ai_cost_terms}}에 따라 발생할 수 있습니다.

실제 전송 데이터의 미리보기, 자유 입력 질문, 필요한 구체 고지 및 명시적인 **“표시한 내용으로 외부 AI 해설 요청”** 행동을 제공합니다. 동의가 법적 근거이면 별도 미선택 동의를 받습니다. 네이티브의 체크박스는 전송 선택의 기술적 증거이며, 미확정된 이전 국가·계약·보유기간까지 자동으로 충족시키지는 않습니다.

질문·선택 결과·payload를 바꾼 뒤 이전 미리보기나 과거 동의로 새 내용을 전송하지 않습니다. 전송 실패·취소 시 요청이 어디까지 전달되었는지 확인 가능한 범위에서 안내하고 실패 메시지에 원본 질문·키·인증 헤더를 노출하지 않습니다.

### 선택적 Upbit 자산조회 고지 및 실행 양식

> **내 Upbit 자산 조회 선택**
>
> 공개 시세 분석과 별도로, 연결한 자산조회 권한을 사용해 통화·기준통화·잔액·잠금 금액·평균 매수가를 조회하고 총수량·원화평가액을 계산합니다. 평가액 계산을 위해 보유 통화의 종목을 Upbit 공개 시세 API에 보냅니다. 이 프로그램은 실제 주문·출금 기능을 제공하지 않습니다. 결과의 처리 위치와 보유기간은 {{privacy.upbit_location_and_retention}}입니다. 자산 조회를 선택하지 않아도 공개 시세 연구 기능은 사용할 수 있습니다. 키는 조회에 필요한 최소 권한만 사용하고, 고객지원 채팅이나 Git에는 보내지 마세요.

키가 존재한다는 사실을 자산조회 선택의 증거로 간주하지 않습니다. 조회 요청 전 기본 미선택의 별도 제어를 두고 명시적 요청 이후에만 계좌 endpoint가 호출되는지 검증합니다. 현재 Flet 흐름은 이 기준을 충족하도록 보완·검증하기 전까지 미완료입니다.

### 문의 양식의 최소 고지

> (주)넥스트제너레이션은 문의 응답을 위해 회신 연락처와 문의 내용을 {{privacy.support_basis}}에 따라 {{privacy.support_retention}} 동안 처리합니다. 필수 연락처가 없으면 회신이 어려울 수 있습니다. API 키·비밀번호·원본 계좌자료를 보내지 마세요. 첨부파일은 필요한 부분만 가려서 제출해 주세요. 자세한 내용과 권리행사 경로는 개인정보 처리방침에서 확인할 수 있습니다.

지원 업무에 적합한 법적 근거를 정한 뒤 필요한 경우에만 별도 동의 문구로 구성합니다. 문의 접수를 광고 수신 동의의 조건으로 만들지 않습니다.

### 동의·철회 증거 기록

`기록 ID / 처리 목적 ID / 제시 문안·버전·해시 / 제시 화면과 언어 / 선택한 항목 / 명시적 실행 행동 / 일시와 시간대 / 필요한 최소 이용자 식별자 / 법정대리인 확인 여부(해당 시) / 철회 일시·범위 / 철회 후 전송 중단 검증 / 보유 만료일`을 기록합니다.

실제 동의 증거는 접근 제한된 시스템에 보관합니다. 이 양식을 채운 것만으로 동의 획득을 주장할 수 없고, 보관 문안과 실제 화면이 같아야 합니다. 계약 확인·고객 동의·국외이전 동의의 이력을 목적에 맞게 구별합니다.

## 검증과 변경 시 재검토

- **통과:** 미선택 상태에서는 선택 처리·외부 전송이 없고, 실제 전송 내용과 미리보기·고지·동의 버전이 일치합니다. 거부 후 기본 기능과 철회 후 중단을 합성 키·mock endpoint로 검증합니다.
- **차단:** API 키 존재를 동의로 취급, 자유 입력을 필터가 완전히 보호한다고 설명, 필수·선택 통합, 미확정 수령자·국가·기간, 화면과 다른 동의 기록입니다.
- 새 입력 필드·연구 내보내기·AI payload·질문·계좌 endpoint·지원 폼·회원·결제·광고·외부 수령자 변경 시 재검토합니다. Flet와 네이티브는 각 경로를 별도로 검증합니다.
- 정적 파이프라인은 변경과 증거 누락을 확인하는 도구입니다. 필요한 고지 내용·실제 동의 취득·법적 근거의 타당성은 별도 검토합니다.
