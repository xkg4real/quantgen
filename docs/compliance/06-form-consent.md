## 적용 범위와 현재 상태

현재 QUANTGEN에는 연구 입력·규칙 이름·메모·외부 AI 질문과 선택적 Upbit 연결이 있습니다. 검토한 소스에서는 회원가입·구매·광고 수신 신청을 위한 공통 폼과 동의 대장을 확인하지 못했습니다. 새 양식 도입 시 목적·필수성·법적 근거를 먼저 판정하고 필요한 고지와 동의를 설계해야 합니다.

네이티브 AI 화면은 전송 미리보기와 기본 미선택 체크박스를 제공합니다. Flet의 AI 패널은 전송 설명·질문·전송 버튼을 제공하지만 동일한 체크박스 흐름은 없습니다. 구조화된 private 필드를 제외하는 필터는 자유 입력 질문에 개인정보가 있는지 탐지하지 않습니다. Flet Crypto 분석은 키가 설정되면 자산 조회가 기본 포함될 수 있고 네이티브에서는 기본 OFF이므로, “모든 개인정보 처리는 별도 선택 후 실행”이라는 현재 상태 설명은 부정확합니다.

### 2026-10-31 앱 UI 변경 검토

교육 지표·기간·커서 선택은 로컬 예제 표시이고, 내보내기는 별도 저장 동작입니다. 언어 전환은 금융 입력·정규 연구 기록·실행 권한을 변경하지 않습니다. 기존 AI·Upbit 선택 흐름은 이 기능과 별개이며 그 차이를 해소했다고 표시하지 않습니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

### 2026-11-02 KIS 조회·연결 초기 이력

다음은 초기 통합 당시 동작이며 Flet은 해당 제어를 유지합니다. 현재 네이티브의 조회 후 자동 연결·후속 입력 갱신은 아래 수신 체결봉 후속 절을 적용합니다.

새 입력은 자산·종목·거래소/시장·주기·봉 수입니다. 최초 화면 진입이나 조건 선택만으로 원격 조회를 시작하지 않습니다. 사용자는 조회 버튼, 기본 미선택인 5초 REST 반복 조회, 별도 실시간 연결을 선택합니다. 새 실시간 연결은 REST 이력을 갱신한 후 승인키 발급·WebSocket 구독을 시작합니다. 화면 이탈·종료는 반복 조회·수신을 멈추며 복귀 시 자동 재개하지 않습니다. Flet의 실시간 연결 중지는 WebSocket 수신에 해당하고 REST 반복 조회는 별도 스위치를 OFF로 바꿉니다. 진행 중 REST 요청이 이미 제공자에게 전달됐을 수 있고 정지가 승인키 전역 캐시·제공자 로그의 삭제를 보장하지는 않습니다.

이는 기능 실행 선택의 소스 근거이며 개인정보·국외이전·광고의 법적 동의나 동의 이력, 상업 시세 이용권 검증이 아닙니다. 새 KIS 계좌 입력·AI 질문·결제·동의 대장을 추가하지 않았습니다. 승인키·선택 종목의 전송처와 비TLS WebSocket, 보관 한계는 [KIS 변경 사실](FACTS.md#kis-market-integration-2026-11-02)과 일치시킵니다. 기존 Flet/네이티브 AI·Upbit 선택 차이를 해결했다고 표시하지 않습니다. [Flet](../../ui/market_chart_page.py), [Qt](../../quantgen_desktop/market_chart.py)가 실행 근거입니다.

이 절은 양쪽 소스·문서 검토를 통합한 사실 기록이며 `review-required`와 운영 증빙의 미확정 상태를 유지합니다. 법률 검토·공개 승인·실제 배포 검증이 아닙니다.

### 2026-11-02 M3-N08 재평가 파라미터 일관성

금리 시뮬레이션의 채권·스왑 기간말 재평가 API는 전달된 `model`·`kappa`·`theta`·`sigma`·`r0`가 시뮬레이션에 실제 사용된 `sim.params`와 다르면 재평가 전에 거부합니다. 설명용 `note`만 다른 경우는 허용합니다. 설정을 바꾸려면 시뮬레이션을 다시 생성해야 하며, Hull–White의 곡선 기반 `r0` 정규화 후 값을 사용하도록 기존 Flet·네이티브 서비스 호출을 맞췄습니다.

이는 기존 계산 입력의 일관성 검사이며 새 개인정보 입력·동의 대장·전송처·저장·실행 권한을 추가하지 않습니다. 정상 입력의 계산·표시 및 선택적 AI 전송 범위는 유지하고 기존 제공자 조회·AI/Upbit 선택 절차의 미확정 사항도 유지합니다. 이 API 검사는 개인정보 동의·연구 실행 승인 또는 실제 Windows 수용 검증을 대신하지 않습니다. [소스·검증 범위](../product/RATES_REVALUATION_PARAMS_2026-11-02.md)를 근거로 `review-required`를 유지합니다.

### 2026-11-02 Home 시세·Q-SCORE 후속 검토

네이티브 Home은 기본 실행의 자동 갱신 또는 새로고침에서 일별 시장지표와, 키가 있으면 고정 국내주식 목록의 KIS REST 시세를 조회합니다. 따라서 앱 전체에 대해 “최초 진입에는 외부 요청이 없다”거나 “키가 있어도 모든 공개 시세 조회는 별도 클릭 후에만 실행된다”고 설명하지 않습니다. 개인 계좌·잔고 조회를 추가하는 흐름은 아닙니다.

수정 일별 이력과 체결 스트림을 이용하는 Home의 **실시간 목록 연결**은 별도 실행 행동입니다. 중지·Home 이탈 시 연결을 끝내고 돌아왔다고 자동 재개하지 않습니다. 별도 국내주식 차트에서는 명시적 조회 결과에 따라 점수용 수정 일별 이력을 추가 조회합니다. Q-SCORE 방법 도움말은 로컬 문구이며 외부 AI 질문이나 상품 구매 신청이 아닙니다. 이 실행 버튼을 개인정보·국외 이전·광고에 관한 포괄 동의의 증거로 사용하지 않습니다. 기존 Flet/네이티브 AI·Upbit 선택 흐름의 차이는 유지합니다.

소스·문서 정합성 검토이며 기존 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. 법률 의견·공개 승인·실제 계정 연결·Windows 수동 검증이 아닙니다.

### 2026-11-02 네이티브 수신 체결봉·선택 지표 후속

네이티브에서는 최초 조건 선택은 조회 전 준비이며, **조회 / 새로고침** 또는 Enter가 이력/현재가 조회와 지원 체결 구독을 함께 시작합니다. 소켓 미지원 자산은 지원 이력을 5초 REST 조회하며 실시간 체결로 표시하지 않습니다. 활성 갱신 중 입력 변경은 450ms 뒤 새 조건으로 이어지고 중지·이탈은 이 자동 재시작도 해제합니다. 연결 복구 뒤 한 번의 자동 재동기화를 허용하고 반복 공백에는 수동 조회를 안내합니다.

지표 선택·숨기기·언어·읽기 안내는 표시 조작이며 새 구독이나 AI 전송을 실행하지 않습니다. 최초 조회 전에도 지표를 선택할 수 있습니다. 명시적 기능 실행을 개인정보·국외이전·광고의 포괄 동의로 삼지 않고, 이미 제공자에게 전송된 요청·캐시·로그가 중지로 삭제된다고 설명하지 않습니다. Flet의 기존 별도 연결/폴링 제어와 Home의 시작 시 REST 조회는 별도입니다.

[실제 지원·20종 영향 검토](../product/CHART_RECEIVED_BARS_REVIEW_20261102.md)를 따릅니다. 기존 `review-required`·공개 준비 `BLOCKED`와 미확정 계약/운영 사실을 유지하며 공개 승인·실계정 검증을 뜻하지 않습니다.

### 2026-11-03 AI 해설 요청 버튼

“AI 해설 요청” 버튼은 이제 항상 누를 수 있고 손 모양 커서를 보입니다(소유자 B3: 반응하지 않는 버튼으로 보였음). 누르면 필요한 단계를 차례로 안내합니다. 결과를 고르지 않았으면 완료 결과 목록을 읽고, 전송 내용을 미리 보여 준 뒤 동의 체크를 요청합니다. 동의가 없으면 아무것도 전송하지 않고 안내만 합니다. 동의 상자는 기본으로 꺼져 있고, 결과·질문을 바꾸면 다시 꺼집니다. 동의가 있을 때만 버튼이 강조 상태가 됩니다. [AI 해설 화면](../../quantgen_desktop/commentary.py)과 [시험](../../tests/desktop_commentary_acceptance.py)이 근거입니다.

### 2026-11-04 시장 관심종목·종목 선택

위 2026-11-02 후속 절의 “최초 조건 선택은 조회 전 준비”는 시장 화면에는 더 이상 맞지 않습니다. 자동 갱신이 켜진 창에서는 다음 동작이 곧 원격 조회의 실행입니다.

- 시장 화면을 보이면 관심종목 카드마다 일별 종가를 조회하고, 화면이 보이는 동안 주기적으로 다시 조회합니다.
- 카드·검색 결과를 고르거나 검색창에서 Enter를 누르거나 Home 상세의 차트 버튼을 누르면 그 종목의 차트 조회·지원 체결 연결과 종목 정보 조회(국내주식은 현재가·투자자별 매매·공매도 포함)를 함께 시작합니다.
- 종목 검색 칸에 처음 포커스가 가면 KIS 종목 마스터 두 파일을 받습니다.

자동 갱신이 꺼진 창(시험)에서는 셋 다 저절로 실행되지 않습니다. 카드의 새로고침과 차트의 조회 버튼은 그대로 동작하고, 종목 마스터는 받지 않습니다. 화면을 떠나거나 관심종목으로 돌아가면 차트 갱신이 멈춥니다. ☆·★·× 버튼은 관심종목 목록만 바꾸며 조회 동작의 동의가 아닙니다. 이 실행 동작을 개인정보·국외이전·광고의 포괄 동의로 쓰지 않습니다. [변경 사실](FACTS.md#markets-watchlist-2026-11-04)을 따릅니다.

## 정책 또는 구현 기준

### 양식 설계 규칙

1. 입력 필드마다 목적·항목·필수/선택·법적 근거·보유기간·수령자·외부 전송을 식별합니다. 개인정보 처리방침은 상세 설명이며, 동의가 필요한 처리를 포괄 동의 한 개로 대체하는 수단이 아닙니다.
2. 계약 이행에 필요한 처리, 법정 의무, 동의 기반 처리를 구분합니다. 서비스 약관 동의, 개인정보 수집·이용 동의, 제3자 제공, 국외 이전, 선택적 광고 수신을 서로 자동 결합하지 않습니다. 해당 근거에 별도 동의가 필요한지 실제로 검토합니다.
3. 동의를 받는 경우 목적, 항목, 보유·이용기간, 거부권 및 거부 시 구체적 영향을 쉽게 읽을 수 있게 제시합니다. 제3자 제공·국외 이전 등에는 그 처리에 필요한 추가 고지 항목도 제공합니다.
4. 선택 항목·광고 수신은 기본 미선택입니다. “전체 동의”를 제공해도 세부 항목을 개별 선택·해제할 수 있게 하며 선택 항목을 거부해도 관계없는 기본 기능을 제한하지 않습니다.
5. 폼을 닫거나 스크롤하거나 값을 입력한 사실만으로 동의했다고 기록하지 않습니다. 마지막 실행 시 제시된 문안·데이터 범위·선택 상태가 변경되지 않았는지 확인합니다.
6. 동의의 증명은 실제 제시 문안 버전, 목적별 선택, 일시, 이용자가 수행한 명시적 행동, 철회 이력을 최소한으로 보관합니다. 서명 그림·IP·기기 지문을 무조건 추가 수집하지 않습니다.
7. 주민등록번호, 계좌 비밀번호, 원본 인증 키를 고객지원 폼에 요구하지 않습니다. 개인정보가 들어갈 수 있는 질문·메모에는 입력 전 주의 문구와 삭제 경로를 제공합니다.
8. 연령·법정대리인·민감정보·고유식별정보 처리가 실제 필요하면 별도 요건을 검토합니다. “필수 동의”라는 글자만으로 필요성이나 적법성을 입증하지 않습니다.

질문·선택 결과·payload를 바꾼 뒤 이전 미리보기나 과거 동의로 새 내용을 전송하지 않습니다. 전송 실패·취소 시 요청이 어디까지 전달되었는지 확인 가능한 범위에서 안내하고 실패 메시지에 원본 질문·키·인증 헤더를 노출하지 않습니다.

### 선택적 Upbit 자산조회 고지 및 실행 양식

> **내 Upbit 자산 조회 선택**
>
> 공개 시세 분석과 별도로, 연결한 자산조회 권한을 사용해 통화·기준통화·잔액·잠금 금액·평균 매수가를 조회하고 총수량·원화평가액을 계산합니다. 평가액 계산을 위해 보유 통화의 종목을 Upbit 공개 시세 API에 보냅니다. 이 프로그램은 실제 주문·출금 기능을 제공하지 않습니다. 결과의 처리 위치와 보유기간은 {{privacy.upbit_location_and_retention}}입니다. 자산 조회를 선택하지 않아도 공개 시세 연구 기능은 사용할 수 있습니다. 키는 조회에 필요한 최소 권한만 사용하고, 고객지원 채팅이나 Git에는 보내지 마세요.

키가 존재한다는 사실을 자산조회 선택의 증거로 간주하지 않습니다. 조회 요청 전 기본 미선택의 별도 제어를 두고 명시적 요청 이후에만 계좌 endpoint가 호출되는지 검증합니다. 현재 Flet 흐름은 이 기준을 충족하도록 보완·검증하기 전까지 미완료입니다.
