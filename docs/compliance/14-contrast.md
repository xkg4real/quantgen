# 14. 색상 대비·색상 독립 전달 기준 및 측정 양식

문서 ID: QG-C14 · 버전: 1.0 · 검토일: 2026-10-31 · 상태: review-required

## 적용 범위와 현재 상태

Flet·Qt의 라이트·다크·시스템 테마, 차트, 포커스·입력 경계, 오류·성공 상태 및 내보낸 문서에 적용한다. `core/theme.py`가 공통 팔레트를 제공하지만 실제 렌더링에는 투명도·그래프·별도 색상·상태 스타일도 있으므로 팔레트 검사만으로 전체 화면을 통과시키지 않는다.

2026-10-31 소스의 sRGB 값을 WCAG 상대휘도 공식으로 계산한 일부 결과:

| 테마 | 전경 / 배경 토큰 | 대비비 | 해석 |
|---|---|---:|---|
| LIGHT | text / bg | 13.87:1 | 해당 불투명 일반 텍스트 조합은 4.5:1 이상 |
| LIGHT | muted / surface_2 | 4.69:1 | 여유가 작아 상태·투명도 변경 시 재측정 |
| LIGHT | error / surface | 5.15:1 | 해당 불투명 일반 텍스트 조합은 4.5:1 이상 |
| DARK | muted / surface_2 | 6.61:1 | 해당 불투명 일반 텍스트 조합은 4.5:1 이상 |
| DARK | error / surface | 4.70:1 | 여유가 작아 실제 배경과 투명도 확인 필요 |
| LIGHT | border / surface | 1.28:1 | 필요한 입력 경계를 이것만으로 식별하면 재검토 필요 |
| DARK | border / surface | 1.59:1 | 필요한 입력 경계를 이것만으로 식별하면 재검토 필요 |

Qt의 버튼·텍스트 입력은 `border` 토큰을 사용한다. 포커스에는 `accent` 테두리를 쓰는 선택자가 있지만 모든 제어 유형의 포커스가 검증된 것은 아니다. 위 결과는 특정 소스 조합의 측정이며 실제 앱의 접근성 인증이 아니다.

## 정책 또는 구현 기준

1. 일반 텍스트와 텍스트 이미지는 배경에 대해 최소 4.5:1을 목표 수용 기준으로 한다. WCAG의 큰 텍스트 정의를 실제 글꼴 크기·굵기와 단위로 입증한 경우에만 3:1 기준을 적용한다. 단순히 제목이라는 이유로 기준을 낮추지 않는다.
2. 제어를 식별하는 데 필요한 경계·상태 표시와 의미 있는 그래픽 요소는 인접 색상에 대해 최소 3:1을 점검한다. 장식 구분선에 무조건 같은 기준을 적용하거나, 필요한 제어 경계를 장식으로 분류하지 않는다.
3. 색상만으로 양수·음수·통과·실패·오래된 데이터·선택 상태를 전달하지 않는다. 부호·숫자·텍스트·모양·선 스타일 중 적절한 수단을 함께 사용한다.
4. 실제 합성된 색상을 계산한다. 투명한 색·음영·호버·선택·비활성·차트 배경을 원래 HEX 값만으로 판정하지 않는다. WCAG 예외를 적용하면 요소와 이유를 기록한다.
5. 포커스는 배경과 구별되고 가려지지 않아야 한다. 대비 측정 외에 [15번 키보드 점검](15-keyboard.md)에서 위치·지속성·도달 가능성을 검증한다.
6. 라이트·다크를 모두 검사하고, 시스템 테마를 지원하는 Flet은 실제 OS 모드 전환도 확인한다. 확대·고대비 설정에서 오류·선택 상태를 구별할 수 있어야 한다.

측정 공식은 WCAG의 sRGB 선형화와 상대휘도를 사용한다. 대비비는 `(밝은 상대휘도 + 0.05) / (어두운 상대휘도 + 0.05)`이며, 반올림 표시가 기준을 넘더라도 원래 계산값이 기준 미만이면 통과가 아니다.

## 검증과 변경 시 재검토

- **통과:** 실제 필요한 전경·배경 조합이 해당 기준을 충족하고, 색상 외에도 의미와 상태를 이해할 수 있으며, 모든 지원 테마·필수 상태의 증거가 있다.
- **실패:** 일반 텍스트 기준 미달, 필요한 제어·그래픽 식별 실패, 색상만으로 중요한 상태를 전달한다. 기준 미달 조합을 전체 평균으로 상쇄하지 않는다.
- **미실행:** 토큰만 검사했거나 실제 화면·알파 합성·필수 상태를 확인하지 못했다. 접근성 자동 검사 결과는 수동 검증과 별도 기록한다.
- `core/theme.py`, Qt 스타일시트, Flet 구성요소, 차트 색상·투명도·범례, 글꼴 크기·테마 처리 변경 시 영향을 받은 모든 쌍을 재측정한다. 변경 없는 측정값도 기준 소스 커밋과 연결한다.
