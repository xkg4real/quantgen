# QUANTGEN 운영 정책 20종과 변경 점검

이 묶음은 사진의 20개 항목을 QUANTGEN의 정책 본문, 작성·처리 양식, 구현 기준으로 옮긴 저장소 관리 문서다. 기준일은 **2026-10-31 한국시간**, 코드 기준은 `2999296`이다. 각 문서의 `양식` 절을 복사하여 사용할 수 있다. 문서와 파이프라인의 관리 방법은 [PIPELINE.md](PIPELINE.md)에 있다.

문서의 현재 상태는 **검토용 초안 / 공개 승인 전**이다. 사업자·요금·보유기간·국외이전 계약 등 확인되지 않은 사실은 `{{...}}`로 남겼다. 구현되지 않은 화면·동의·삭제 기능은 구현 완료로 표현하지 않았다. 문서 구조 점검 PASS는 공개 준비, 법적 적합성, 접근성 인증을 뜻하지 않는다. [확인된 동작](FACTS.md), [남은 조치](RELEASE_GAPS.md), [공식 근거](SOURCES.md)를 함께 사용한다.

운영자가 제공한 `(주)넥스트제너레이션`, 대표자 고건, 현 주소와 대한민국 운영·Cloudflare 이용 정보를 반영했다. 요금은 Research 월 29,000원, Pro 월 59,000원, Team Pilot 월 290,000원(모두 VAT 포함·월 자동 갱신, Team Pilot 최대 5인)이다. 사업자등록번호·지원 및 개인정보 연락처와 추가 자율 환불조건은 미정이다. Cloudflare의 이용 제품·처리 국가·계약, 상품별 기능·청구일·실제 결제/해지 절차는 별도 확인 대상이다.

## 문서를 사용하는 순서

1. [FACTS.md](FACTS.md)의 실제 기능과 배포 형태를 확인한다. 브라우저 Flet, 네이티브 PyQt6, 운영 서버를 구분한다.
2. [release-profile.json](release-profile.json)의 운영 정보를 확인한다. 실제 개인정보나 비밀키를 넣지 말고, 공개할 사업자 정보와 증빙 문서 참조만 기록한다.
3. 해당 문서의 `정책 또는 구현 기준`을 실제 서비스와 일치시키고 `{{...}}`를 확정한다. 기능이 없는 경우 적용 조건과 대체 절차를 확정한다.
4. `양식`을 복사하여 보호된 운영 기록 시스템에서 작성한다. 이용자 요청서, 동의 이력, 계좌 자료, 키, 계약 원문은 이 공개 가능 저장소에 커밋하지 않는다.
5. 코드·문서·운영 증거를 검토한 뒤 [PIPELINE.md](PIPELINE.md)의 명시적 기준선 갱신 명령을 실행한다. 자동 점검 결과와 공개 준비 결과를 구분한다.

사진은 점검 주제의 목록이다. 사진 자체는 한국 법령, 모든 서비스의 의무 목록, 법률 검토 결과 또는 QUANTGEN의 현재 구현 증거가 아니다. 예를 들어 쿠키 동의나 법정대리인 동의는 실제 처리 목적·근거·이용자와 배포 방식에 따라 판단해야 한다.

## GitHub 변경 후 유지관리

`.github/workflows/compliance-review.yml`은 PR, 기본 브랜치 변경, 정기 실행, 수동 실행에서 점검한다. 코드·의존성·자산이 검토 기준선과 달라지면 영향받은 문서와 재검토 항목을 보고한다. 새 위치의 미분류 소스는 보수적으로 20종 전체에 연결한다. 문서의 법률 문구나 사업 사실을 자동으로 만들어 확정하지 않는다.

파이프라인은 이 PR을 기본 브랜치에 병합하고 GitHub Actions가 허용되어야 기본 브랜치에서 지속 실행된다. 필수 상태 검사와 브랜치 보호 설정은 저장소 관리자가 별도로 적용한다. 현재 브랜치에서 수행한 검증 범위는 [PIPELINE.md](PIPELINE.md)의 로컬 실행과 GitHub 실행 결과를 각각 확인한다.

## Word 문서와 별도 양식 재생성

저장소의 20개 문서를 원본으로 사용한다. 아래 도구는 수정 가능한 Word 본문 20개, 별도 Word 작성 양식 20개와 같은 내용의 양식 Markdown, 검색·인쇄용 통합 HTML, 치환필드 목록, 원본·파이프라인과 점검 결과를 ZIP으로 묶는다. 양식은 각 문서의 `양식` 절에서 추출하므로 두 원본을 따로 관리하지 않는다. 출력 폴더는 체크아웃 밖의 새 경로여야 한다.

```bash
python -m pip install "python-docx==1.2.0"
python -m tools.compliance.check --check
python -m tools.compliance.export --output /tmp/quantgen-compliance-delivery
python -m tools.compliance.verify --directory /tmp/quantgen-compliance-delivery
```

Word 생성 의존성은 문서 내보내기용이며 제품 실행·자동 정합성 검사에는 필요하지 않다. 치환필드 목록 `FIELD_INDEX.csv`에는 빈값만 있으며 실제 개인정보를 입력한 요청서는 저장소에 반영하지 않는다. 생성물의 `MANIFEST.json`으로 문서 원본과 파일 해시를 대조할 수 있다. 생성된 Word·HTML을 직접 수정하기보다는 저장소 원본을 고친 뒤 다시 생성한다. Word 표와 페이지 배치는 설치된 글꼴·편집기에 따라 달라질 수 있다.

GitHub에서 받으려면 문서 점검 Actions의 성공 실행을 열고 **Artifacts → QUANTGEN_Compliance_20_Documents-실행ID-시도번호**를 누른다. GitHub 로그인이 필요하며 기존 저장소 접근 권한이 적용된다. 보관기간은 30일이다. 실행 요약에도 실제 다운로드 링크가 표시된다. 다운로드 ZIP에는 Word 본문 20개와 별도 Word 양식 20개가 들어 있다. 로컬·클라우드 내부 `/workspace/...` 경로는 사용자 PC에서 저장할 수 있는 다운로드 첨부가 아니다.
