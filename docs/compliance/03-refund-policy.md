## 적용 범위와 현재 상태

현재 확인한 QUANTGEN 실행 코드에는 자체 서비스 요금 결제·정기구독·해지·환불 처리 흐름이 없습니다. 상업 출시 의사와 실제 유료 계약·결제 개시는 구분합니다. 아래 정책은 대한민국 소비자 대상 온라인 판매를 할 때 사용할 문안과 처리 양식이며, 실제 계약 유형·상품 공급 방식·판매 국가·사업자·결제대행사·가격을 확정한 후 적용합니다.

분석 화면에 입력하는 수수료·슬리피지·`Cost bp/side`는 연구 계산의 가정입니다. QUANTGEN 프로그램 이용료나 실제로 사용자에게 부과한 수수료가 아닙니다. 외부 API·AI 제공자가 직접 청구하는 비용에는 해당 제공자 계약이 적용되며, 운영자가 받은 서비스 대금과 구분하여 안내해야 합니다.

## 정책 또는 구현 기준

### 이용자에게 공개할 정책

**판매자와 상품.** (주)넥스트제너레이션은 {{pricing.plan_name}}을 {{pricing.total_price_and_currency}}에 제공합니다. 제공 기간, 포함 기능, 결제 주기, 자동 갱신 여부, 외부 API 별도 비용은 구매 화면과 계약 확인서에 표시합니다. 문의·청약철회·해지는 {{operator.support_email}} 또는 {{billing.cancellation_url}}로 신청할 수 있습니다. 미구현 URL을 작동하는 경로로 표시하지 않습니다.

**법정 청약철회.** 전자상거래법이 적용되는 계약은 원칙적으로 계약내용에 관한 서면을 받은 날부터 7일 이내에 철회할 수 있으며, 공급이 더 늦으면 공급받거나 공급이 시작된 날을 기준으로 법정 기간을 계산합니다. 서면 미교부·주소 누락·청약철회 방해가 있는 경우에는 법에서 정한 별도 기산점을 적용합니다. 운영자가 더 유리하게 정한 조건은 {{billing.additional_refund_benefit}}에 명시합니다.

**디지털콘텐츠·용역 제공 개시.** 공급 개시로 청약철회가 제한되는지 상품별로 판단합니다. 제한을 적용하려면 법정 요건에 맞게 구매 전에 명확히 표시하고, 디지털콘텐츠에는 시험 사용 등 권리 행사가 방해받지 않도록 하는 조치를 함께 제공합니다. 가분적 콘텐츠·용역은 아직 제공되지 않은 부분의 권리를 별도로 검토합니다. 프로그램 실행·로그인·다운로드 한 번을 근거로 모든 환불·하자 권리를 일괄 소멸시키지 않습니다. 법정 예외 요건을 입증할 수 없으면 제한을 적용하지 않습니다.

**표시·광고 또는 계약과 다른 제공.** 계약 내용과 다르게 제공되거나 표시·광고와 다른 경우에는 공급받은 날부터 3개월 이내 및 그 사실을 알았거나 알 수 있었던 날부터 30일 이내라는 법정 기간을 적용합니다. 단순 변심 제한과 별개로 판단하며, 이미 사용했다는 이유만으로 하자에 관한 권리를 배제하지 않습니다.

**해지와 자동 갱신.** 정기구독을 실제 제공하는 경우 {{billing.renewal_and_cancellation_terms}}에 따라 다음 결제를 중단할 수 있습니다. 해지 접수 경로·효력 발생일·남은 이용 기간·환불액을 구분하여 안내합니다. 자동 갱신 중단을 신청한 이용자를 추가 설득 화면, 숨겨진 연락처 또는 가입보다 현저히 어려운 절차로 붙잡지 않습니다. 현재 정기구독을 제공하지 않으면 이 항목은 “정기구독 미제공”으로 확정합니다.

**환급 시점과 방법.** 유효한 청약철회에 대해 용역·디지털콘텐츠를 공급한 경우 또는 아직 공급하지 않은 경우에는 법정 철회일부터 3영업일 이내에 법에 따라 환급합니다. 환불 승인 내부 결재일을 임의로 기산점으로 삼지 않습니다. 해당 결제수단의 청구 정지·취소를 지체 없이 요청하고 처리 결과를 알립니다. 결제사 정산 소요와 운영자의 환급 의무를 구분하고, 지연이 발생하면 적용되는 지연배상금 등을 검토합니다.

**공제와 장애.** 법정 철회·하자 환급에 임의 위약금·정액 수수료를 부과하지 않습니다. 그 밖의 해지에서 이미 제공한 가분적 서비스 등의 공제를 적용하려면 법적·계약상 근거, 산식, 사용량·기간 증거를 확인하여 사전에 설명합니다. 중복 결제·미제공·중대한 기능 하자·운영자 귀책 장애는 원인과 영향을 확인하고 법정·계약상 구제를 제공합니다. 연구 결과가 기대 수익에 미달한 경우와 약속한 기능을 제공하지 못한 경우를 구분합니다.

**이의제기.** 환불 거절·일부 환급 시 근거, 계산, 적용 조항과 이의제기 경로를 알려드립니다. 본 정책으로 소비자에게 보장된 강행법규상 권리를 제한하지 않습니다. 분쟁이 해결되지 않으면 관계 법령에 따른 소비자 분쟁조정 등의 경로를 안내합니다.

다음은 최소 항목의 신청 양식입니다. API 키·비밀번호·잔고·신분증 전체 사본·카드 전체 번호를 요구하지 않습니다.

| 필드 | 입력 안내 |
| --- | --- |
| 회신 이메일 또는 이용 중인 문의 경로 | {{request.reply_contact}} |
| 주문/결제 식별번호 | {{request.order_id}}; 영수증은 민감 결제정보를 가림 |
| 상품·결제일·결제액 | {{request.product}} / {{request.paid_at}} / {{request.amount}} |

| 공급일·하자 인지일 | 알고 있는 범위. 사용자가 알 수 없는 서버 기록은 운영자가 확인 |

## 검증과 변경 시 재검토

- **통과:** 실제 상품별 공급 개시 사건, 계약 서면, 체험·예외 고지, 환불 신청·접수·결제 취소·통지가 연결되며 합성 주문으로 미공급·단순 변심·하자·갱신 중단을 각각 검증했습니다.
- **차단:** 무조건적 환불 불가, 전체 권리 포기 동의, 공급 기록·예외 증거 부재, 판매자·가격·접수 경로 미확정, 법정 기산점 대신 내부 승인일 적용입니다.
- 금액 산정 사례는 수치와 계산식을 검토한 뒤 정책에 추가합니다. 미확정된 일할 공제·취소 수수료를 이 문서가 승인한 것으로 취급하지 않습니다.
- 결제사·판매 국가·영구 라이선스/구독 구조·무료 체험·공급 단위·할인·가격·지원 기능·법령 변경 시 재검토합니다.
