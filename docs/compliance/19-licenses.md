# 19. 이미지·폰트·소프트웨어·데이터 권리 관리 정책 및 대장

문서 ID: QG-C19 · 버전: 1.7 · 검토일: 2026-11-04 · 상태: review-required

## 적용 범위와 현재 상태

QUANTGEN의 이미지·브랜드·아이콘·폰트, 설치물에 포함하는 소프트웨어와 전이 의존성, 금융 데이터·문서·AI 출력의 이용·표시·배포·내보내기에 적용한다. 원래 사진의 이미지·폰트 항목을 실제 금융 연구 제품의 배포 범위에 맞춰 확장했다.

- 현재 네이티브 QG Interface는 Gothic A1 기반 hinted TrueType 400/500/600이며, 누락 기호는 Pretendard 기반 QG Symbols로 보충한다. Flet의 기존 Pretendard OTF는 유지한다. 각각 SIL OFL 1.1이다. `assets/fonts/README.txt`에 출처·원본/동봉 SHA256·재생성 명령이 있고 현재 `OFL.txt`와 이전 Noto 고지 `OFL-Noto-legacy.txt`를 구분한다. 실제 배포물의 고지 포함 여부는 따로 검사한다.
- `assets/branding/`의 SVG, 아이콘·로고 PNG는 저장소에 있지만 파일별 창작·양도·허락 근거를 확인하지 못했다. 존재 자체를 상업적 이용 허락으로 간주하지 않는다. `assets/manifest.json`은 웹 앱 구성 파일이며 권리 대장이 아니다.
- `pyproject.toml`은 선택 의존성으로 PyQt6 6.12.0을 지정한다. 배포 방식에 맞는 GPL 의무 준수 또는 유효한 상업 라이선스 등의 선택·검토 증거가 필요하다. 상업 소프트웨어라는 사실만으로 반드시 상업 라이선스만 가능한 것으로 단정하지 않는다.
- 금융 데이터 API 접근 가능 여부와 상업적 화면 표시·재배포·다운로드 허락은 다르다. 네이티브 시장 화면도 데이터 권리가 미검증이라고 표시한다. 공급자별 계약과 실제 사용 범위를 확정해야 한다. FRED는 제삼자 제공 계열도 포함하므로 FRED에 공개되어 있다는 이유로 모든 계열의 상업 이용을 허용된 것으로 처리하지 않는다.
- 현행 프로젝트 버전의 모든 직접·전이 의존성에 대한 라이선스 검토가 완료되었다는 증거는 없다.

### 2026-10-31 앱 UI 변경 검토

시장 표시 검토는 Home 6개·등록 계열 73개·제공 정책 13개를 추적하고 사용 가능/조건 충족 후 가능/대체 필요/추가 확인을 구분합니다. 현재 무조건 사용 가능 판정은 없고 게시 승인이나 법률 의견이 아닙니다. 교육 자료의 계열별 출처와 Babel/Unicode 고지 사항을 아래에 추가하며 전체 상업 배포권 확보로 확대하지 않습니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

C형 후속은 기존 차트 렌더러·브랜드 자산·동봉 글꼴을 재사용합니다. 새로운 앱 배포 의존성을 추가하지 않았습니다. 로컬 확인에만 사용한 Chromium/Playwright는 제품 배포 의존성이나 데이터 이용권 증거가 아닙니다.

### 2026-11-02 KIS 차트·WebSocket 의존성

KIS 동적 REST/WS 시세·차트와 새 필수 패키지 `websockets>=15,<17`을 추가했습니다. 통합 검토의 지정 개발 인터프리터가 확인한 설치본 16.0의 `METADATA`는 `License-Expression: BSD-3-Clause`이며 `Requires-Dist` 항목이 없습니다. 해당 배포본의 `licenses/LICENSE` 원문도 대조했습니다. PR #57은 당시 별도 프로젝트 가상환경에서 16.1.1의 같은 라이선스 메타데이터·원문을 확인한 기록을 남겼습니다. 각 환경·시점별 증거를 구분하고 한 버전을 전체 현재 설치본으로 단정하지 않습니다. 현재 그 별도 환경에서 발견한 17.3은 선언 범위 밖이며 해당 환경을 이 통합의 의존성 충족 증거로 사용하지 않습니다. 환경이나 의존성 선언을 이 문서가 변경하지 않습니다.

새 차트는 기존 자산·글꼴을 재사용합니다. 기존 Home 6개·등록 계열 73개 검토 숫자에 모든 신규 동적 종목·거래소·실시간 구독권이 포함된 것으로 간주하지 않습니다. 개인 계정·무료/지연 시세·메모리 처리·지표 계산·첨부 사양·API 접속·배율 확인 또는 소프트웨어 라이선스가 제3자 앱/브라우저 상업 표시·다중 사용자 전달·재배포·가공 권리를 부여하지 않습니다. [별도 차트 권리 범위](../product/MARKET_DISPLAY_RIGHTS_2026-10-31.md#kis-chart-scope-2026-11-02)에 미확정 이용권을 기록하며 실제 릴리스 버전·해시·전이 의존성·최종 설치물 고지 포함 여부도 별도로 확인합니다.

이 절은 양쪽 소스·문서 검토를 통합한 사실 기록이며 `review-required`와 운영 증빙의 미확정 상태를 유지합니다. 법률 검토·공개 승인·실제 배포 검증이 아닙니다.

### 2026-11-02 Home 시세·Q-SCORE 후속 검토

Home의 추가 국내주식 시세·수정 일별 이력·실시간 목록과 파생 Q-SCORE는 KIS 자료의 내부 계산·화면 표시·파생값·상업적 전달 범위를 따로 확인해야 합니다. 점수를 계산하거나 기존 NumPy·기술신호·위험 엔진을 재사용했다는 사실이 시장자료의 상업 사용·재배포 허락을 새로 부여하지 않습니다.

이번 표시·계산 변경은 기존 브랜드·글꼴·의존성을 재사용하며 새로운 라이선스 확보를 주장하지 않습니다. 기존 Home 6개 거시계열과 등록 계열 73개의 검토 목록이 새 6개 국내주식과 점수의 계약·권리 확인까지 완료한 목록인 것으로 해석하지 않습니다.

소스·문서 정합성 검토이며 기존 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. 법률 의견·공개 승인·실제 계정 연결·Windows 수동 검증이 아닙니다.

### 2026-11-02 종목 정보·글꼴 확장 후속

당시 도입한 글꼴(현재 Flet 및 기호 보충 원본)은 Pretendard1.3.9의 Regular400·Medium500·SemiBold600을 서브셋하고 QG Interface로 이름을 바꾼 파생물입니다. 원본은 `orioncactus/pretendard`의 고정 커밋 `5c41199ea0024a9e0b2cb31735265056e5472d76`이며 원본/동봉 해시·재생성 명령·귀속은 [글꼴 README](../../assets/fonts/README.txt)에 기록합니다. 예약 이름 Pretendard를 파생물의 기본 가족 이름으로 사용하지 않고 기존 가족 참조를 유지합니다.

현재 원본 [OFL.txt](../../assets/fonts/OFL.txt)는 Copyright2021 KilHyung-jin·예약명 Pretendard와 SIL OFL1.1을 담습니다. 글꼴 내부의 원래 저작권·라이선스 기록을 보존하고, 단독 판매 금지·저작권/라이선스 동봉·파생물의 동일OFL·예약명·권리자 추천 표현 제한을 지킵니다. 이전 Noto 기반 자산의 고지는 [OFL-Noto-legacy.txt](../../assets/fonts/OFL-Noto-legacy.txt)로 이력을 보존합니다. 실제 패키지에 세 글꼴과 해당 고지가 포함되는지는 빌드 검증으로 따로 확인합니다.

PER/EPS·업종·상장주수 필드 확인과 가격×상장주수 계산은 시장자료의 상업 표시·저장·파생/재배포 허락을 새로 부여하지 않습니다. 원시 HTS 시가총액 단위와 재무기간/희석 기준은 미검증 상태로 유지합니다. 폰트·필드 출처 확인을 전체 앱·소개사이트 권리 승인이나 실제 배포로 확대하지 않습니다.

소스·문서 정합성 검토이며 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. [최종 범위와 검증 기록](../product/HOME_COMPACT_REVIEW_20261102.md)을 참조합니다.

### 2026-11-02 네이티브 수신 체결봉·선택 지표 후속

수신 체결을 틱/초봉과 지표로 가공해 표시하는 범위가 추가되지만 기존 KIS/거래소 자료 이용권을 새로 승인하지 않습니다. API 지원·사용자 키·무료/지연 피드·메모리 처리·분석 계산은 제3자 앱/브라우저의 상업 표시·재배포·보관·파생값 이용 허락과 별개입니다. 미국 시장센터 한정 피드와 해외 지연, 모의/시장별 지원 제한을 유지합니다.

새 외부 데이터 endpoint·글꼴·SDK·AI 제공자·주문 기능을 추가하지 않습니다. PR61의 Pretendard 기반 QG Interface Regular/Medium/Semibold와 OFL·기존 자산 고지를 보존합니다. 토스증권의 간결한 가격 우선 정보 구조를 참고하는 것은 해당 브랜드·소스·시세·이미지의 복제/제휴 근거가 아닙니다.

[실제 지원·20종 영향 검토](../product/CHART_RECEIVED_BARS_REVIEW_20261102.md)를 따릅니다. 기존 `review-required`·공개 준비 `BLOCKED`와 미확정 계약/운영 사실을 유지하며 공개 승인·실계정 검증을 뜻하지 않습니다.

### 2026-11-04 꺾쇠 SVG

`assets/ui/`의 꺾쇠 SVG 8개(아래·위·왼쪽·오른쪽 × 밝은·어두운 테마)는 이 저장소에서 만든 12×12 선 경로이며 외부 아이콘 세트를 복사하지 않았습니다(`2349132`). `pyproject.toml`의 `share/quantgen/assets/ui`로 설치물에 넣습니다. 설치물에서 실제로 그려지는지는 미검증입니다. 새 글꼴·굵기·SDK·다운로드는 없습니다. 화면의 KIS/KRX 종목 이름과 투자자별 매매·공매도 자료의 표시 권리는 기존 `kis_krx` `rights_conditional` 그대로이며 이 변경이 이용권을 승인하지 않습니다. [변경 사실](FACTS.md#markets-watchlist-2026-11-04)을 따릅니다.

1. 자산·의존성·데이터마다 식별자, 버전·해시, 출처, 권리자, 허락 근거, 허용 범위, 의무, 담당자를 기록한다. 인터넷에 공개되어 있다는 이유로 복제·상업 이용·재배포를 허용된 것으로 처리하지 않는다.
2. 이미지·로고는 자체 제작·양도 계약·허용 라이선스 등 근거를 확보한다. 인물·상표·제삼자 요소에 별도 권리가 필요한지도 확인한다. 구매 영수증만으로 모든 이용 범위가 허락되었다고 단정하지 않는다.
3. 폰트는 수정·이름 변경·임베딩·웹 배포·동봉 고지 조건을 확인한다. QG Interface는 출처·OFL 고지와 수정 기록을 유지하고 실제 wheel·설치물·배포 자산을 대조한다.
4. 소프트웨어는 직접 의존성뿐 아니라 실제 배포되는 전이 패키지·Qt 구성요소·플러그인도 목록화한다. 고지·소스 제공·동일 라이선스 등 조건과 상업 계약의 적용 범위를 릴리스별로 검토한다.
5. 데이터는 내부 계산, 최종 사용자 표시, 원자료·파생자료 재배포, 캐시 보관, CSV·JSON·보고서 내보내기, AI 입력의 권한을 따로 확인한다. API 키·무료 요금제·개인 계정이 해당 권한을 자동으로 부여하지 않는다. FRED는 실제 사용하는 계열 ID별로 원제공자·저작권·재배포 조건을 기록하고, 출처 표시만으로 별도 허락이 필요한 이용을 대신하지 않는다.
6. AI 생성 자산·텍스트도 실제 이용하는 API 또는 상품의 약관, 입력 권한, 제삼자 권리·표절·출처 문제를 검토한다. API용 상업 약관과 일반 소비자 서비스 약관을 혼동하지 않고, 외부 데이터의 AI 전송 권한을 따로 확인한다. 생성되었다는 이유만으로 독점권·무침해를 보장하지 않는다.
7. 권리가 불명확·만료·충돌한 자료는 허용 범위를 확인할 때까지 해당 배포·표시·내보내기 범위에서 제외하거나 대체한다. 확인되지 않은 상태를 `허용`으로 바꾸지 않는다.
8. 계약·영수증·계정 정보 등 비공개 증거는 공개 저장소에 넣지 않는다. 이 대장에는 비공개 위치·문서 ID·해시·검토 결과만 남긴다.

## 검증과 변경 시 재검토

- **통과:** 해당 릴리스가 실제 사용하는 모든 항목의 권한·조건과 배포물 고지를 확인했고 사용 범위가 허락 범위를 넘지 않는다. 조건부 항목은 필요한 의무의 이행 증거가 있다.
- **실패:** 무단 이미지·폰트, 필수 고지 누락, 라이선스와 충돌하는 배포, 미허용 데이터 재배포가 확인된다.
- **미실행·보류:** 자산 출처·계약·전이 의존성·배포물 검증이 없다. 자동으로 라이선스 문자열을 수집한 것만으로 권리 확보를 승인하지 않는다.
- 이미지·폰트·패키지 버전·빌드 방식·데이터 공급자·요금제·상업화 범위·내보내기·AI 입력이 바뀌면 재검토한다. 파일 목록·해시·계약 만료 검사는 자동화하고 권한 해석·계약 승인은 별도 검토로 남긴다.
