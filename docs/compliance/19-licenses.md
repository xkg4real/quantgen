# 19. 이미지·폰트·소프트웨어·데이터 권리 관리 정책 및 대장

문서 ID: QG-C19 · 버전: 1.0 · 검토일: 2026-10-31 · 상태: review-required

## 적용 범위와 현재 상태

QUANTGEN의 이미지·브랜드·아이콘·폰트, 설치물에 포함하는 소프트웨어와 전이 의존성, 금융 데이터·문서·AI 출력의 이용·표시·배포·내보내기에 적용한다. 원래 사진의 이미지·폰트 항목을 실제 금융 연구 제품의 배포 범위에 맞춰 확장했다.

- `assets/fonts/README.txt`는 QG Interface가 Noto Sans CJK KR의 이름을 바꾼 서브셋이며 SIL OFL 1.1이라고 기록한다. 출처·원본 SHA256·재생성 명령과 `OFL.txt`가 있다. 실제 배포물에도 해당 고지가 포함되는지 검사해야 한다.
- `assets/branding/`의 SVG, 아이콘·로고 PNG는 저장소에 있지만 파일별 창작·양도·허락 근거를 확인하지 못했다. 존재 자체를 상업적 이용 허락으로 간주하지 않는다. `assets/manifest.json`은 웹 앱 구성 파일이며 권리 대장이 아니다.
- `pyproject.toml`은 선택 의존성으로 PyQt6 6.12.0을 지정한다. 배포 방식에 맞는 GPL 의무 준수 또는 유효한 상업 라이선스 등의 선택·검토 증거가 필요하다. 상업 소프트웨어라는 사실만으로 반드시 상업 라이선스만 가능한 것으로 단정하지 않는다.
- 금융 데이터 API 접근 가능 여부와 상업적 화면 표시·재배포·다운로드 허락은 다르다. 네이티브 시장 화면도 데이터 권리가 미검증이라고 표시한다. 공급자별 계약과 실제 사용 범위를 확정해야 한다. FRED는 제삼자 제공 계열도 포함하므로 FRED에 공개되어 있다는 이유로 모든 계열의 상업 이용을 허용된 것으로 처리하지 않는다.
- 현행 프로젝트 버전의 모든 직접·전이 의존성에 대한 라이선스 검토가 완료되었다는 증거는 없다.

## 정책 또는 구현 기준

1. 자산·의존성·데이터마다 식별자, 버전·해시, 출처, 권리자, 허락 근거, 허용 범위, 의무, 담당자를 기록한다. 인터넷에 공개되어 있다는 이유로 복제·상업 이용·재배포를 허용된 것으로 처리하지 않는다.
2. 이미지·로고는 자체 제작·양도 계약·허용 라이선스 등 근거를 확보한다. 인물·상표·제삼자 요소에 별도 권리가 필요한지도 확인한다. 구매 영수증만으로 모든 이용 범위가 허락되었다고 단정하지 않는다.
3. 폰트는 수정·이름 변경·임베딩·웹 배포·동봉 고지 조건을 확인한다. QG Interface는 출처·OFL 고지와 수정 기록을 유지하고 실제 wheel·설치물·배포 자산을 대조한다.
4. 소프트웨어는 직접 의존성뿐 아니라 실제 배포되는 전이 패키지·Qt 구성요소·플러그인도 목록화한다. 고지·소스 제공·동일 라이선스 등 조건과 상업 계약의 적용 범위를 릴리스별로 검토한다.
5. 데이터는 내부 계산, 최종 사용자 표시, 원자료·파생자료 재배포, 캐시 보관, CSV·JSON·보고서 내보내기, AI 입력의 권한을 따로 확인한다. API 키·무료 요금제·개인 계정이 해당 권한을 자동으로 부여하지 않는다. FRED는 실제 사용하는 계열 ID별로 원제공자·저작권·재배포 조건을 기록하고, 출처 표시만으로 별도 허락이 필요한 이용을 대신하지 않는다.
6. AI 생성 자산·텍스트도 실제 이용하는 API 또는 상품의 약관, 입력 권한, 제삼자 권리·표절·출처 문제를 검토한다. API용 상업 약관과 일반 소비자 서비스 약관을 혼동하지 않고, 외부 데이터의 AI 전송 권한을 따로 확인한다. 생성되었다는 이유만으로 독점권·무침해를 보장하지 않는다.
7. 권리가 불명확·만료·충돌한 자료는 허용 범위를 확인할 때까지 해당 배포·표시·내보내기 범위에서 제외하거나 대체한다. 확인되지 않은 상태를 `허용`으로 바꾸지 않는다.
8. 계약·영수증·계정 정보 등 비공개 증거는 공개 저장소에 넣지 않는다. 이 대장에는 비공개 위치·문서 ID·해시·검토 결과만 남긴다.

## 검증과 변경 시 재검토

- **통과:** 해당 릴리스가 실제 사용하는 모든 항목의 권한·조건과 배포물 고지를 확인했고 사용 범위가 허락 범위를 넘지 않는다. 조건부 항목은 필요한 의무의 이행 증거가 있다.
- **실패:** 무단 이미지·폰트, 필수 고지 누락, 라이선스와 충돌하는 배포, 미허용 데이터 재배포가 확인된다.
- **미실행·보류:** 자산 출처·계약·전이 의존성·배포물 검증이 없다. 자동으로 라이선스 문자열을 수집한 것만으로 권리 확보를 승인하지 않는다.
- 이미지·폰트·패키지 버전·빌드 방식·데이터 공급자·요금제·상업화 범위·내보내기·AI 입력이 바뀌면 재검토한다. 파일 목록·해시·계약 만료 검사는 자동화하고 권한 해석·계약 승인은 별도 검토로 남긴다.
