# 13. 이미지·차트 대체 정보 기준 및 대체 텍스트 양식

문서 ID: QG-C13 · 버전: 1.5 · 검토일: 2026-11-02 · 상태: review-required

## 적용 범위와 현재 상태

Flet 이미지·차트, PyQt6의 직접 그리기 차트, 브랜드 아이콘, 공개 보고서·웹 이미지에 적용한다. 의미 있는 비텍스트 정보를 보조기술을 통해 이해할 수 있어야 한다.

- Flet 브랜드 이미지는 `main.py`의 `semantics_label`을 사용한다.
- `ui/qcharts.py`의 공통 `_to_image()`는 C형 FigureStudy를 통해 제목 기반 이미지 이름과 축·범례·한계 읽기 영역을 제공한다. `fcharts.py`와 `xcharts.py`도 이 생성기를 사용한다. 제목·범례만으로 모든 관측값과 관계의 동등한 대체 정보가 충족되는 것은 아니다.
- Qt 차트에는 차트 종류를 나타내는 접근성 이름이 일부 있다. SignedBars는 이름에 값을 포함하지만, 다른 차트의 동적 수치·동등한 표 제공까지 확인된 것은 아니다.
- 이 문서는 수정 기준과 검증 양식이다. 현재 모든 이미지·차트의 대체 정보가 구현되었다고 주장하지 않는다.

### 2026-10-31 앱 UI 변경 검토

새 공통 교육/Signals SVG에는 title·desc와 커서 값·선택일 해석을 제공하고 네이티브에는 접근성 이름과 키보드 커서를 추가했습니다. C형 후속의 기존 이미지 읽기 영역 보완은 아래에 구분합니다. 실제 스크린리더 동등성은 미실행으로 유지합니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

C형 후속은 공통 Flet 이미지에 차트 제목 기반 semantics_label과 축·범례·한계의 읽기 영역을 추가합니다. 교육 SVG의 한글 글꼴 참조를 단일 등록 가족 QG Interface로 수정했습니다. 로컬 Chromium에서 표시를 확인했지만 이미지의 모든 데이터가 동등하게 읽힌다는 스크린리더 판정은 아닙니다.

### 2026-11-02 KIS 차트 대체 정보

새 [공통 시세 SVG](../../core/market/presentation.py)는 캔들·거래량·SMA20·볼린저밴드·RSI14·MACD를 표시합니다. SVG에는 일반적인 `title`이 있지만 `desc`나 전체 관측값의 동등한 표는 없습니다. [Flet](../../ui/market_chart_page.py)의 종목·주기 이미지 이름·선택 봉 OHLCV 텍스트/tooltip과 [Qt](../../quantgen_desktop/market_chart.py)의 접근성 이름·선택 봉 OHLCV 설명·커서 값을 함께 점검합니다. 공급원·단위·시장/수신 시각·지연·부분 이력·미확정 값·수신 공백도 인접 문자로 전달합니다. 지표 수치는 최신 봉 기준이며 과거 커서 봉의 지표라고 설명하지 않습니다.

제한된 수치 대안의 존재는 전체 시계열·지표 관계의 동등한 대체 표나 실제 스크린리더 읽기 검증을 의미하지 않습니다. 종목·주기·언어·오래된 값/오류 상태별 동등성, Windows와 배포 브라우저 보조기술 수용은 미실행으로 유지합니다. [KIS 검증 범위](../product/KIS_MARKET_CHARTS_2026-11-02.md)를 참조합니다.

이 절은 양쪽 소스·문서 검토를 통합한 사실 기록이며 `review-required`와 운영 증빙의 미확정 상태를 유지합니다. 법률 검토·공개 승인·실제 배포 검증이 아닙니다.

### 2026-11-02 Home 시세·Q-SCORE 후속 검토

네이티브 Home의 큰 카드 대신 종목·시세·변화·상태·출처/시각과 Q-SCORE를 표의 텍스트 셀로 제공합니다. 행 상세 창에는 기존 조회 수치·단위·출처와 연결 한계를 텍스트로 표시하며, 별점은 수치·산정 상태·방법 설명과 함께 제시합니다. 방법 도움말 버튼이 있어 별 모양 또는 마우스 tooltip만으로 의미를 전달하지 않습니다.

이 표와 상세 읽기는 새로운 Home 목록의 수치 대안이며 기존 차트 전부의 동등한 표나 실제 스크린리더 발화를 확인한 것은 아닙니다. 표 선택·새 체결 갱신·상세 창·실패 상태에서 이름과 현재값이 일치하는지 별도로 검사합니다. 기술지표 가이드가 독립 메뉴로 이동해도 그 설명과 보고서의 의미를 바꾸지 않습니다.

소스·문서 정합성 검토이며 기존 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. 법률 의견·공개 승인·실제 계정 연결·Windows 수동 검증이 아닙니다.

### 2026-11-02 Home compact 후속 검토

Home의 Q-SCORE 열 제목 옆 `?`는 접근성 이름이 있는 실제 버튼입니다. hover 요약 외에 클릭·Enter·Space로 스크롤 가능한 소개·한계 본문을 열 수 있으므로 마우스 tooltip만으로 의미를 전달하지 않습니다. 44px 행에서도 종목·수치·상태·출처와 상세 조회를 유지하고 오류를 빈 값이나 정상 별점으로 대체하지 않습니다. 웹·Flet·스크린리더의 전체 동등성 검증으로 확대하지 않습니다.

소스·문서 정합성 검토이며 `review-required`와 공개 준비 `BLOCKED`를 유지합니다. [변경 근거와 20종 대조](../product/HOME_COMPACT_REVIEW_20261102.md)를 참조합니다.

## 정책 또는 구현 기준

1. 정보를 전달하는 이미지는 목적·의미를 설명하는 이름을 가진다. 파일명, `차트`, `이미지`만으로 설명을 끝내지 않는다. 버튼 이미지는 모양보다 수행하는 동작을 설명한다.
2. 장식용 이미지는 보조기술에서 적절히 제외한다. 인접한 텍스트가 같은 정보를 완전히 제공하는 로고도 중복 읽기를 고려하되, 의미 있는 단독 이미지를 일괄 장식 처리하지 않는다.
3. 복잡한 차트에는 짧은 이름과 별도의 상세 설명·데이터 표를 제공한다. 종목, 데이터 출처, 관측 기간, 축·단위, 계열·구간 의미, 핵심 수치와 불확실성을 전달한다. 원자료를 노출할 때는 데이터 이용 권한도 확인한다.
4. 시뮬레이션 차트는 과거 관측과 미래 시뮬레이션, 합성 데이터, P5·P50·P95의 의미를 구분한다. 방향·색상만으로 정보를 전달하지 않는다.
5. Qt에서 직접 그린 픽셀의 의미가 자동으로 전달된다고 가정하지 않는다. 접근성 이름 외에 값과 상태를 읽을 수 있는 결과 텍스트·표를 함께 제공한다.
6. 데이터·종목·단위·모델이 바뀌면 대체 정보도 갱신한다. 로딩·실패·미실행에는 이전 결과를 현재 결과처럼 읽지 않게 한다.
7. 보고서의 HTML·문서 이미지에도 같은 의미의 대체 정보를 유지한다. CSV 다운로드만으로 화면상 필수 정보의 접근성을 전부 대체하지 않는다.

동적 차트 설명 양식:

> {{analysis.symbol}} 가격 시뮬레이션. 모델 {{analysis.model}}, 예측 기간 {{analysis.horizon_sessions}}거래일, 가격 단위 {{analysis.currency}}. 중앙선은 P50, 음영은 P5–P95와 P25–P75입니다. 이는 미래 수익 보장이나 95% 신뢰구간이 아닙니다. 데이터 출처 {{analysis.source}}, 최종 관측일 {{analysis.observation_date}}, 합성 여부 {{analysis.synthetic_status}}. 구간별 값은 아래 결과 표에서 확인할 수 있습니다.

이 예시는 실제 결과 필드를 넣는 설계 양식이다. 실제로 존재하지 않는 `아래 결과 표`를 구현 전 안내하지 않는다.

## 양식

이미지·차트별로 다음 대장을 작성한다. 동적 차트는 생성기와 표시 화면을 모두 적는다.

| 필드 | 작성 내용 |
|---|---|
| 대체 정보 ID / 화면 / 플랫폼 | QG-ALT-번호 / 화면 경로 / Flet·Qt·보고서 |
| 자산·생성기 / 코드 경로 | 정적 파일 또는 함수·클래스·호출 화면 |
| 목적 / 정보·장식·동작 구분 | 사용자가 이 요소에서 알아야 할 내용 |
| 짧은 접근성 이름 | 실제 보조기술에 제공할 문자열·동적 필드 |
| 상세 설명 / 축·단위 / 데이터 기간 | 시각적 의미와 주요 수치·한계 |
| 동등한 표·텍스트 / 접근 경로 | 키보드·화면 읽기로 도달 가능한 위치 |
| 데이터 변경·오류 시 갱신 규칙 | 이전 설명 제거·새 상태 반영 방식 |
| 원자료 표시 권리 | 19번 권리 대장 ID, 공개 가능한 데이터 범위 |
| 검증 환경 / 읽힌 결과 / 증거 | OS·앱·보조기술 버전과 실제 발화·화면 기록 |
| 판정 / 수정 담당 / 기한 | 통과·실패·미실행·미적용과 사유 |

초기 결함 추적 대상은 Flet `_to_image()`의 설명 누락, Qt 차트의 일반적 이름만으로 전달되지 않는 결과 정보, 브랜드·아이콘의 중복 또는 무명 읽기다.

## 검증과 변경 시 재검토

- **통과:** 보조기술 사용자가 이미지 없이 같은 목적의 핵심 정보를 이해하고, 상세 표·설명에 키보드로 접근할 수 있다. 동적 변경과 오류 상태도 일치한다.
- **실패:** 의미 있는 차트가 무명 이미지로 읽히거나, 이름만 있고 필요한 결과 정보가 없거나, 설명이 실제 종목·값·단위와 다르다.
- **미실행:** 정적 속성만 확인했고 실제 브라우저·네이티브 보조기술 테스트를 하지 않았다. 접근성 이름 존재를 전체 WCAG 통과로 바꾸지 않는다.
- 공통 차트 생성기, 차트 계열·축·단위, 새 이미지·내보내기, UI 프레임워크 변경 시 재점검한다. 자동 검사는 누락 후보를 찾고 수동 동등성 확인을 요구한다.
