## 적용 범위와 현재 상태

검토한 QUANTGEN 앱 코드에서 자체 광고·분석 추적 쿠키 또는 방문자 브라우저의 `document.cookie`·`localStorage`를 직접 사용하는 경로는 확인하지 못했습니다. 이것은 Flet·웹서버·리버스 프록시·CDN·호스팅·지원 위젯·외부 의존성에 저장장치가 없다는 뜻이 아닙니다. 실제 운영 URL·브라우저·배포 환경은 별도 검증 대상입니다.

서버 또는 로컬 Python 프로세스에서 yfinance 등이 사용하는 HTTP 쿠키는 방문자 브라우저에 심는 쿠키와 구별합니다. `~/.nextgen`의 KIS 토큰·연구 파일·시계열 캐시는 브라우저 쿠키가 아니며 개인정보 방침과 삭제 절차에서 따로 다룹니다. 데스크톱 화면 자체에 브라우저용 동의 배너를 기계적으로 삽입하지 않습니다. 내장 웹뷰나 외부 웹사이트를 사용하면 그 경로를 별도 평가합니다.

현재 저장소만으로 실제 배포의 쿠키 전체 목록, 만료기간, 필수 여부, 제3자 전송을 확정할 수 없습니다. “쿠키 없음” 또는 “추적하지 않음”이라는 공개 문구는 아래 실행 조사 후에만 확정합니다.

운영자는 대한민국 운영과 Cloudflare 이용을 알렸습니다. 이용 제품·설정·도메인·추가 스크립트·로그는 확인되지 않았으므로 Cloudflare의 기능을 모두 사용한다고 추정하거나 특정 쿠키를 실제 사용 목록에 임의로 넣지 않습니다. 실제 배포 구성에서 최초 접속과 선택 전후의 저장·전송을 조사합니다.

### 2026-10-31 앱 UI 변경 검토

네이티브 ui/language·ui/locale은 Qt의 로컬 애플리케이션 설정이며 방문자 브라우저 쿠키가 아닙니다. Flet 언어 선택은 page의 세션 상태로 관리합니다. 이번 변경에 광고·분석 추적 SDK나 앱 자체 브라우저 영구 저장 경로를 추가하지 않았으나, 실제 소개사이트·서버·프레임워크 저장 조사는 여전히 별도입니다.

검토 범위와 코드 근거는 [코드 사실 기록](FACTS.md)의 앱 UI 변경 절을 참조합니다. 소스·문서의 정합성 검토이며 상태는 `review-required`를 유지합니다.

C형 차트 후속의 네이티브 ui/theme은 로컬 QSettings 선호 설정입니다. Flet 테마는 page 세션 상태로 유지하며 앱 자체 쿠키·localStorage 저장을 추가하지 않습니다. 이 동작은 quantgeneration.com의 실제 저장장치 조사 결과가 아닙니다.

## 정책 또는 구현 기준

### 공개 정책 문안

(주)넥스트제너레이션은 {{service.web_origins}}에서 서비스를 제공하기 위해 아래에 확정한 쿠키 및 유사 저장장치를 사용합니다. 필수 항목과 선택 항목을 목적별로 구분하며 선택 항목을 거부해도 관계없는 기본 기능을 이용할 수 있습니다. 설정은 {{cookies.preference_location}}에서 변경할 수 있습니다.

| 이름·키 | 종류·도메인/저장 위치 | 설정 주체 | 목적 | 항목/식별정보 | 유지 기간 | 필수·선택 및 근거 |
| --- | --- | --- | --- | --- | --- | --- |
| {{cookies.item_name}} | 쿠키 / localStorage / IndexedDB / 기타 중 실제 종류 | {{cookies.setter}} | {{cookies.purpose}} | {{cookies.fields}} | {{cookies.expiry}} | {{cookies.classification_and_basis}} |

실제 항목마다 행을 추가합니다. 검증하여 사용하지 않는 범주는 “선택적 분석 쿠키 사용 안 함”처럼 범위와 조사일을 명시합니다. 아직 조사하지 않은 항목을 “없음”으로 표시하지 않습니다. 브라우저 세션 종료 시 삭제되는지, 서버가 다른 식별자와 결합하는지, 만료 갱신이 되는지도 확인합니다.

선택적 분석·광고 저장장치를 도입할 경우 목적·제공자·전송 항목·기간·국외 이전을 먼저 확정하고 필요한 선택 전에는 태그·스크립트·네트워크 요청을 실행하지 않습니다. 배너의 수락·거부·설정 버튼과 선택 철회는 [쿠키 선택 설계](05-cookie-consent.md)에 따릅니다. 동의 기록 자체에도 식별정보 최소화와 보유기간을 적용합니다.

사용자는 브라우저의 사이트 데이터 설정으로 쿠키를 조회·삭제·차단할 수 있습니다. 현재 사용 중인 브라우저의 공식 도움말로 안내하며 지원 브라우저별 절차를 {{cookies.browser_help_links}}에 제공합니다. 전체 쿠키 차단으로 필수 연결·설정 유지가 제한될 수 있는 경우 실제 영향을 구체적으로 설명합니다. 선택적 쿠키 거부 때문에 필수 기능이 차단되는지 검증합니다.

쿠키에 개인정보가 포함되거나 수신자에게 이전되는 경우 [개인정보 처리방침](01-privacy-policy.md)과 동일한 수령자·근거·국가·기간을 적용합니다. 쿠키 분류는 특정 법역의 의무를 자동 면제하는 판단이 아닙니다. 판매·접속 대상 국가를 정하고 해당 개인정보·통신 관련 규칙을 검토합니다.

### 조사·분류 절차

1. 운영 URL·앱 버전·Flet 버전·호스팅·프록시·CDN·관측 도구·태그 관리 설정을 목록화합니다. 운영자 권한으로 확인 가능한 설정과 브라우저 관측 결과를 함께 사용합니다.
2. 새 브라우저 프로필에서 접속 전 저장장치를 초기화하고 최초 진입, 동의 전 대기, 거부, 선택 수락, 철회, 새로고침, 새 세션을 각각 확인합니다. 인증·결제·지원 경로가 도입되면 함께 조사합니다.
3. 쿠키와 브라우저 저장소의 이름·설정자·도메인·만료·SameSite·Secure·HttpOnly 등 실제 속성, 네트워크 수신자·유출 가능 항목을 기록합니다. 모든 쿠키가 HttpOnly여야 한다는 식의 일괄 판정 대신 용도별 위협을 평가합니다.
4. 인증/보안상 꼭 필요한 항목, 사용자가 요청한 기능, 선택 분석, 광고·프로파일링을 목적·대안과 함께 분류합니다. “당사에서 쓰므로 필수”는 근거가 아닙니다.
5. 외부 Python HTTP 세션·API 쿠키와 브라우저 방문자 쿠키를 분리하여 대장에 연결합니다. API 응답의 쿠키가 브라우저로 전달되는지 실제 경로를 확인합니다.
6. 필요한 사전 선택, 철회 후 추가 전송 중단·저장정보 제거, 설정 유지 및 설명을 검증한 뒤 공개합니다. 조사 자료는 쿠키 값·세션 토큰을 제거한 형태로 보관합니다.

### 사용자 설정 안내 양식

> QUANTGEN 쿠키 설정은 {{cookies.preference_location}}에서 변경할 수 있습니다. {{cookies.required_purposes}}에 필요한 저장장치와 {{cookies.optional_purposes_or_none}}를 구분합니다. 선택 항목을 거부하거나 철회해도 {{cookies.unaffected_features}}는 계속 이용할 수 있습니다. 브라우저에서 직접 삭제하면 {{cookies.after_browser_deletion}}가 발생합니다.

제공하지 않는 선택 범주를 문구에 남기지 않습니다. 실제 쿠키·토큰 값, 원본 HAR 또는 인증 헤더가 들어간 캡처를 Git에 올리지 않습니다.

## 검증과 변경 시 재검토

- **통과:** 실제 운영 URL의 최초 접속·거부·수락·철회·재접속을 조사했고, 대장·정책·네트워크 동작이 일치합니다. 선택 저장장치가 없으면 그 조사 결과에 맞는 짧은 설명을 제공합니다.
- **차단:** 소스 검색만으로 쿠키 없음 판정, 도메인·기간·수신자 미확정, 미선택 상태의 분석/광고 요청, 필수성 근거 없이 모든 쿠키를 필수로 분류한 경우입니다.
- Flet·웹서버·호스팅·CDN·도메인·지원 도구·분석 SDK·광고·로그인·결제·브라우저 저장 기능을 변경하면 재조사합니다. Python 의존성의 쿠키 변경도 브라우저 전달 여부와 제공자 흐름을 재검토합니다.
- 정적 파이프라인은 변경을 탐지할 수 있지만 실제 배포 브라우저 조사와 동의 전 네트워크 검증을 대신하지 않습니다.
