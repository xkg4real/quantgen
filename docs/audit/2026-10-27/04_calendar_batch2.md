# 달력 감사 2차: kr_sessions · publication_schedules · source_skipped

- **작성:** 2026-10-28
- **범위:** 소유자 지시("네 3가지 먼저 감사하겠습니다")에 따라 다음 세 파일의 **모든 행**을 감사했습니다.
  - `kr_sessions`: 수능일(11/19)까지 KR 운영에 필요합니다.
  - `publication_schedules`, `source_skipped`: US 데이터 입력에 필요합니다.
- **규칙:** 감사 요청서 7절 8번에 따라 `core/calendars/data/`는 바꾸지 않았습니다. 서명 필드도 쓰지 않았습니다.

- **방법:** 1차 감사(`01_calendar_T-CAL-02.md` 2절)와 같습니다.
  - 공식 출처를 대조하고, 저장소에 있는 실측 데이터와 맞춰 봤습니다.
  - 근거 등급은 A·B입니다. 이번에는 C(추정) 등급이 없습니다.
  - 공식 문서는 원문을 열지 못하고 검색 발췌로만 확인했습니다. 네트워크 정책이 원문 사이트를 막기 때문입니다.

- **1998-12-12 이전 토요일 장 마감 시각:** 이 정보가 없으면 그날 계산은 거부됩니다(fail-closed).

## 3. 서명 후 상태 (모의 서명으로 확인)

`calendar_batch2/simulate_signed.py`는 실제 데이터 사본에 세 파일만 가짜 서명을 넣고 로더로 확인합니다. 결과는 **23/23 통과**이고, 원본 데이터는 바뀌지 않았습니다(md5 확인).

| 항목 | 결과 |
|---|---|
| KR 결정 시각 | 2026-11-19(수능) **07:30Z**(16:30 KST), 종가 확정 07:30:30Z. 2027-11-18(수능) 07:30Z. 평일 2026-11-20 06:30Z |
| H.15 / 재무부 금리 공개 시각 | 2026-10-27 관측분 → 10-28 20:15Z / 10-27 22:00Z |
| 성금요일 건너뛰기 | DGS10·DGS2·T10Y2Y 모두 2025-04-17 다음 관측일이 04-21. 2027-03-25 다음은 03-29. 2026-04-03은 값이 있어 건너뛰지 않음 |
| VIX | 공개 시각은 계산됨. 데이터 늦음 판단은 `holidays_CBOE`가 비어 있어 거부됨(예상대로) |
| BLS | 발표일이 없어 KeyError(예상대로, M5에서 채움) |
| 시장 상태 | **US: signed=True.** **KR: signed=False**(`kr_regime_tags` 남음). 다만 KR 결정 시계와 ARM 전제조건은 열림 |
| 커버리지 경보 | warn 2027-10-05~08, page 2027-12-01~03 → 세 파일도 2028년 버전을 2027년 9월 말까지 서명해야 함 |

**KR ARM 주의.** ARM 전제조건은 시계 파일(`kr_sessions`, `holidays_KRX`)만 봅니다. 따라서 `kr_regime_tags`가 서명 전이어도 KR 북이 ARM될 수 있습니다. 그 상태에서는 제도 태그를 읽는 입력이 fail-closed되어, 북이 OPS HALT로 멈추는 쪽으로 동작합니다. 안전한 방향이지만, KR 실전 전에 `kr_regime_tags`도 서명하기를 권합니다.

## 5. 제안 파일과 서명 양식

**파일.** 모두 `docs/audit/2026-10-27/calendar_batch2/`에 있습니다.

- `build_proposed.py`: 감사 이전 초안(커밋 `1f63f91`)에서 제안본을 다시 만듭니다.
- `proposed/*.yaml`, `proposed.diff`: 제안 파일과 현재 초안과의 차이입니다.
- `simulate_signed.py`, `simulate_signed.log`: 3절 모의 서명 검증의 스크립트와 결과입니다.

**서명 양식.** 소유자가 제안을 승인하시면 Claude가 `proposed/`를 `core/calendars/data/`로 옮기고 MANIFEST 버전을 1.0.0으로 올립니다. 그 뒤에 아래 양식으로 서명하시면 됩니다.

```
[QUANTGEN 달력 서명서 · 2차 (kr_sessions · publication_schedules · source_skipped)]

서명 대상과 초안 지문:
  [ ] kr_sessions.yaml            v1.0.0   94c8d4f57fe44fb20f31d5fff2bce567
  [ ] publication_schedules.yaml  v1.0.0   14100e737e79154b737a8814f1c23675
  [ ] source_skipped.yaml         v1.0.0   d4ac8e4147d6642859b3210881167f2e

확인 사항:
  [ ] 2027-11-18 수능일 추가, 1995~1998 점심 휴장 11:30~13:00 (KS-01, KS-02)
  [ ] 성금요일 예외를 H.15 전체로 확대, 2027-03-26 추가 (SS-01, SS-02)
  [ ] 서명 후에도 VIX·BLS·BEA·ECOS 입력은 막혀 있음을 안다 (PS-02)
  [ ] 2008년 이전 수능일, 1998년 이전 토요일 마감 시각, 2015년 이전 랜덤엔드 연장은 공백으로 둔다

  [ ] KRX의 수능일 시간 공지가 설정(10:00~16:30)과 다르면 새 버전으로 다시 서명한다

서명 문장:
  "나 ______은(는) 위 3개 파일의 날짜·시각·출처를 확인했으며, 이 파일들에 서명합니다."

서명 시각 (UTC): 서명 도구가 자동으로 기록
```

```bash
  --expect kr_sessions=94c8d4f57fe44fb20f31d5fff2bce567 \
```
