# 개인정보 처리방침 개정 문구 제안 (유료 결제)

판 0.1, 2026-11-20, PAYMENTS_ACCOUNT_KEYS 세션.

**이 문서는 제안만 합니다.**
- `docs/compliance/01-privacy-policy.md`는 고치지 않았습니다. 메인의 정책 PR-2가 소유자 결정(P2-xx) 뒤에 반영합니다.
- 회원 계정 부분의 칸 값은 `docs/commercial/accounts/ACCOUNT_SETUP.md` 4.2절에 있습니다. 이 문서는 그 위에 **결제 행만** 더합니다.

**법률 자문이 아닙니다.** 근거는 [PAYMENT_DESIGN.md](PAYMENT_DESIGN.md) 7·8절에 적었습니다. 시행령 제6조의 항목별 기간은 원문 미확인이며, 판매 전 원문으로 다시 확인합니다.

## 1. "유료 구매·환불 및 법정 기록" 행 (01의 123행 칸 채우기)

| 칸 | 제안 값 |
|---|---|
| 처리 항목 | 계정 고유번호, 구독 상품·기간·상태, 주문번호, 결제 금액, 승인번호, 승인·취소 시각, 결제 카드의 카드사와 끝 4자리 (결제대행사가 알려 주는 범위), 환불 금액·사유·처리일, 자동 갱신·요금 변경 동의 기록. **카드번호 전체, 유효기간, CVC는 운영자가 받거나 저장하지 않으며 결제대행사가 처리합니다** |
| `{{privacy.payment_processors}}` | 결제대행사: (PG 확정 후 이름) — 카드 결제·정기결제 처리, 카드정보 보관. (PortOne을 쓰면) 결제 연동 대행: 코리아포트원 주식회사 *(법인명 미검증)*. 결제 기록 저장: Amazon Web Services (시드니 리전, 서버 위치는 P2-14로 확정) |
| 처리 근거 | 계약 체결·이행 (요금 결제, 환불), 법령상 의무 (거래기록 보존) |
| `{{privacy.commerce_retention}}` | 계약 또는 청약철회 등에 관한 기록 5년, 대금결제 및 재화 등의 공급에 관한 기록 5년, 소비자의 불만 또는 분쟁처리에 관한 기록 3년 (전자상거래법 시행령 제6조, **원문 미확인**). 회원 탈퇴 후에도 위 기간 동안 다른 정보와 분리하여 보관한 뒤 파기합니다 |

## 2. 새 행: 유료 이용 연령 확인

| 칸 | 제안 값 |
|---|---|
| 처리 항목 | 만 19세 이상 여부 (예/아니요), 확인 시각, 본인확인기관 이름, 확인 거래 번호. **이름·생년월일·휴대전화번호·주민등록번호는 저장하지 않습니다** (P2-11에서 연계정보(CI)를 저장하지 않기로 할 때) |
| 수집 방법 | 첫 유료 결제 전, 본인확인기관의 휴대폰 본인확인 화면에서 회원이 직접 인증 |
| 수탁자·제공처 | 본인확인 대행사 (PG 또는 별도 업체, 확정 후 이름) |
| 처리 근거 | 계약 체결 (유료 이용 연령 기준, 이용약관 제3조) |
| 보유 기간 | 구독 종료 후 5년 (계약 체결 기록의 일부, P2-12에서 확정) |

## 3. 처리위탁 표에 더할 줄

| 수탁자 | 위탁 업무 | 비고 |
|---|---|---|

| Amazon Web Services | 결제 기록 저장 (결제 서버) | 국외 (호주 시드니). `01` 국외 이전 표에 "결제 기록" 항목을 더함 (`ACCOUNT_SETUP.md` 4.3절과 같은 형식) |

## 4. 파기 문단에 더할 문장

> 정기결제를 위해 결제대행사가 발급한 결제 수단 식별값(빌링키)은 유료 이용이 끝나는 날 결제대행사에 삭제를 요청하고, 운영자가 보관하던 값도 함께 삭제합니다.

## 5. 반영 전에 메인·소유자가 확인할 것

1. PG와 본인확인 대행사의 이름은 계약 뒤에 넣습니다. 이름이 정해지기 전에는 이 행들을 공개 방침에 넣지 않습니다. 01은 "미운영 시 해당 행 삭제"라고 적고 있습니다.
2. 결제 서버 위치(P2-14)가 시드니가 아니면 국외 이전 표를 다시 씁니다.
3. 시행령 제6조 항목별 기간을 원문으로 확인합니다.
