# PG 선택 기준과 비교 (시나리오 A)

판 0.2, 2026-11-20, PAYMENTS_ACCOUNT_KEYS 세션. 0.2: 2026-11-20 재검색 결과 반영 (확인한 칸에 출처·확인일, 확인 못 한 칸은 미검증 유지).

**주의**
- 이 표는 공개 자료 검색만으로 만들었습니다. 수수료, 정산 주기, 가입 조건은 PG가 가맹점마다 심사로 정합니다.
- **"미검증"이 붙은 칸은 PAY-0 03번 문의 회신이나 PG 견적으로 확정합니다.** PG 가입·견적 요청·키 발급은 하지 않았습니다.
- 포트원 블로그 자료에는 자사 홍보 목적이 섞여 있습니다.

## 3. 공통 확인 질문 (PAY-0 03번 문의에 더할 것)

**상태 (2026-11-20):** 아래 6개 질문(과 후보 7번)은 아직 `docs/commercial/inquiries/03-portone-pg.md`에 넣지 않았습니다. 넣을지는 소유자 결정 OA-39입니다. 결정이 나면 이 목록을 그대로 03번 문의 끝에 붙이면 됩니다. 2026-11-20 재검색으로도 간이과세자 가입 가능 여부, 빌링 심사 서류 목록, PG별 빌링 수수료·정산 주기는 공개 자료에서 확인되지 않아, 이 질문들은 여전히 필요합니다.

1. "개인 명의 데스크톱 투자 분석 소프트웨어 월 구독 (실제 주문·자산 보관 없음)"이 카드사 업종 심사를 통과할 수 있습니까? 필요한 설명 자료는 무엇입니까?
2. 빌링키로 매월 비인증 승인을 해도 됩니까? 부분 취소(일할 반환)를 지원합니까? 결제 실패 재시도에 제한이 있습니까?
3. 개인사업자 (일반/간이), 통신판매업 신고 전에도 가입할 수 있습니까? 법인 전환 때 빌링키를 옮길 수 있습니까?
4. 빌링 결제의 수수료, 영중소 우대, 정산 주기, 보증보험·가입비는 어떻게 됩니까?
5. 휴대폰 본인확인 서비스를 같이 계약할 수 있습니까? 생년월일만 받아 만 19세 여부를 판정할 수 있습니까?
6. 승인 요청 서버가 해외(AWS 시드니)에 있어도 됩니까?

7. (질문 후보, 미검증) 2026-12-17 시행 개정 전자금융거래법으로 PG의 정산자금 외부 관리가 의무화된다고 들었습니다. 이 개정이 가맹점의 정산 주기·보증보험·가입 조건에 영향을 줍니까?

**7번 근거 (미검증):** 업계 뉴스레터([페이플](https://maily.so/payple/posts/g1o40d8lzve?nb=3jrkdkgeo51)) 하나뿐이고 공식 자료(법령 원문·금융위 발표)로는 확인하지 못했습니다. 그래서 이 개정은 **PAY-2 설계의 근거로 쓰지 않고**, 03번 문의에 붙일 때의 질문 후보로만 둡니다 (메인 지시 2026-11-20).

## 4. 지금의 제안 (P2-13)

- **1순위 후보: PortOne 경유 + PG 하나.**
  - PG를 나중에 바꾸거나 둘로 늘려도 앱 코드를 다시 쓰지 않아도 됩니다 (C2 잠금 위험 완화).
  - 상담 창구가 하나입니다.
  - 단점은 연동 대행이라는 한 단계가 더 생긴다는 점입니다. 장애·정책 변경이 두 곳에서 올 수 있습니다.
- **PG는 C1 (업종 심사) 회신으로 고릅니다.**
  - 수수료 차이보다 **심사 통과**가 먼저입니다.
  - 회신이 둘 이상 "가능"이면 C4·C5 견적으로 고릅니다.
- 결정은 **PAY-0 01번(사업 형태)과 03번(PG) 회신 뒤**에 합니다. 그 전에는 가입하지 않습니다.

이 비교는 **법률 자문이 아닙니다.** 여신전문금융업법상 가맹점 준수사항에 따라, 카드 결제 거절·불리한 대우와 가맹점 수수료의 회원 전가는 금지됩니다. 그래서 카드 결제 시 수수료를 회원에게 따로 더 받지 않습니다.
- **근거:** 여신전문금융업법 제19조 ([해설](https://korea.legal/wiki/%ec%97%ac%ec%8b%a0%ec%a0%84%eb%ac%b8%ea%b8%88%ec%9c%b5%ec%97%85%eb%b2%95-%ec%a0%9c19%ec%a1%b0/)).
- **원문 확인:** 항 번호가 자료마다 달라 원문 미확인.
