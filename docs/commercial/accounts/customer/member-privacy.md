# QUANTGEN 무료 회원의 개인정보 안내

**검토용 초안 · review-required · 시행일 미정**

이 안내는 무료 웹 회원으로 가입할 때의 개인정보 처리와 이메일 문의를 다룹니다. 개인정보를 관리하는 사람은 QUANTGEN 운영자 고건입니다. 웹 가입과 내 계정 화면은 공개 전이며, 이 안내는 아직 시행되지 않았습니다.

## 가입하면 어떤 정보가 남나요?

| 용도 | 처리하는 정보 | 보관 기간 |
| --- | --- | --- |
| 계정 생성과 로그인 | 입력한 이메일 주소와 비밀번호, 자동으로 생성되는 계정 번호, 가입·수정 시각, 계정 상태, 이메일 인증 여부 | 탈퇴하면 계정과 함께 즉시 삭제합니다. 가입 후 7일이 지나도 이메일 인증을 마치지 않은 계정은 매주 확인해 삭제합니다. |
| 약관과 연령 확인 | 가입할 때 적용한 약관·개인정보 처리방침의 버전, 약관 동의 시각, 만 14세 이상이라는 본인의 확인 | 탈퇴할 때까지 보관합니다. |
| 선택한 2단계 인증 | 선택한 경우에만 인증 앱 또는 이메일 코드를 이용한 2단계 인증 등록 정보 | 계정 삭제 시 함께 삭제합니다. |
| 광고성 소식 메일 | 가입 이메일 주소, 수신 선택 여부와 선택·변경 시각 | 광고 발송을 위한 이메일 이용은 수신 동의를 철회하거나 탈퇴하면 끝납니다. 계정에는 최근 수신 여부와 변경 시각이 남습니다. |
| 계정 보안 | 가입·로그인·비밀번호 찾기 등 요청의 시각, 접속 IP와 종류. 관리자가 회원 계정을 처리하면 담당 역할, 브라우저, 대상 계정 번호와 작업 종류도 기록됩니다. 회원 본인의 요청 기록에도 계정 번호가 남는지는 확인 중입니다. | 시드니에 보관하는 보안 기록은 기록일로부터 400일 뒤 자동 삭제됩니다. 중간에 탈퇴해도 이 기간은 같습니다. |

무료 회원은 만 14세 이상부터 가입할 수 있습니다. 나이는 본인이 확인하며 생년월일이나 신분증을 받지 않습니다. 가입할 때 이름, 전화번호, 증권계좌 번호, 증권사 인증키도 요구하지 않습니다. 만 14세 미만 회원으로 확인되면 이용을 정지한 뒤 계정을 삭제하는 절차를 적용할 예정입니다.

## 정보는 어디로 가나요?

**회원 계정과 보안 기록은 호주 시드니에서 처리합니다.** 가입하고 계정을 이용할 때 계정 정보와 보안 기록이 인터넷을 통해 Amazon Web Services(AWS)로 전송됩니다. AWS는 웹사이트 호스팅, 계정 보관과 로그인 인증, 가입 확인·비밀번호 재설정 이메일 발송, 보안 기록 보관을 맡습니다. 비밀번호는 인증 서비스인 Amazon Cognito가 보관하며 운영자는 볼 수 없습니다. 계정 정보와 보안 기록은 위 표의 기간 동안 보관합니다. 이 이전을 원하지 않으면 가입을 건너뛰거나 탈퇴할 수 있습니다. 데스크톱 앱의 무료 기능은 회원 계정 없이 사용할 수 있습니다.

**문의 메일은 계정과 다른 경로로 처리합니다.** 문의 주소로 메일을 보낼 때마다 Cloudflare가 발신 주소, 적은 경우 이름, 제목, 본문과 첨부를 운영자의 Gmail로 전달합니다. 그곳에 받은 메일과 보낸 답장이 보관됩니다. 가입 확인이나 비밀번호 재설정 이메일에 답장할 때도 같은 경로를 거칩니다. 회신에는 받는 주소와 본인 확인 안내, 열람을 요청한 계정 정보가 담길 수 있습니다. 복구를 요청하면 임시 비밀번호가, 계정 삭제에 동의하는 절차에서는 일회용 확인 코드가 보낸편지함에 남을 수 있습니다. 임시 비밀번호가 담긴 부분은 비밀번호 변경 뒤, 삭제 동의 안내와 답장은 처리가 끝났다는 회신 뒤에 지웁니다. 전달·보관 과정에서 정보가 국외로 이전되며, Cloudflare의 실제 처리 국가와 Google의 실제 보관 국가는 확인 중입니다.

메일을 통한 국외 이전을 원하지 않으면 문의 메일과 인증 메일에 대한 답장을 보내지 않을 수 있습니다. 이 경우 이메일로 문의와 답변을 주고받기 어렵습니다. 메일 없이 내 정보를 확인하거나 탈퇴하는 방법은 웹 계정 페이지 공개 뒤 제공할 예정입니다. 이 페이지에서는 위의 AWS 시드니 경로를 이용합니다. 현재 이용할 수 있는 다른 비메일 문의 창구는 확인되지 않았습니다.

## 내 정보를 확인하거나 지우려면 어떻게 하나요?

본인이나 적법한 대리인은 개인정보 열람, 정정, 삭제, 처리정지, 동의 철회를 요청할 수 있습니다. 가입 화면의 [필수 확인과 선택 동의](member-consent.md)를 미리 볼 수 있습니다. 개인정보 담당 이메일은 contact@quantgeneration.com이며, 요청과 답장은 위의 문의 메일 경로로 처리됩니다. 비밀번호, 증권사 인증키 또는 신분증 전체 사본을 문의 메일에 넣을 필요는 없습니다.

계정을 삭제하면 계정 번호, 이메일 주소, 가입 시 남긴 동의 기록과 2단계 인증 정보가 삭제되고 계정을 복구할 수 없습니다. 문의 메일의 삭제도 별도로 요청할 수 있습니다. 계정 삭제 요청을 받으면 접수일부터 10일 안에 삭제 완료 또는 거절 사유를 안내하는 것이 목표입니다. 더 짧은 법정 기한이 적용되면 그 기한을 따릅니다. 메일 보관 기간, 운영자가 지운 메일이 Google에서 완전히 삭제되는 시점, 권리 요청 처리 결과를 보관할 기간은 확정 전입니다.

**공개 전 확인 중인 사항**은 AWS 계약 법인과 개인정보 문의처, Cloudflare와 Google의 실제 계약 상대방·처리 국가·문의처, 메일 전달 기록과 문의 메일의 보관 기간, 국외 이전의 적용 근거 및 고지 방식입니다. 웹 계정 페이지의 주소와 실제 열람·탈퇴 기능, 메일 이외의 문의 경로를 확인한 뒤 시행일을 안내할 예정입니다.
