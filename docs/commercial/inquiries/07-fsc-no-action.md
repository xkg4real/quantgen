## 본문

**제목:** 개별 투자 조언을 하지 않는 데스크톱 시장 분석 도구의 유료 구독 판매가 투자자문업·유사투자자문업에 해당하는지

**신청인 소개.** 저는 QUANTGEN을 준비하는 고건입니다 (개인, 법인 설립 전).
QUANTGEN은 사용자가 자기 PC에서 시장 데이터 분석·시뮬레이션·백테스트·연구 기록·모의투자를 하는 데스크톱 프로그램으로, 실제 주문의 실행·중개·취소와 자산 보관 기능이 없고, 월 정액 구독으로 판매하려 합니다.

**사실관계 (제공 방식).**
- 모든 이용자에게 같은 기능을 제공합니다. 운영자가 특정 이용자에게 종목·매매 시점을 골라 주는 기능, 1:1 상담, 채팅·전화 등 양방향 소통 채널은 없습니다.
- 분석 결과는 사용자가 고른 종목·조건·기간을 프로그램이 계산한 값입니다. "합성 데이터", "실패", "미실행" 결과는 정상 결과와 구별해 표시합니다.
- 요금: 월 정액 (부가세 포함 29,000원 / 59,000원 / 290,000원), 기능 범위에 따라 다르며 투자 성과와 연동되지 않습니다.
- 유료 이용은 만 19세 이상.

**질문.**

0. 법인 설립 전 개인이 이 요청을 낼 수 있는지, 법인 설립 뒤 다시 내야 하는지.
1. 위 사실관계의 유료 구독 판매가 자본시장과 금융투자업에 관한 법률상 **투자자문업**에 해당하는지.
2. 같은 판매가 **유사투자자문업** (신고 대상)에 해당하는지. 특히 "불특정 다수를 대상으로" 하는 조언에 일반 분석 도구 제공이 포함되는지.
3. 다음 기능을 더하면 판단이 달라지는지 (각각):
   a. 사용자가 고른 종목 차트에 조건부 해석 문구를 붙이는 기능 (예: "이 조건에서 과거 수익률 분포는 …").
   b. AI가 분석 결과를 문장으로 설명하는 기능 (특정 매수·매도 권유는 하지 않음).
   c. 여러 종목을 점수로 정렬해 보여 주는 화면 (모든 이용자에게 같은 기준).
4. 무료로만 배포하고 나중에 유료로 바꿀 계획일 때, 무료 배포 단계도 "영업"으로 볼 여지가 있는지.
5. 2024-08-14 시행 개정(유사투자자문업의 유료 양방향 채널 관련)이 위 사실관계에 미치는 영향.
