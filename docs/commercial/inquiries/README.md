## 3. 보낼 순서와 이유

1. **01 세무사 먼저.** 개인사업자로 열지, 법인을 먼저 세울지가 정해져야 사업자등록번호가 생기고, 통신판매업 신고(02)·계좌(04)·PG 심사(03)가 모두 그 번호와 명의로 진행됩니다. 법인으로 바로 가면 02~06은 법인 명의로 다시 써야 합니다 (handoff `INCORPORATION_CHECKLIST.md` A·E).
2. **07 금융위는 01과 같이.** 답이 오래 걸릴 수 있고 (회신 기한 미확인), 답에 따라 상품 범위 자체가 바뀝니다. 다만 보내기 전 소유자가 "변호사 검토를 먼저 받을지" 정합니다. 개인 명의로 보내도 되는지는 초안 안의 질문으로 확인합니다.
3. **02 구청**은 사업자등록 뒤 (신고 서류에 사업자등록번호가 들어갈 것으로 보임, 미확인).
4. **04 은행**은 사업자등록 뒤, PG 가입 전 (PG 정산 계좌가 필요).
5. **03 PortOne**은 사업자등록·계좌 뒤. 통신판매업 신고증을 요구할 수 있어 02 뒤가 안전.
6. **06·05 CMS**는 정보 수집. 시나리오 A(카드) 밖이므로 마지막. 05는 06의 답으로 충분하면 보내지 않아도 됩니다.
