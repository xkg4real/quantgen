- 엑셀 대조: 정보 19종·대안별 171칸, **원본 변경 0칸**, 소유자 확정 차이는 N·O·W로 별도 표시.

## 메인 통합 전 독립 검토 보완: 동일 버전 메타데이터 충돌

독립 QA가 기존 버전 키(공급원·항목·수신시각·payload SHA)는 같지만
`kind`, `published_at` 또는 `valid_at`이 다른 입력도 `False`(동일 중복)로
조용히 무시되는 사례를 찾았다. 합성 EDGAR 입력의 `acceptanceDateTime`만
바꿔도 payload는 그대로이므로 실제 파서 경로로도 재현된다.

- `False`는 정규화한 시각·종류·payload까지 동일한 기록에만 반환한다.
  같은 버전 키에 다른 메타데이터가 오면 값을 노출하지 않는 `StoreError`로
  거절하고 기존 이력은 보존한다.
- 같은 순간의 다른 시간대 표현은 여전히 중복이다. 나중 수신시각으로 들어온
  정정은 새 행으로 허용하며 이전 시점의 `as_of` 답은 그대로다.
- DB 스키마·UNIQUE 키·버전 선택 규칙·사전등록·평가 문턱을 바꾸지 않았다.
  자동으로 수신시각을 늦추거나 상충 메타데이터를 덮어쓰지 않는다.
- 새 회귀 5개를 추가했다. 수정 전 저장소 13개 검사에서 실패 이벤트 5건
  (메타데이터 3개 subtest·재연결·EDGAR 충돌)을 확인했다. 수정 후 저장소
  13개와 DIDM 전체 137개가 통과했다. 앞선 132개를 포함하므로 합산하지
  않는다. 모든 저장소 검증은 임시 합성 SQLite만 사용한다.
