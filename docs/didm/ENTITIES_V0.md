# DIDM-7 개체 연결·근접 중복 군집화·유사도 V0 (규칙·사전 기반 첫 판)

- 작성: DIDM_DEV 세션, 2026-11-24. 코드: `core/didm/entities/{similarity,cluster,linker}.py`. 시험: `tests/didm_entities_acceptance.py` (합성 제목과 합성 별칭 사전만; 모델·네트워크·시계 없음).
- **실제 기사에서의 연결 정밀도·재현율은 아직 재지 않았습니다.** 정답 집합이 없습니다. 시험은 동작을 고정할 뿐이고, 등록 기준 (정밀도 ≥ 0.95, 재현율 ≥ 0.80)은 Stage 1에서 `core/didm/eval/metrics.linking_scores`로 잽니다 (연결 결과를 그 함수에 넣는 자리까지 만들어 둠).

## 1. 유사도 (`similarity.py`)

- 글을 NFKC 정규화 → 소문자 → 글자·숫자만 남기고 빈칸 하나로 → **5글자 겹침 조각**으로 자릅니다. 영어·한국어를 같은 길로 처리합니다.
- 유사도 = 두 조각 집합의 Jaccard (겹친 것 ÷ 합친 것). 둘 다 비어 있으면 0 (비교할 것이 없는 것은 "같음"이 아님).
- 큰 묶음용으로 MinHash 서명 128개 (추정 오차 약 0.03). 해시는 `hashlib`만 써서 실행·기계가 달라도 같은 서명이 나옵니다 (파이썬 내장 `hash()`는 실행마다 달라져 쓰지 않음; 시험이 두 프로세스에서 대조).
- `article_similarity(texts)`는 참신성 모형 (`core/didm/novelty.py` `build_features`)에 주입하는 유사도 함수입니다. 사전등록 4.1절의 설명변수 "최대 유사도, 유사 (≥ 0.80) 기사 수 …"가 이 유사도로 계산됩니다.

## 2. 원출처 묶음 (`cluster.py`)

- 받은 순서대로 처리하고, 기사는 **자기보다 먼저 받은 기사 중 충분히 비슷한 가장 이른 기사**의 묶음에 들어갑니다. 나중에 받은 기사는 앞 기사의 묶음을 바꾸지 못합니다 (시험이 확인) → 시점 규칙을 지킵니다.
- 재게재의 재게재는 처음 원출처의 묶음으로 갑니다. `rank_in_cluster`는 묶음 안 순번 (참신성 모형의 설명변수 `cluster_decay`의 입력).
- `origin_cluster_id` = `cl-` + 원출처 기사 ID의 SHA-256 앞 20자 (레코드 식별자 규칙을 만족).
- 사전등록 4절: 같은 `origin_cluster_id`는 1건으로 셉니다.

## 3. 개체 연결 (`linker.py`)

- 호출자가 준 **별칭 사전** (별칭, 대상 ID, 종류, 유효 시작일·종료일)을 제목·첫 문단·본문·태그에서 찾습니다. 사전은 자료 쪽에서 공시·거래소 목록으로 만듭니다 (이 모듈은 파일을 열지 않음).
- 정밀도 우선 규칙:
  - 별칭은 **유효 기간 안에서만** 씁니다 (사명 변경, 재사용된 티커). 종료일 당일은 포함.
  - 그날 **두 대상이 같은 별칭**을 가지면 어느 쪽에도 연결하지 않습니다.
  - 로마자 별칭은 **낱말로 떨어져 있어야** 하고, 4글자 이하이거나 모두 대문자인 별칭 (티커)은 **대소문자까지 같아야** 합니다 ("it"은 티커 IT가 아님).
  - 한국어 별칭은 왼쪽에 한글·영숫자가 붙어 있으면 안 됩니다 ("신가상전자"는 "가상전자"가 아님). 오른쪽 조사는 허용 ("가상전자는").
- 언급 위치는 사전등록 4절의 보정 전 관련성 값 (제목 100, 첫 문단 80, 본문 40, 태그만 20)을 냅니다. 이 값은 관련성 **모형의 설명변수**이고 관련성 점수 자체가 아닙니다. 한 대상의 별칭이 여러 곳에 나오면 가장 좋은 위치를 씁니다.

## 4. 이 세션이 정한 것 (등록값이 아님)

| # | 무엇 | 값 | 근거·다른 선택지 |
|---|---|---|---|
| E1 | 근접 중복 문턱 | 0.80 | 사전등록 4.1절의 "유사 (≥ 0.80)"와 같은 값을 씀. 재게재 판정에 따로 등록된 값은 없음 |
| E2 | 묶음을 찾는 과거 범위 | 7일 | 그보다 오래된 재게재는 새 묶음이 됨. 사전등록의 관심도 창 (7일)과 같게 둠 |
| E3 | 조각 길이 | 5글자 | 짧은 제목에서도 조각이 충분히 나오는 길이 |
| E4 | 비교하는 글 | 호출자가 줌 (제목, 또는 제목 + 첫 문단) | 본문 전체 비교는 권리·저장 문제로 첫 판에서 뺌 |
| E5 | 티커로 보는 길이 | 4글자 이하 또는 모두 대문자 | 5글자 대문자 티커도 "모두 대문자" 조건에 걸림 |

E1·E2는 Stage 1 정답 집합 (새 사건 여부 표시)으로 맞는지 확인해야 합니다 (미결).

## 5. 이 첫 판이 못 하는 것

- 대명사·줄임말 ("the company", "동사"), 사전에 없는 대상, 오타, 음차 표기 차이.
- 같은 이름의 두 회사를 문맥으로 가르기 (지금은 둘 다 버림 → 재현율 손해).
- 같은 사건을 다르게 쓴 기사 묶기 (조각 유사도는 같은 글의 반복만 잡음. 뜻이 같은 다른 글은 못 잡음).
- 거시 대상의 별칭은 일반 낱말과 겹치기 쉬워 ("policy rate") 정밀도가 낮을 수 있습니다. 실제 사전에서 따로 확인이 필요합니다.
