# DIDM Stage 1 표시 안내 V0 (주석자용)

- 작성: DIDM_DEV 세션, 2026-11-24. 한 줄의 형식은 `docs/didm/SCORE_SCHEMA_V0.md` 4절 (`validate_gold`). 표본은 `GOLD_SET_V0.md`.
- 초안입니다. 시범 표시 50건으로 두 주석자의 일치도를 본 뒤 고칩니다 (고치면 V0.1, 고친 이유를 적음). 시범 50건은 정답 집합에 넣지 않습니다.

## 1. 원칙

1. **기사에 적힌 것만** 봅니다. 그 뒤 주가가 어떻게 됐는지, 다른 기사가 뭐라고 했는지 찾아보지 않습니다.
2. 두 주석자는 서로의 답을 보지 않습니다. 모델의 답도 보지 않습니다.
3. 모르겠으면 가장 가까운 것을 고르고 메모에 "불확실"이라고 적습니다. 비워 두지 않습니다.
4. 기사 하나에 대상이 여럿이면 대상마다 한 줄씩 씁니다.

## 2. 칸마다 묻는 것

| 칸 | 질문 | 답 |
|---|---|---|
| `target_kind`, `entity_id` | 누구(무엇)에 관한 줄인가 | 미리 채워져 나옵니다 (바꾸지 않음) |
| `is_subject` | 이 대상이 기사의 **주제**인가, 지나가며 언급된 것인가 | 예 / 아니오. 제목이나 첫 문단이 이 대상에 관한 것이면 예. 목록·비교 대상으로만 나오면 아니오 |
| `event_type` | 기사가 전하는 일은 어떤 종류인가 | 아래 14개 중 하나, 맞는 것이 없으면 `none` |
| `direction` | 이 일이 이 대상에 **좋은 소식인가 나쁜 소식인가** (기사 내용만으로) | `+1` 좋음 / `-1` 나쁨 / `0` 중립이거나 알 수 없음 |
| `is_new_event` | 이 기사가 **처음 알리는 일**인가, 이미 알려진 일을 다시 전하는가 | 예 / 아니오. 기사에 "앞서 보도된", "지난주 발표한" 같은 말이 있으면 아니오 |
| `claim_status` | 확인된 사실인가, 전해진 말인가 | `confirmed` (회사·기관의 공식 발표, 공시) / `reported` (소식통, 관계자, 추측 보도) |

## 3. 사건 유형 14개

| 코드 | 이름 | 넣는 것 | 헷갈릴 때 |
|---|---|---|---|
| `monetary_policy` | 통화정책 | 금리 결정, 중앙은행 발언, 양적 완화·긴축 | 물가 지표 발표 자체는 `inflation` |
| `inflation` | 물가 | CPI, PPI, 기대 인플레이션 | |
| `employment` | 고용 | 고용 지표, 실업률 | 한 회사의 감원은 `management` |
| `growth` | 성장 | GDP, PMI, 소매 판매, 산업 생산 | |
| `fiscal` | 재정 | 예산, 세금, 국채 발행, 정부 지출 | |
| `trade_tariffs` | 무역·관세 | 관세, 수출입 규제, 무역 협정 | 부품 조달 차질은 `supply_chain` |
| `geopolitics` | 전쟁·지정학 | 전쟁, 제재, 외교 충돌 | |
| `election_policy` | 선거·정책 | 선거 결과, 공약, 정권 교체, 큰 정책 방향 | 개별 규제 조치는 `regulation_litigation` |
| `earnings` | 실적 | 분기 실적, 실적 전망, 잠정 실적 | |
| `mergers_acquisitions` | 인수합병 | 인수, 합병, 지분 매각, 분할 | |
| `management` | 경영진 | 대표 교체, 이사회, 감원, 지배구조 | |
| `regulation_litigation` | 규제·소송 | 당국 조사, 과징금, 소송, 인허가 | 암호화폐 관련이면 `crypto_regulation_hack` |
| `supply_chain` | 공급망 | 생산 차질, 부품 부족, 물류 | |
| `crypto_regulation_hack` | 암호화폐 규제·해킹 | 거래소 규제, 해킹, 상장폐지 | |
| `none` | 해당 없음 | 위 어디에도 안 맞음 (시황 요약, 주가 움직임만 전하는 기사, 광고) | |

두 유형에 걸치면 **기사 제목이 말하는 쪽**을 고릅니다.

## 4. 판정자

두 주석자의 답이 다르면 판정자가 기사를 다시 읽고 하나를 정합니다. 판정자는 두 답을 볼 수 있지만 모델의 답은 보지 않습니다. 판정 결과가 정답 (`gold`)이 되고, 두 주석자의 원래 답은 일치도 계산을 위해 그대로 둡니다.

## 5. 미결

- 주석자·판정자 지정과 표시 도구 (소유자).
- 한국어 기사에서 `claim_status`의 "공시" 범위 (자율 공시, 조회 공시 답변을 `confirmed`로 볼지) — 시범 50건에서 정합니다.
