# DIDM-9/e2e 끝에서 끝까지 합성 실행 V0

- 작성: DIDM_DEV 세션, 2026-11-24. 코드: `core/didm/sim/newsroom.py` (합성 기사 세계), `core/didm/sim/pipeline.py` (조각을 잇는 실행기), `core/didm/credibility/events.py` (사건 식별자). 시험: `tests/didm_e2e_acceptance.py`.
- **배선 시험입니다.** 따로 시험한 조각들이 이어졌을 때도 시점 규칙을 지키고, 합성 세계에 심어 둔 답을 되찾는지만 봅니다. 등록 실행이 아니고 판정 줄을 내지 않습니다. 실제 기사·가격·모델·네트워크·시계를 쓰지 않습니다. 여기서 나온 숫자는 어떤 시장에 대해서도 아무것도 말하지 않습니다.

## 1. 흐름

```
합성 기사 ─▶ 원출처 묶음 ─▶ 개체 연결 (기사 날짜 기준 별칭 사전) ─▶ 채점기 ─▶ 판단 검증
        ─▶ 사건 식별자 ─▶ 신뢰 상태 ─▶ 레코드 조립·검증 ─▶ 결정일마다 충격 ─▶ 패널 ─▶ LP·HAR-X 추정
```

- 합성 세계: 종목 40개 × 400일, 주장 (사건) 약 1,200개, 기사 약 8,800건. 주장마다 독립 보도 1~3건 (매체마다 다른 글), 그 재게시, 또는 소셜 소문 1건 + 재게시 5~30건 (일부는 같은 날 또는 며칠 뒤 공식 부인).
- 일부러 심은 것: 본문에 지나가며 나온 이름, 유효 기간이 끝난 별칭, 두 종목이 함께 쓰는 이름, 표본 한가운데서 이름을 바꾼 종목 1개.
- 채점기는 세계가 쓴 확률을 그대로 내는 가짜 (보정된 채점기의 대역)입니다. 보도의 입장 (지지/부인)과 공식 여부는 합성 기사에 달린 표시를 호출자가 넘깁니다 (판단 형식에 그 필드가 없음).
- 정답: `newsroom.oracle_shocks`가 세계의 참값에서 **파이프라인 코드를 쓰지 않고** 단순 산수로 "그날 봤어야 할 충격"을 냅니다 (그날 받은 서로 다른 원출처 수 × 그 결정 시각의 신뢰 × (P(+1) − P(−1))).

## 3. 이번에 정해진 것

- **사건 식별자 (C9, 메인 결정 2026-11-24):** 대상 + 사건 유형 + 첫 보도 뒤 7일 창. 원출처 묶음은 식별자에 넣지 않고 사건 안에서 재게시 할인에만 씁니다 (넣으면 독립 매체들의 보도가 서로 다른 사건이 되어 신뢰가 쌓이지 않음). 소유자 질문 14.
- **`p_credibility`의 뜻:** 레코드의 값은 **기사를 받은 시점 (조립 시점)** 의 신뢰입니다. 충격을 만들 때는 그 값을 쓰지 않고 결정 시각 기준 값을 다시 읽습니다.
- **`market_confirmation`:** 조립 시점에는 사건 창이 끝났을 수 없으므로 언제나 PENDING입니다. 창이 끝난 뒤의 판정은 레코드를 고치지 않고 따로 기록해야 합니다 (아래 4절).

## 4. 잇다가 드러난 틈 (고치지 않고 적어 둠)

1. **시장 확인 표지를 둘 자리.** 레코드는 조립 뒤 바뀌지 않는데 시장 확인은 며칠 뒤에야 정해집니다. 지금 e2e는 PENDING만 넣습니다. 나중 판정을 시점 저장소에 "레코드 ID + 판정 + 알게 된 시각"으로 따로 쌓는 형식이 필요합니다 (`didm-score-v1` 제안에 절 추가).
2. **참신성·관련성 모형이 아직 이 흐름에 없습니다.** e2e는 `novelty_0_100`에 묶음 순번에서 온 대역값 (첫 글 100, 재게시 0)을, `relevance_0_100`에 언급 위치의 등록 규칙값 (제목 100 … 본문 40)을 넣습니다. 두 모형은 정답 집합으로 맞춘 뒤 들어갑니다.
3. **입장·공식 표시.** 모델이 낼 길이 없습니다 (판단 v1 제안에 절 추가).
4. **보정.** e2e는 보정 없는 길로 돕니다 (가짜 채점기가 이미 보정돼 있어 정답과 정확히 비교하려고). 보정 지도를 끼운 길은 DIDM-5와 계약 시험에서 따로 확인했습니다.
5. **속도.** 원출처 묶음이 과거 7일의 모든 기사와 비교해 기사 8,800건에 약 10초가 걸립니다. 실제 규모 (하루 수만 건)에서는 MinHash 띠 묶기 같은 후보 줄이기가 필요합니다.
6. **유형 판단이 틀릴 때.** 가짜 채점기는 유형을 언제나 맞춥니다. 같은 주장의 보도들에 유형이 다르게 붙으면 사건이 갈라져 신뢰가 덜 쌓입니다 (식별자에 유형이 들어가므로). 실제 채점기의 유형 정확도 (Stage 1)가 이 영향의 크기를 정합니다.
