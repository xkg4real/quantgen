### MINOR-6: Over-Engineering in Part B That Should Be Cut
* **Spec section:** [§5.2 Stage 3, Stage 7, Stage 8, Stage 10](file:///C:/Users/whydi/OneDrive/Desktop/QUANTGEN/docs/superpowers/specs/2026-10-23-quantgen-split-and-paper-pipeline-design.md#L198-L287) and [§5.4 Skill & Workflow](file:///C:/Users/whydi/OneDrive/Desktop/QUANTGEN/docs/superpowers/specs/2026-10-23-quantgen-split-and-paper-pipeline-design.md#L292-L298)
* **Problem:** Part B layers five ceremonial abstractions onto a personal research pipeline:
  1. **Four parallel blind sub-agents + a 5th completeness critic (`L200-209`) for Literature Review:** Running 5 separate sub-agents per paper just to assemble `references.bib` burns massive context/tokens and produces duplicate/conflicting BibTeX keys that then have to be reconciled. One researcher agent + a deterministic Python script (`verify_bib.py` querying Crossref/arXiv APIs and checking local files) is faster, cheaper, and deterministic.
  2. **3-Referee $\times$ up to 3-Round Automated CLI Debate Loop (`L252-270`):** That is up to **9 full-paper LLM invocations + 3 full LaTeX rewrites + 3 `study.py` re-runs** per paper. Worse, allowing Stage 8 referee rounds to re-run `study.py` with modified tests or parameters (`L265: "Code or test changes in study.py, re-run"`) without registering a new trial or labeling it post-hoc **violates QUANTGEN's own pre-registration / multiple-testing principles (P7, P13, R-23)**!
  3. **Converting LaTeX PDFs to PNGs to run `design:design-critique` (`L239`):** LaTeX typography (`microtype`, `booktabs`, standard margins) does not benefit from a UI design-critique skill meant for web/app interfaces; checking the `.log` file for `Overfull \hbox` / `Underfull \vbox` / `Float too large` warnings in `compile.py` is deterministic and catches real LaTeX layout defects.
  4. **Static HTML Index Generator (`build_index.py`, `L281-286`) with `design-system.md` tokens:** For a local folder of PDFs (`docs/papers/<slug>/`), a clean `docs/papers/README.md` table (or a 30-line script) suffices; building a styled HTML portal with custom CSS tokens (`#faf9f5`, `#1a365d`, Pretendard/Inter) is unnecessary UI maintenance.
  5. **`.claude/workflows/research-paper.workflow.js` (`L294-295, L309`):** Redundant with `.claude/skills/research-paper/SKILL.md` and not natively executed by Claude Code.
* **Evidence:**
