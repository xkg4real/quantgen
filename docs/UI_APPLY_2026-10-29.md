## Apply to a local checkout

1. Finish/save active analysis and stop the old Flet process normally.
2. Inspect `git status --short` and `git branch --show-current`. Do not reset, clean,
   switch over local edits, or overwrite .env. Preserve existing credentials privately.
3. After this UI integration is merged, a clean checkout already on main can run
   `git pull --ff-only origin main`. On a Claude/work branch, first reconcile its
   changes; do not blindly replace it with main.
4. In the existing project interpreter, run `python main.py` (or its existing Flet
   web launcher) and open the NEW address it prints. The old localhost port may change.
5. Confirm Research Home first, F1 logo, Markets/Build & Test menus and one existing
   analysis route. The owner PC restart has not been performed from cloud.
