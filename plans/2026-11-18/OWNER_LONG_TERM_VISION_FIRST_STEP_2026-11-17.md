# QUANTGEN 장기 비전 첫걸음 초안

Nov 17, 2026 · @GEON

첫걸음은 **검증 계층 v0**입니다. 사람·자체 LLM·DIDM이 만드는 모든 전략과 모형을 하나의 표준 카드로 기록하고, 모든 시도를 원장에 남기고, 그 위에서 자체 LLM의 기준선을 재는 6주 작업입니다. 커뮤니티 비교와 원클릭 추종은 이 카드 위에서만 작동하고, 리딩방과의 차이도 이 검증 기록에서 나옵니다.

## 1. 비전을 네 층으로 나누면

&#91;embedded content: QUANTGEN 비전 · 네 층과 공통 기반, 규제 위치는 2절 자료 기준\]

①②는 지금 준비 중인 유사투자자문 신고 범위 안에서 만들 수 있고, ③은 채널 설계에 따라, ④는 투자일임업 등록이나 제휴가 있어야 열 수 있습니다. 네 층 모두 맨 아래 검증 계층을 공유하므로, 그것부터 만듭니다.

## 2. Go/No-go 판단

자체 LLM과 DIDM 확장은 조건부 Go, 커뮤니티는 보류, 주문 실행까지 연동한 원클릭 추종은 지금은 No-go입니다. 법적 판단은 공개 자료에 근거한 사전 검토이며 법률 의견이 아닙니다.

| 항목 | 판단 | 근거 | 조건 |
| --- | --- | --- | --- |
| 자체 금융 LLM: 처음부터 사전학습 | No-go (지금) | [BloombergGPT](https://arxiv.org/abs/2303.17564)는 500억 파라미터, 금융 토큰 3,630억 개로 학습했습니다. 그런데 금융 전용 학습이 없는 GPT-4가 공개 금융 벤치마크 대부분에서 앞섰다는 [비교](https://beancount.io/bean-labs/research-logs/2026/05/05/bloomberggpt-large-language-model-finance)가 있고, 범용 모델이 금융 특화·미세조정 모델을 여러 과제에서 앞선다는 [연구](https://arxiv.org/html/2305.05862v2)도 있습니다. | 규모 경쟁은 차별점이 되지 않습니다 |
| 자체 금융 LLM: 공개 가중치 모델 + 미세조정 + 데이터 근거 연결 + 확률 보정 + 학습 시점 고정 | 조건부 Go | 말씀하신 오류(추측·환각)는 모델 크기보다 구조로 줄입니다. 수치는 도구로 조회하고, 모르면 답하지 않고, 확률을 보정합니다. 학습 시점을 고정한 모델은 작은 규모로도 만들 수 있다는 [ChronoGPT 연구](https://arxiv.org/abs/2502.21206)가 있습니다. | 5절 평가 하네스에서 '상용 API + 근거 연결' 구성보다 나아야 계속 |
| DIDM 확장: 앱이 스스로 모형 생성 | 조건부 Go | 정해진 모형 템플릿, 사전 등록한 가설, 모든 시도를 남기는 원장이 있으면 강한 연구 도구입니다. 제약 없이 생성하면 운 좋은 백테스트를 대량으로 만들어 냅니다(4절). | 시도 원장을 두고, DSR·PBO를 통과한 카드만 사용자에게 노출 |
| 커뮤니티 비교 | 보류 | 2024-08-14부터 유사투자자문업자는 단방향 채널로 불특정 다수에게 개별성 없는 조언만 할 수 있고, 온라인 양방향 채널의 유료 회원제 영업은 투자자문업으로 규율됩니다([금융위](https://fsc.go.kr/po010101/82887)). 대가 없는 무료 회원 대상이면 양방향 운영이 가능하다는 금감원 설명도 있습니다([보도](https://www.blockmedia.co.kr/archives/621243)). | 6절 법률 질의 뒤 구조 결정 |
| 원클릭 추종: 주문 실행까지 연동 | No-go (지금) | 금융위는 선택한 트레이더와 같은 주문이 실시간으로 집행되는 카피트레이딩과, 알고리즘이 종목을 고르고 매매하는 프로그램을 '미등록 투자일임'으로 봅니다. 위반 시 3년 이하 징역 또는 1억원 이하 벌금입니다([2021 강화방안](https://www.smallake.kr/wp-content/uploads/2021/06/%EC%9C%A0%EC%82%AC%ED%88%AC%EC%9E%90%EC%9E%90%EB%AC%B8%EC%97%85%EC%9E%90-%EC%A0%9C%EB%8F%84%EA%B0%9C%EC%84%A0%EB%B0%A9%EC%95%88-full-vf.pdf)). 투자일임업 자기자본 요건은 15억원입니다([금융위 2019](https://www.fsc.go.kr/po010102/73492)). | 장기: 투자일임업 등록, 또는 증권사·일임사 제휴 |
| 원클릭 '복제': 카드를 내 작업공간으로 가져오고 주문은 사용자가 | 조건부 Go | 종목과 주문 결정이 사용자에게 남아 지금의 원칙("자동으로 주문하지는 않습니다")과 맞습니다. OKX도 상위 봇 전략을 골라 복제하는 [봇 마켓](https://www.fintechfutures.com/press-releases/okx-bot-marketplace-makes-it-easier-to-use-trading-bots)을 따로 둡니다. | 다른 회원 전략 배포가 유사투자자문 범위인지 확인 |

## 3. 리딩방과 구별되는 지점

리딩방과의 차이는 문구가 아니라 구조에서 나와야 합니다. 리딩방은 '누구를' 믿게 만들고, QUANTGEN은 '무엇이 검증됐는지'를 보여줘야 합니다. 오른쪽 열이 곧 첫걸음(5절)의 산출물입니다.

| 리딩방의 특징 | QUANTGEN 설계 |
| --- | --- |
| 사람(리더)이 종목을 찍어 준다 | 단위는 사람이 아니라 규칙입니다. 카드마다 경제적 가설, 데이터, 신호·위험 규칙, 비용 가정이 적혀 있습니다 |
| 수익 인증은 캡처 몇 장 | 모든 성과를 같은 엔진·같은 비용 가정으로 다시 계산하고, 코드 해시와 데이터 시점을 기록합니다 |
| 성공 사례만 보여준다 | 폐기된 카드와 시도 횟수까지 원장에 남기고, 시도 수를 반영한 샤프(DSR)를 표시합니다 |
| 유료 단체방에서 양방향으로 조언 | 법률 의견 전까지 단방향·불특정 다수 원칙을 유지합니다 |
| 손실보전·이익보장 광고 | 2024년 개정법이 금지한 광고 문구를 쓰지 않고([금융위](https://fsc.go.kr/po010101/82887)), 성과는 범위와 불확실성으로 표기합니다 |
| 따라 하면 끝 | 복제 전에 그 카드가 왜 작동한다고 보는지를 배우기 화면으로 연결합니다 |

같은 이유로 "자체 LLM은 오류가 적다"는 문구도 측정값 없이 쓰면 리딩방식 주장이 됩니다. 5절의 평가 하네스가 그 숫자를 만듭니다.

## 4. 왜 검증이 먼저인가

앱이 스스로 모형을 많이 만들수록, 수익이 없는 전략도 운으로 좋아 보이는 비율이 커집니다.

&#91;embedded content: 계산: Bailey & López de Prado(2014)의 기대 최대 샤프 근사식 · 참 샤프 0, 독립 시행, 정규 수익률, 연 샤프 표준오차 √(1/T) 가정 · 일별 데이터 T년\]

QUANTGEN 연구카드 34개 중 PASS는 5개였고, TRADEGEN은 21,408개 설정 중 Holm 보정 5% 검정을 통과한 것이 0개였습니다(DIDM 연구 보고서). 앱이 모형을 대량으로 만들면 같은 문제가 사용자 화면으로 옮겨오고, 커뮤니티 순위표는 운 좋은 전략을 위로 올립니다. 사용자 알고리즘을 모아 헤지펀드를 운용한 Quantopian도 성과 부진 끝에 2020년 문을 닫았습니다([Bloomberg](https://www.bloombergquint.com/amp/businessweek/quant-trading-platform-quantopian-closes-down)). 그래서 모든 시도를 남기고 시도 수만큼 기준을 올리는 원장(DSR, PBO)이 첫걸음에 들어갑니다.

## 5. 첫걸음: 검증 계층 v0 (6주)

새로 만드는 것보다 이미 있는 것을 표준으로 올리는 작업입니다. 저장소에는 저장 연구카드, `gate_ledger.py`, `run_registry_store.py`, 계산 코드 해시를 만드는 `core/research/provenance.py`가 있고, ⑨-1 누출 감사는 승인됐고, ⑨-4 새 모델 채택 기준(DM/MCS, ΔSharpe, DSR)에는 결정 M-1\~M-22가 반영돼 있습니다. 파일 이름과 업무 기록까지만 확인했고, 코드 내용은 아직 보지 못했습니다.

&#91;embedded content: 검증 계층 v0 구조 · 입력 3개, 카드·엔진·원장, 화면 3개\]

입력이 사람이든 LLM이든 DIDM이든 같은 카드 형식으로 들어오고, 원장을 통과한 카드만 배우기·비교·복제 화면에 나옵니다.

| 작업 | 내용 | 기간 | 완료 기준 |
| --- | --- | --- | --- |
| W1 카드 표준 (QSS v0) | 저장 연구카드를 바탕으로 필드를 확정: 경제적 가설, 데이터와 시점, 신호 규칙, 위험 규칙, 비용 가정, 대상 시장, 버전, 작성자 | 1\~2주 | 기존 연구카드 34개를 빠짐없이 표현하고, 카드로 백테스트를 다시 돌리면 같은 결과와 같은 코드 해시가 나옴 |
| W2 시도 원장 | 모든 백테스트 실행을 카드 ID와 함께 기록하고, 카드별 시도 수와 DSR·PBO를 자동 계산 | 2\~3주 | 원장을 거치지 않는 실행 경로 0개, DSR이 손계산과 일치 |
| W3 LLM 평가 하네스 (FinEval-QG v0) | 300\~500문항, 다섯 묶음: ① 수치 근거 질문 ② 자연어 전략 → 카드 변환 ③ 뉴스 유형 판정(DIDM 골드셋 계획과 공유) ④ 답할 수 없는 질문(기권) ⑤ 학습 시점 이후 정보 누출 탐지 | 3\~5주 | 기준선 3개(상용 API + 근거 연결, 공개 가중치 원본, 자체 파이프라인 모델)의 점수표: 환각률, 기권 보정(ECE), 카드 변환 정확도, 누출률, 1,000건당 비용 |
| W4 결정 | W3 점수로 자체 모델 개발 계속, 좁은 작업용 미세조정만, 상용 API + 근거 연결 중 하나를 고름 | 6주차 | 결정과 근거를 한 장으로 기록 |

6주 뒤 결정 규칙(제안):

- **Go:** 자체 모델이 환각률과 기권 보정에서 '상용 API + 근거 연결'과 같거나 낫고 1,000건당 비용이 낮으면 자체 LLM 개발을 계속합니다.
- **부분 Go:** 한 축만 앞서면 DIDM 뉴스 유형 판정 같은 좁은 작업에만 자체 모델을 쓰고, 해설은 API + 근거 연결로 둡니다.
- **No-go:** 둘 다 뒤지면 자체 모델 개발을 멈추고 데이터와 하네스에 투자합니다. 카드·원장·하네스는 어느 경우든 남는 자산입니다.

W1·W2는 출시 준비 작업과 겹치지 않게 연구 브랜치에서, W3는 DIDM 1단계 골드셋 작업과 합쳐 진행하는 것을 권합니다.

## 6. 병행: 변호사에게 보낼 질의

커뮤니티와 추종 기능을 설계하기 전에 답이 필요합니다. 지금 준비 중인 유사투자자문 신고 자문과 한 건으로 묶는 것을 권합니다.

1. 다른 회원이 만든 전략 카드를 열람·복제하게 하는 기능이 유사투자자문업 범위(단방향, 불특정 다수, 개별성 없음)에 드는가?
2. 유료 구독 앱 안에 회원끼리 토론하는 공간을 두면 '온라인 양방향 채널 유료 영업'인가? 무료 회원에게만 열고 운영자는 조언하지 않으면 달라지는가?
3. 사용자가 고른 카드의 신호를 계산해 보여주고 주문은 사용자가 직접 넣는 구조는 투자일임이 아닌가? 신호 옆에 사용자가 매번 누르는 주문 버튼을 두면 어떤가?
4. 앱 안 LLM이 사용자 질문에 답하는 기능의 경계는? 기존 'AI 자유 질문 제외' 판단과 고정 해설안이 그대로 유효한가?
5. 장기 경로로 투자일임업 등록, 증권사·일임사 제휴, 코스콤 로보어드바이저 테스트베드 중 어느 쪽이 현실적인가? 각각의 비용과 기간은?
6. TRADEGEN이 다루는 가상자산 전략의 공유·추종은 자본시장법 밖이라는 해석이 있습니다([법무법인 글](https://chakwon.com/_ENG/dh_board/views/56884)). 다른 규제는 어떻게 걸리는가?

## 7. 확인이 필요한 것

이 초안을 확정하려면 다음을 알려주세요.

- **자체 LLM 파이프라인의 현재 상태:** 기반 모델 이름과 크기, 학습 방식(사전학습·미세조정·LoRA), 학습 데이터의 출처와 마지막 시점, 쓸 수 있는 GPU와 예산. 5절 W3의 기준선 설계가 여기에 달려 있습니다.
- **"경제학적 모형 구성"의 범위:** 정해진 모형 목록(예: 공시 후 표류, 변동성 점프, 거시 지표 서프라이즈 반응)에서 고르고 추정하는 수준인지, 새 방정식을 만드는 수준인지.
- **커뮤니티의 첫 시장:** 한국 사용자인지 해외 사용자인지. 규제 경로가 다릅니다.
- **기관 고객의 시점:** 기관은 계약과 전문투자자 규정이 따로 붙습니다.
- **투입 가능한 인력:** 동료 1명을 포함해 주당 몇 시간을 쓸 수 있는지, 출시 준비 작업과의 우선순위는 어떻게 두는지.
